# Partial selected reference houses

This is a source-preservation regression, not an independent astronomical or classical Guolao oracle. The canonical Guolao payload has seven core planet records, null reference axes, no reference house cusps and null planet houses. Its source validation explicitly keeps classical acceptance false, life-palace degrees unresolved and the selected reference houses unavailable. The canonical engine's separate four-remainder and functional-palace structures do not become extra local chart objects through this fixture.

The portable fixture injects the same frozen canonical source into in-process REST, CLI and MCP to isolate the missing-house boundary from native astronomy build differences. The 24 options cover both exact poles, both orientations, both first-house choices and no/legacy/modern mansion overlays. These are 24 control inputs, not 24 independent algorithms or numerical house successes.

Actual live-source protocols were checked separately on 35 requests: 24 partial cases, 8 ordinary Guolao cases, 2 invalid requests and 1 unknown-clock date case. Historical failures, source captures, complete before/after bodies and timing are external research records, not repository test dependencies.

The source bibliography and validation are retained verbatim in the fixture. In the public result, calendar source groups remain a dictionary and the selected chart bibliography is an additional `rulesets.chart` group. Source validation is under `validation.chart_source`. An unavailable house layer does not turn a known clock into an unknown one or suppress planet, calendar or requested modern-mansion results.

Primary source entry already declared by the canonical engine: [Tohoku University, Lu Wei's Guolao edition](https://touda.tohoku.ac.jp/collection/en/database/library/10020000001141). This fixture does not re-certify the book's whole method or its relation to modern reference coordinates. Previously frozen CGAL circle tests keep their original separate numerical scope.
