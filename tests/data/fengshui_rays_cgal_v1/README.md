Generated outside FateBridge with unmodified CGAL 6.2.1 and its exact rational Cartesian kernel backed by Boost cpp_rational. Original Ray_2/Segment_2 intersections, point/segment containment, convex_hull_2 and exact squared_distance_2 determine the answers. Convex hull normalization applies only to declared convex input, not arbitrary nonconvex polygons. [CGAL intersection semantics](https://doc.cgal.org/latest/Kernel_23/group__intersection__linear__grp.html) include shared boundary points; [Ray_2](https://doc.cgal.org/latest/Kernel_23/classCGAL_1_1Ray__2.html) retains the supplied direction vector.

Inputs and acceptance criteria were frozen before production changes. Metadata pins the release archive, reference driver, original inputs and complete independent output. No FateBridge import or output supplies a reference answer. Full source, compiler/header provenance, failed controls and protocol captures remain in the external fatebridge-spatial-rays-20261112 artifact; no CGAL product dependency is introduced.

Includes 17056 finite closed-convex ray cases, 6296 source-rectangle corner cases and 9478 backing cases. Corners retain all 6296 four-corner reference masks. Of the backing cases, 24 collapsed-segment raw controls are invalid public PlanSegments; tests preserve public rejection and exercise the shared internal geometric primitive separately. They do not count as public success. The 18 synthetic public controls preserve eight quarter-turn/mirror corner cases, eight backing cases and independently known rounded/unknown shape facts. No site action is executed.

Presence and nearest ray parameter must match exactly. Boundary contact, inside starts and collinear overlap are included; finite reach uses exact squared Euclidean distance, not a rounded ray endpoint or expanded epsilon. Normal backing distances use the original 2e-12 metre line; explicit magnitudes below 1e-100 or above 1e100 use two ULPs of an MP90-rounded exact-reference distance. Basic 45-degree components share the correctly rounded magnitude; general rotations are a finite rational model of MP90-rounded coefficients. This does not prove all transcendental angle boundary decisions. Empty/point/segment targets and zero direction vectors are internal closed-set controls, not expanded public body schemas.

This finite mathematical comparison does not validate all scenes, physical measurements, author rules, action permissions, predictive effects or global SOTA. Existing visibility, shadow, calendar and source counterexamples retain their own scope and original gates.
