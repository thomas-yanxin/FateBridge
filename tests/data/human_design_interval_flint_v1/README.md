# Independent nominal geometry and interval primitives

The fixture retains every input and rounded reference value from the separately frozen 354-case Arb cohort and all 320 exact FLINT primitive cases. Its raw JSON SHA-256 is pinned in `tests/human_design/test_hd_interval_reference.py`. Original input, generator, criteria and reference hashes are retained in the metadata. No FateBridge value generated an expected answer. The earlier 21,627 projection triples and 36 limb controls remain separate and unchanged.

The reference used **python-flint 0.9.0 / FLINT 3.6.0**, with **16,384-bit Arb**. It computes spherical separation with `acos(dot)` and the nominal solar angular radius with `asin(radius/distance)`; the product uses integer interval series and `atan2(cross-norm,dot)`. Both use the original finite binary64 coordinates as exact rational inputs. Constants remain 695,700,000 m, 149,597,870,700 m/AU and the original binary64 `1e-12` classifier resolution. Both Arb enclosure endpoints certify each rounded value. A separate integer quotient/remainder IEEE binary64 encoder checked all 2,124 endpoint encodings without `Fraction.__float__`.

The 354 inputs comprise 128 random, 40 coincident/antipodal, 96 nearly parallel/antiparallel or tiny-latitude, and 90 limb-neighbor cases. **66 exact coincident/pole/antipodal cases use explicit analytic glue and receive no independent Arb credit.** All three scalar outputs and the classifier are retained, with no tolerance or filtered cases. The portable fixture stores rounded targets; it does not include the full Arb enclosures.

The 320 primitive inputs use 16, 64, 128, 512 and 2,048 bits. Eleven exact endpoint checks per input use FLINT `fmpq` and `fmpz.isqrt`. Division denominators are positive. Square root is explicitly evaluated on the nonnegative-clamped interval declared before comparison. These cases do not cover all private argument domains, guards or transcendental primitives separately.

Primary references: [NIST sine/cosine series](https://dlmf.nist.gov/4.19), [inverse-function series](https://dlmf.nist.gov/4.24), [range reduction](https://dlmf.nist.gov/4.45), [Johansson's Arb paper](https://arxiv.org/abs/1611.02831), [FLINT 3.6.0 source](https://github.com/flintlib/flint/releases/tag/v3.6.0), [python-flint 0.9.0 release](https://pypi.org/project/python-flint/0.9.0/). Archived release checksums bind the source downloads; the recorded wheel and loaded-library bytes do not establish a source-to-binary rebuild attestation.

This verifies bounded mathematics on supplied coordinates. It does not certify the native coordinates, physical occultation, visibility, Human Design source rules, predictive efficacy, all inputs or SOTA. The runtime's existing physical and source qualification flags remain unchanged.
