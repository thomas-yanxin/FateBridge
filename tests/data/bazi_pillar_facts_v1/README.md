# 柱内与柱间字面事实固定参考

`reference.json` 来自两个固定外部实现，采集器不导入 FateBridge：

- [lunar-python 1.4.9](https://github.com/6tail/lunar-python/blob/1645ad3b3653635e5cb31b0c6df22b5e4298f8ce/lunar_python/util/LunarUtil.py)：干支五行、有序藏干、支六冲与所选 `CHONG_GAN_4`。它另有其他干冲表，本参考没有把这些表混用。
- [china-testing/bazi](https://github.com/china-testing/bazi/blob/33b18354d5407727640e545c3aaec0efb4bf5282/ganzhi.py)：原十神字典的本、生、生我、克、被克五类映射与六冲表；执行同提交 `common.py::check_gan` 的原函数100次，核对全部有序干对。采集期使用bidict 0.23.1，未增加项目依赖。

参考包含120个干支符号赋值的本气关系、280条有序藏干关系、100个干对与144个支对。回归将各单柱放到四个位置，将60甲子的3600个有序对放到六个位置对，检查方向、原字与位置。符号赋值不等于有效出生盘；这些穷举不是盲测，也不证明有效力量、完整反吟学说或预测效度。
