# AA1996 的 Canping 立春范围

原队列为2200—2320年每年24个太阳黄经交点，另加1799年立春，共2905项。压缩包保留完整输入、独立 Skyfield/DE440 参考、原候选值、原比较、19个超差项和原协议；未筛除失败行。原1秒 TT 门槛及最大1.2738615274429321秒误差保持不变。

Canping 在此次修改前就只消费315度立春。其缺失的2205—2320年116个事件均在同一1秒线内，最大0.8757948875427246秒。1.2.0仅为这项原有需求增加按年约束的派生事件资格，普通工作 TT 区间、公开1800—2200年及完整节气1784—2204年资格均不扩张。

参考使用 NASA 原始 DE440、Skyfield 1.53 的默认视位置与当日真黄道、jplephem 2.24、NumPy 2.5.4；未导入 FateBridge。原资料在本次实现前已经可见，不算盲测或新增物理观测。模型保持原 AA1996 轨道、月球及归算代码，没有写入参考事件时刻或替换轨道。数值 TT 对照不证明未来 UTC 闰秒、历代钟时、传统规则或预测有效性。
