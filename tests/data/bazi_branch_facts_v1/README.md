`reference.json.gz` 固定[china-testing/bazi提交33b1835](https://github.com/china-testing/bazi/tree/33b18354d5407727640e545c3aaec0efb4bf5282)的原字典，以及实际执行的`get_gong`和两段原始三合／三会循环。采集器不导入FateBridge，未替换函数体、格式器或判断语句。20,736个四支赋值分别在四干不同、四干相同两种输入下执行，共41,472次原函数、82,944次原循环。原源码和采集器留在任务验收材料。

同干取虚拱后比字面成员额外报告2,816条三合；这些原结果全部保留，不能当作原局真实出现了所缺支。该仓库的`zhi_half_3hes`字典列12对，但主CLI未使用该字典，不能把读表说成已执行12对半合算法。

`convention.json` 明示本项目含中神的8对半合口径，另外4对是缺中神端支；它不是全古籍唯一读法。四局中神由既有独立lunar-python 1.4.9的120项长生表中阳干帝旺支导出，原参考的散列保留；这不是新独立语料。三合齐字与半合口径分别测试，不把12对分歧筛掉后宣称与第三方完整一致。

目验[四库扫描115–116页](https://zh.wikisource.org/wiki/Page:文淵閣四庫全書_0810冊.djvu/115)及118–121页的三合、六害、刑链与异名。原书卷二主说和所引《三车一览》互换无恩／恃势名称，均保留。115页一处“申子申”异文及其前文“申子辰”、水生旺库语境也保留；不静默重判来源输入。
