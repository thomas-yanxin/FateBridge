# 选定时标与星历的太阳日界对照

输入与原判据在调用前冻结：94个正向输入，覆盖Moshier、SWIEPH、
显式JPL，以及默认ΔT与选定IERS C04；另8个C04搜索窗越界输入必须拒绝。
两种明确冬至日政策重复执行，不作为新的独立物理样本。

比较使用未改动的原作者Swiss 2.10.03、官方SOFA 2023-10-11和独立
FLINT进程。SWIEPH使用给定原始文件，JPL使用既有18条DE441系数切片；
只修改原头部两个覆盖端点，系数不改，不宣称完整DE441。来源字节和
复制件在计算前冻结，文件与原库的哈希见`provenance.json`。

角度沿用一微角秒、钟时沿用0.0002秒、产品日界夹逼沿用1毫秒。坐标
在同一给定TT／UT1数值对上比较；UT1转TT的独立时标对照另行计分，
不把不同历元的量化差当作坐标误差。参考日界独立二分至相邻UT1浮点。
94个输入的两种政策共188次排盘、376次日界比较，全部参考夹逼包含
在产品夹逼内；其中按模型和时标区分的不同参考夹逼为176个。

`retained-epochs-v1.json` 补充现行精确历元的出生对照。70 个选定模型
输入及 4 个默认模型输入分别记录独立时标区间，以及在同一给定 TT、
UT1 上由 Swiss 与 SOFA 算出的太阳赤经、格林威治真恒星时和均时差。
现行回归核对给定数值对与公开回执，再使用原 0.0002 秒时标门和一微角秒
几何门。旧参考、原日界输入和 1 毫秒根界保留。

首次4个正向输入、8次政策调用失败，原因是全年节气的UTC标签与TT
搜索锚点不必要地要求选定UT1覆盖。修复把原子UTC转换放在共享时标
所有者内，节气显示及锚点复用该转换。真正依赖地球自转的日界求根
仍要求完整原三日窗。原失败原样保留，修复后同一组输入可用；8个
越界输入的16次调用仍拒绝，没有缩窗、外推或换默认模型。

太阳钟仅说明它消费给定的同次UT1，不再无条件将输入称为估算值。
这也不自动将给定UT1认定为实测。果老公开请求没有`ut1_source`选择器；
本数据中C04果老排盘是显式本地库上下文，不宣称新增公开能力。

[C04精确参考](../../astro/iers_c04/flint-interpolation-v1.provenance.json)
另比较同一冻结序列的23638个发布锚点及全部23637个相邻区间，每段取
1/4、1/2、3/4，共70911个内部查询。SOFA给实际原子秒差，FLINT从原始
十进制读数计算连续UT1减TAI在TT轴的线性插值和闭式反解。它是同一
源数据的数值核验，不是新增瞬时地球自转观测；形式误差不作物理界。

参考进程不导入FateBridge。Swiss与SDK、SOFA与ERFA的共同祖先明确保留。
本数据不证明独立物理星历、全部历元、完整地球定向、历史日界、冬至
当天是否纳入、日出辰寅几何、预测效果或全局SOTA。便携测试读取冻结
数值，生成器和原始失败在provenance所指仓库外目录。文件型星历控制
标为`local_data`，执行时必须具备并核对实际源文件；不能以跳过当通过。
