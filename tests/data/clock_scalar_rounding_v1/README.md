# 名义日历与标量 TT 的单次舍入参考

本参考由未修改的 [IAU SOFA 2023-10-11 C](https://www.iausofa.org/2023-10-11c)
`iauCal2jd` 给出 Gregorian 日界，并从同版 `dat.c` 原始十进制常数独立求
UTC 偏移，以有理数保留整数微秒和 32.184 秒。生成进程没有导入 FateBridge。
另实际编译运行 `iauDtf2d(UTC)`、`iauUtctai`、`iauTaitt`，保留两部 TT 原值。
源文件、原归档、生成器和完整参考 SHA-256 均在压缩 JSON 中。
原官网重新下载返回 403，本轮使用与既有官方归档逐文件散列相符的原始副本重编。

完整固定队列有 381,920 个时刻、447,456 个字段义务；其中 16,384 个名义日历
时刻是另一个 SHA256 队列，65,536 个时刻另核原子 TT。旧版名义 JD 有 148 项
不是最近 binary64 值；历史／现代 TT 分别有 8,325／10,144 项不是最近值。
修复后按同一参考均为零。各项最大误差和全部原失败保留，未调门槛。

便携回归保留全部 148 项名义 JD 失败、历史和现代各前 64 项 TT 失败，以及
16 项未失败留出控制，共 292 项；样本挑选不改变完整队列分母。
`nominal_exact` 是均匀的名义 Gregorian 标签，**不是 SOFA UTC quasi-JD**。
`tt_exact` 依照所选发布偏移求得，不能用来认证历史实测钟时或 UT1。

原强门槛要求不劣于官方 C 的两部 TT，标量输出仍有 65,536／65,536 项更差，
继续判失败。将原两部 TT 最后合成标量后，修复结果全部相同；这只证明该标量
表示下的源算术舍入，不等于达到完整 SOFA 时标能力或 SOTA。
未来沿用末次 37 秒偏移只是共同假设；18,277 项 SOFA 可疑年份警告保留。
本队列未覆盖闰秒标签、全部调整端点、所有微秒和天文物理精度。

仓库回归入口为 `tests/astronomy/test_utc_clock_domains.py`；它读取所保留的独立参考，不从生产实现重建期望值。完整队列成绩与便携回归的覆盖范围分别按上述分母解释。
