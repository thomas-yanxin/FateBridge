# Given-argument house-coordinate rounding: independent Arb reference

All72 original B input arguments are retained, in order: R24, C24 and T24. `inputs.json` is a byte-identical copy of the frozen input file. `reference.jsonl.gz` decompresses to the original72 reference JSONL bytes, including both unshifted geometry and the separately declared shifted policy. Gzip mtime is zero. The reference used independent vector planes and a certified physical-quadrant sign bracket with outward Arb intervals; its original generator, plan, criteria, dependencies and result hashes are recorded in `provenance.json`.

`native-diagnostic-inputs.json` copies only the actual BEFORE native-position field as a direct-helper stimulus. It is explicitly diagnostic input, never an expected coordinate. No AFTER output is included. Tests obtain coordinate/phase/house/RNE/delivery targets exclusively from the independent reference and keep the1e-50-degree exact working-phase gate. Action strings are a product contract, separate from mathematical accuracy.

R42 evaluated the then-declared1/3600000-degree phase shift for R/C/T. That historical acceptance and both certified profiles remain intact. Current R/C tests retain the declared shifted target; current T tests select the original unshifted continuous target after removal of the unsupported T offset. This selection changes no reference bytes and does not claim whole-book Polich/Page authority. These72 contain interior T roots only and no shift-induced house changes. They do not establish endpoint/continuum/pole conventions, actual-body latitude, house cusps, physical sky accuracy, all-domain rounding or SOTA.

The existing53568 R/C and61056 defined plus2208 native-pole T fixtures/tests and their hashes/gates are unchanged. These tests are write-only and were not imported, collected or run in this audit batch. No external artifact, memory, temporary directory, network service or native library is needed to read this fixture; executing the two direct mathematical helpers is deferred with the rest of pytest until the user gate is met.
