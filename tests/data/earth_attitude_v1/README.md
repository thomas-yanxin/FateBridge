# 地球姿态与宫位归约控制

`reference.json.gz` 保存 257 个固定 TT/UT1 时刻的官方 SOFA 2006/2000A
NPB/GAST，以及其中 12 个时刻、12 组纬度、23 种宫制、热带与 Lahiri
显示的 6,624 组原作者宫位内核控制。原门槛均为 0.001 角秒；原内核返回
未定义的情形继续要求报错。没有用候选实现生成预期值。

另保留原有太阳钟回归的全部 112 个输入：原始原生赤经仍按旧的
`1e-10` 度容差核验，归约后的赤经也按同一容差单独核验。现代姿态来自
官方 SOFA；远期只核对声明的原作者长期变化及边界三轴对齐，不证明远期
绝对准确性或导数连续性。原有输入与原始值未被更换。

原始 SOFA C 2023-10-11 与 Swiss Ephemeris v2.10.03 均未修改；压缩文件
保留下载版本、原文件摘要、构建命令、生成器原文与摘要、完整外部数组摘要。
SOFA 与 ERFA、Swiss C 与 Python SDK 的共同代码来源不构成独立理论验证。

宫位回归固定原始太阳射线作为共同输入，仅验证几何归约与所选宫制。
完整外部对照另实际调用全部 141,864 组输入并使用真实星历文件；仓库内的
精简样本是在该对照之后分层选择，不能称为盲测。太阳星历、实测地球定向、
折射、日出落、完整时域与预测效果不因这些控制而获通过信用。

原作者 `sidereal_houses_trad` 将小写 `i` 转为大写 `I`，会合并两种公开
Sunshine 算法。本数据按用户选择的原作者 **内核** 分别调用 `I` 与 `i`，
再应用 Lahiri 偏移，保留了这一原 API 反例，未把其合并行为当作正确答案。

用锁定开发环境运行
`scripts/astronomy/export_earth_attitude_reference.py --reference-directory <外部参考构建目录> --output-directory tests/data/earth_attitude_v1`
可从相同摘要的原始外部数组重导出。原始全量数组和编译库不作为 CI 的依赖。
