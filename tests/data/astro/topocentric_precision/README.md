# Topocentric zero-ecliptic-latitude reference

This directory holds the single current unshifted T position-line fixture. The original frozen population has63,282 obligations in its original order: `reference.jsonl.gz` contains the63,264 main rows (61,056 independently defined and2,208 exact-pole conventions left unqualified), `candidate-boundary-reference.json` contains16endpoint rows, and `original-antipode-reference.json` contains the original2exact-antipode rows. The two historical antipodes are retained even though their unshifted houses now coincide. `additional-antipode-reference.json` adds the separately certified two-row unshifted boundary pair; it does not replace either historical row or change the original63,282 denominator.

The fixed regression bundle is allowlisted for version control with this README and `source-files.json`: `inputs.json`, `reference.jsonl.gz`, `candidate-boundary-inputs.json`, `candidate-boundary-reference.json`, `original-antipode-reference.json` and `additional-antipode-reference.json`. Tests read these saved independent values directly; they need no reference regeneration or download. The full `inputs/` expansion, root hints, `certificates.jsonl.gz`, `legacy-input-probes.json`, `generation-summary.json` and `provenance/` remain local audit evidence, identified by the manifest rather than promised as checkout files. They retain exact binary64 angles and exact rational longitudes, including source+180 antipodes that can display as the same float. Root hints are starting brackets only, never targets or proofs; the local expanded inputs prevent a reviewed future reference traversal from silently reconstructing different cusp probes.

The numerical targets come from independent vector/moving-plane geometry evaluated with Arb outward intervals. Accepted rows require the recorded branch/root/endpoint and boundary-separation evidence. Binary64 targets use independent integer quotient/remainder nearest-even conversion; exact geometric phase chooses the half-open house and delivery preserves it. `certificates.jsonl.gz` retains the exact interval/sign/bisection evidence used for these decisions. The compact target file omits redundant derived views, not rows or adverse outcomes.

`provenance/` records source scope, mathematical gates, runtime/version identities and the independent saved review. `original-557-transitions.json` preserves the first reference run's557unresolved outcomes and their separately certified successors; the original first-run files and old shifted fixture/test before-images remain in the external audit archive identified by the provenance records. They were not overwritten or silently regraded.

Tests retain the original delivered-phase limit of1arcsecond and exact house, physical branch, root-selection and candidate obligations, with the endpoint candidate/root/delivery targets. The2,208pole rows retain their explicit native convention without independent numerical credit. Private working precision is process metadata and is not an accuracy threshold.

The generator sources are evidence, not an automatic golden-file updater. Regeneration requires a separately reviewed release that freezes the same exact inputs, dependencies, runtime and gates, preserves every unresolved/error row and records one declared traversal. Do not regenerate targets from FateBridge output, replace strict house ownership by a tolerance, or weaken the original gates to make a run pass.

These fixtures qualify only the supplied-argument continuous zero-ecliptic-latitude geometry and the declared delivery convention. Independent reference certification does not itself qualify FateBridge output, exact geographic-pole geometry, traditional whole-book authority, physical accuracy, prediction or global SOTA.
