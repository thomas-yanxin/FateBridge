# 完整 Moshier 月球源日速参考

628行覆盖314个预先固定的TT时刻、热带与Lahiri两种框架，包括原76时刻、此前太阳样本中的全域和边界时刻，以及64个新增SHA256选定时刻。没有按计算结果删除样本。

来源为[固定版本的原作者月球公式](https://github.com/astrorigin/swisseph/blob/696bda432298d482d27e67a0cf1238920301a7dd/swemmoon.c)及同版`sweph.c`的地心光行时、光行差和显示约定。原文件SHA256为`1d5f5ef9a95cf9a2f395b6334a58c63851ce0512d65bf08e49d3caf0a9fecb00`。

参考按原计算过程独立执行完整月球级数，使用mpmath70／90位运算及1/64、1/128日七点导数；不导入FateBridge。原C提供坐标转换矩阵，因此系数、公式和框架来源并非独立物理理论。月球保留名义0.00005日的向前偏置三点源速度，地球保留0.0001日后向源速度。第五次纬度谐波按实际源码保留为零；另做的恢复谐波控制不进入期望值。

FateBridge以另一种直接三角级数求和方式计算辅助几何状态，均角化简使用Decimal50位，并复用共同岁差模块。参考中的期望值均由上述原作者计算过程产生；没有使用产品数值填充期望值。

外部检查线仍为0.002角秒／TT日，内部联合收敛线为0.0002；每行还保存原C SDK原生日速相对同一参考的误差。该数据检查源算术和有限样本，不能证明相对DE441的物理准确性、连续全域、传统解释或预测有效性。

`reference.json.sha256`核对的是解压后的JSON字节。
