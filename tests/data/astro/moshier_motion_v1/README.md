# Moshier行星源算术日速

固定参考共2720项：76个原调查时刻、70个预声明留出时刻、24个追加来源范围
验证时刻，各覆盖水金火木土天海冥和热带／传统Lahiri两个框架。留出包括
公开源码范围两端、端点内一分钟、2的20／21次方TT附近的相邻浮点数；
追加队列包含按SHA256选定的端点附近距离和来源步长切换点的相邻浮点数。
全部行保留，没有只收已通过的日期或天体。

独立参考直接读取固定Swiss源码的九组原Moshier Poisson级数参数、频率、相位、
缩放常数、短月球地月质心修正和101项太阳有效质量表，以mpmath的70／90位
算术分别计算。原源码固定为`696bda432298d482d27e67a0cf1238920301a7dd`，
没有导入FateBridge，也没有把候选日速、插值多项式或拟合残差作为答案。

被比较的是原来源模型的连续算术：精确名义0.0001日后向源速度算子、一次
线性光行时、有限太阳偏折和Lorentz光行差。原生`fl(TT-0.0001)`的逐位阶跃
另保留诊断，不把其不可微的舍入映射冒充连续天体运动。每个时刻用1／64和
1／128日七点差分，以实际binary64 TT探针构造精确有理数插值权重。
两种步长及70／90位结果各自核对，原内部0.0002角秒／日线不变。

坐标显示矩阵另由未修改原C的ICRS偏置、完整岁差／章动及Lahiri基向量操作
取得，因此框架祖先共用；其执行与FateBridge的原生向量对解旋转不同。
短月球修正的亚ULP历元框架仍是原生double，不声称这一层有90位独立精度。
这是来源公式算术参考，不是现代物理星历、独立观测或预测有效性参考。

测试使用全部2720个固定参考，与实际共享日速服务比较，保持0.002角秒／TT日
外部线，并逐项要求误差不大于独立原C的原生日速误差。显示位置和原生日速
仍保留原生值。原C直接差分队列的254失败／330不稳定、此前的物理位置失败
及自动选择在精确范围端点不可用的记录没有被这些新参考改判。

`reference.json.sha256`核对解压后的完整JSON；`inputs`保留六个完整独立原输出
的内容身份。源码见[原Moshier实现](https://github.com/astrorigin/swisseph/blob/696bda432298d482d27e67a0cf1238920301a7dd/swemplan.c)、
[原视位置归约](https://github.com/astrorigin/swisseph/blob/696bda432298d482d27e67a0cf1238920301a7dd/sweph.c)、
