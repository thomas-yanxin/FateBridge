# Moshier太阳源算术日速

500项固定参考覆盖250个TT、热带和传统Lahiri两个框架。原调查76个、既有
留出70个和来源范围验证24个时刻全部纳入；另在修改前按SHA256选定64个
完整原生范围时刻和16个端点附近时刻。包括原生范围端点、时间ULP及采样
支持切换边界，没有按候选结果筛选输入。

独立mpmath实现从固定原C导出的九组Poisson参数和短月球地月质心修正
直接计算地球；没有导入FateBridge。源码为
`696bda432298d482d27e67a0cf1238920301a7dd`。
`app_pos_etc_sun`的地心Moshier约定是负日心地球，没有行星的线性光行时
迭代或太阳自偏折；完整Lorentz光行差使用名义0.0001日后向地球源速度。
原生舍入源间隔另保留控制，不把它与连续名义算子混成一个精度结论。

每项以70／90位分别评价，并以1／64和1／128日七点差分核对；探针使用
实际binary64 TT时刻及精确有理数权重。日期／Lahiri矩阵由未修改原C另取
基向量，因此框架祖先共用；短月球修正的亚ULP框架仍用原生double，
不声称这一层有90位独立精度，也不把源算术作为物理观测参考。

回归保持原0.002角秒／TT日线，逐项要求不差于原C原生日速。原实现500项
中的230超差、366未应用和189逐项更差保留在修改前证据中。原C直接位置
差分及其他物理星历失败另列，没有用这份新参考重写旧基准。

`reference.json.sha256`核对解压后的完整JSON；JSON另保留固定输入计划及
两份独立输出的内容身份。测试还要求太阳路径不读取其源模型未使用的太阳
有效质量表；其他行星的原表完整性与模型／参考点守卫继续验证。
