# 太阳地平线独立控制

`reference.json.gz` 保存 4,428 组接收者位置／速度、1,042 组太阳视向量及高度、2,538 个升落窗口。输入及预期由原版 Swiss 2.10.03 C、官方 SOFA 2023-10-11 和 SciPy 1.18.0 生成，没有导入 FateBridge。源码、构建收据、输入与完整外部数组摘要均随文件登记；生成器只导出外部数据，不以生产结果生成预期。

`de440-reference.json.gz`另保留同一批96个固定极区地点、时刻与定义的原始JPL DE440对照，全部172个事件均保留。jplephem2.23读取独立下载的原始SPK，官方SOFA计算接收者、源框架投影及光行差，独立SciPy扫描括根；24个Skyfield1.53方向控制最大差约0.489微角秒。`de440-provenance.json`包含原始核身份、实际生成器与构建记录、首两次参考失败及其原生缓存对照。它与原生模型参考分开，未替换原始失败。

`jpl-reference.json.gz`保留所有10288个原始输入窗口及14459个有序事件，覆盖原9000常规、512中央临界、512查询边界、72个C04边界和192个极区窗口。官方CALCEPH5.0.1读取原始DE440／DE441，官方SOFA与独立SciPy求根组成参考，未导入生产代码。`jpl-provenance.json`保存生成器、构建和首轮失败：SPK没有可选版本常量时如实记录，公里／日按精确AU换算；不以默认AU接口失败生成预期。自动来源的源码与Python3.10包均通过该完整队列的原1毫秒TT／UT1线，最大约0.081毫秒。需实际Swiss文件校准的模型UT1窗口仍标为`local_data`，默认完整本地pytest执行全部行。

`jpl-file-reference.json.gz`另保留24个J2000所选文件窗口、32个事件与30个精确拆分TDB源日状态。已有局部DE441夹具的全部24432个系数字节及常数记录已与新核对的原始DE441相符，边界包装不冒列为完整原始文件；谱系及旧接口18项细分源日失败在`jpl-file-provenance.json`保留。原生JPL完整192窗比较有364项时间失败，最大约1.253秒。实际所选文件、完整TDB的光学路径在原192窗364事件上满足原1毫秒线，源码与Python3.10安装包最大约0.040毫秒；这些通过不会改判原生读数近似。

当前自动路径复用已有DE440系数所有者和共享光锥、地球姿态及接收者，在96窗、172事件上通过原1毫秒UT1／TT线，最大差约0.121毫秒。原显式Moshier路径的10窗事件数差异、162个可配对根时间失败及原同源30／32项失败继续保留。具名轨道模型改变不当作同一原生坐标的算术修复；此96窗对照不单独认证全时域、原生严格模式、安装或现实预测；上述全量和安装范围另列。

选样发生在对照之后：接收者全取，视向量每17行取一组，常规窗口取经度0及五个已声明纬度；另保留全部512个中央临界纬度窗口、512个窗口边界、72个实际C04首尾窗口，以及192个近极点春秋分窗口。极区输入覆盖2000／2026／2050年、两季、南北两半球、两种来源及两种定义。48组临界构造的首轮7次未收敛、第二轮方法和残差均保留。原24次窗口末端漏报、72次C04起点失败及首组4/8次极区漏报继续保留。

近极区会在一个两小时分段内出现极大与极小，甚至一小时内升—落—升。共同服务已改为完整事件序列，首轮扩大对照仍有33项失败：31项超过原1毫秒门槛、2项插值未收敛，全部为Moshier，不能算通过。独立原C对384个参考根逐个扫描±20毫秒内的相邻浮点UT1，共382080个值；192个Swiss根均只有一次变号，192个Moshier根中157个反复变号，最多31次，跨度约18毫秒。修复了远离地平线的无须极值细分及每日根坐标归属后，源码返回数与冻结参考一致（192窗共384条）；仍有30个事件超过原1毫秒线，Python3.10安装包有32个，均未判为通过。这一诊断不撤销原失败，也不证明哪种实现物理上更准；后续原始JPL比较对应独立具名精密源，不能替同一旧原生模型改判。

`native-sign-qualification.json.gz` 保留上述原显式 Moshier 96 窗／192 根的独立原 C/SOFA 逐根变号括号，以及重新运行基线的原 25 窗／53 根 TT、UT1 逐根误差。后者复现各 23／53 项满足原 1 毫秒线；原 C 的 53 根共有 739 次局部严格变号。它们的物理太阳交叉、数值函数的局部符号稳定性和相对于历史标签的求根差异是三项不同问题，不能因二分括号只剩一个浮点步长就宣称唯一或精确。此文件是同模型诊断，不是新的独立星历真值，也未更改任何旧参考值。

显式原生 Moshier 路径现在在候选根两侧各 20 毫秒内逐个相邻 binary64 UT1 检查局部变号；先用同一模型解析请求窗口外的局部邻根，再把交付事件筛回请求窗口，因此短升落弧被查询端点截成单个事件时也能保留。此局部准入允许已解析的一对升落；更多局部变号或未解析的第二次变号不获资格，而非宣称物理上不可能存在更短的多重交叉。检查不受请求窗口端点裁剪，所需源或时钟失败照常传播。若候选附近存在这些未获资格的变号，整窗以 `solar_horizon_sign_unstable` 交付非可重试的来源一致性错误，含义是根时刻没有得到唯一资格，不能写成太阳没有升落。有效无根及切触控制仍返回空序列；没有触发本地诊断也不认证全域连续性或物理精度。自动 DE440／DE441 与所选 DE441 文件路径不受该原生检查影响，原来的 96 窗／172 根、24 窗／32 根和 10288 窗／14459 根独立分母保留。

普通求根观测留在声明窗口内；端点高度恰零时，有向交叉需要最近可辨的两侧符号，Moshier 资格检查另读取上述局部邻域。星历错误与有效无事件不同；精确切触、低于源分辨率的弧及全域连续完备性尚未认证。完整外部常规对照为9000窗口；CI取样不是盲测。

位置门槛为0.1毫米，速度为1e−8米／秒，方向／高度为1e−6角秒，事件时间为1毫秒。星历不可用与有效搜索窗口内无事件分别断言。数据文件条件的用例标记为 `local_data`，需要相同的 Swiss 文件配置；明确无文件的窗口使用临时空目录，进入普通CI。标记不表示前者已经在安装包或远端部署中验收。

两项修订保留在数据内：原版C的浮点乘加配置与当前SDK不同，另一个独立参考初版错误地将Swiss的内部钟时用于Moshier接收者。原失败保留在外部证据中，编译配置和参考修正不是盲验证，门槛未改。SOFA与ERFA有共同算法来源，不能当作独立动力学理论。

另有24个原版C的Moshier地球位置／速度一致性控制：使用原始位置、精确二进制TT步长及六阶中心差分，原速度与收敛差分相差约0.056—0.057米／秒。这定位了上游光行差速度的进一步排查方向；差分收敛不等于独立动力学精度，尚未据此修改生产坐标或撤销升落失败。

模型区分 Hindu 的地心、黄纬置零、无折射太阳中心，与行星时使用的海平面、1013.25hPa、0°C折射站心太阳中心。显式原生站心控制保持其原生光路；精密系数路径共用TDB接收地球和发射太阳。两者都以WGS84接收者完整速度进行一次SOFA光行差变换。极移、CIP偏移、地球非匀速修正、地球物理观测、地形与真实大气、全部历表物理精度及现实预测均未由本数据认证。
