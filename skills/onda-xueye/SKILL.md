# 学习与成长

学习方式、深造方向、某年考试与现实选项是不同任务；按本轮问题选择，不自动扩成人生画像。

## 共用规则与资料

先读短的[咨询核心](../_shared/consultation-core.md)。主题重叠或扩展时读[范围选择](../_shared/consultation-routing.md)；涉及阶段、日期或变化才读[时间选择](../_shared/timing-selection.md)。采用八字、紫微或西占解释时，分别定位[八字证据](../_shared/bazi-topic-evidence.md)、[紫微证据](../_shared/ziwei-topic-evidence.md)或[西占证据](../_shared/western-topic-evidence.md)的相关条目。参数、分页或 CLI 有缺口时再查[引擎参考](../_shared/fatebridge-engine.md#怎么调引擎)；表达细节按需查[解读参考](../_shared/onda-counsel.md)。软链接先解析真实目录，再读相对引用。

资料采集、摘要投影、完整交付与追问复用统一按咨询核心执行。

## 按问题选择依据

| 任务 | 候选依据 | 交付 |
| --- | --- | --- |
| 学习方式／学业传统结构 | `bazi_education`；`ziwei_birth` 相关星曜与宫位；`astro_chart` 学习相关配置 | 具体特点、适用条件与真实学习表现核对 |
| 今年考试／未来几年深造 | 专项已有时机；按需 `timing_analysis`、`ziwei_horoscope`、`western_timing_analysis` 或 `firdaria` | 阶段、目标年度和实际可比较的月份分开，不断录取结局 |
| 专业／留学／继续工作比较 | 上述相关依据＋用户实际课程、语言、成本和目标 | 文化参考与现实选择条件分开；不从五行直接指定专业 |
| 孩子学习 | 使用孩子本人的相应主盘或专项 | 不能从父母的子女宫推孩子能力，不贴学历或智力标签 |

## 读取结果与边界

读 `education_analysis` 的实际学习相关分类、文昌／科目类比、考试时机和 `timing_context`，字段名与模型分类不等于现实学历、能力或考试结果。其他体系选择真正相关的配置并核对解释来源，不因为提到水星就另开整套西占。

专题细问按[八字证据参考](../_shared/bazi-topic-evidence.md)读取所选专项的真实结构、位置、权重与已返回时间背景；不把传统分类或模板当现实结果。

## 交付与后续

普通首轮选与当前问题有关的两三处差异，给一项可尝试的学习安排；详细／跨体系请求直接展开其范围。追问时间保留学习主题，不能从年度信号写出某一天发挥或某校录取。考试日期已固定时讨论准备，不用择时暗示必须改考试日期。
