只在本次已选六壬或金口诀时读取。先用工具实际发布的 `evidence_views.core.fields`，配 `strict_fields=true`、`include_snapshot_text=false`；字段卡不是 `view` 参数。先回应所问，再用两三处实际结构支持传统解释。未完成的规则只限制相应判断，不替代已有课盘的解读。

## 六壬起课与行年

核对 `analysis_context` 的输入时间、校正时间、时区及 `four_pillars`，月将看 `liureng.month_general` 与 `meta.month_general_basis`。中气换将用实际瞬间，不能用月建代替月将。

用户给了秒数时保留 `analysis_second`，不截成整分钟；交中气或太阳时时辰边界可能在同一分钟内。秒数是时间输入精度，不代表秒级事件应期。

核对“符合国家历法标准”时，[GB/T33661-2017官方预览](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E107EA4DE9725EDF819F33C60A44B296)第5.1–5.2条要求日月位置采用IERS规范模型、朔和节气北京时间计算精度达到1秒，并排除编算时尚未发布的闰秒；这是规范要求，不能当作本工具已通过认证或印刷分钟表的实测误差上界。[PMO官方解读](https://pmo.cas.cn/xwdt2019/kpdt2019/202203/P020240201504886119982.pdf)明确北京时间属于UTC，不能为改善对表成绩改用UT1。尚未取得分钟舍入算法，原30秒条件不变，也不能自行改成31秒。历史UTC前的标签、未来闰秒和具体计算来源仍分别说明；标准农历日的零点界不改写本工具所选子初日时柱口径。原页、五配置事后诊断及范围见第六十七轮。

读取 `liureng.calendar_policy` 或 `jinkou.calendar_policy` 的民用输入、日时取用钟与 `effective_day_date`。当前日时柱采用所选时钟23:00子初换日，`standard` 指 JDN+49 日序，不能说成零点换日。真太阳钟只用于日时柱；年/月柱交节和月将中气仍用民用瞬间。`swisseph` 提供者状态不等于完整历法域精度认证；`symbolic_or_unverified_civil_input` 不证明真实公历时刻。503 `dependency_missing` 表示未能取得可靠天文交气，不从线性回退或旧课补造本次结果。

打包DE440来源按每项交气的实际`ephemeris_model`和完整来源回执核对：既有年网格档案与1700—2300范围所用扩展档案分别保留身份，跨年依赖可并用两份档案，不将其压成一个全局型号，也不因提供者同名而套旧档案。黄经过界须在该实际档案上复算；私有历史或长期投影档案不因此成为公开起课来源。来源可用不认证历史UT1、未来闰秒或全域物理精度，也不扩张独立农历换算、行年岁数与原典认证范围。完整队列及原失败见第八十二轮来源接线。

`meta.guiren_profile` 区分既有 `liuren_common_v1` 和《探原》贵人歌 `tanyuan_xieji_v1`。后者只换大六壬昼夜贵人表，不声称采用《探原》全书所有异法；明确要求该表才传相应配置。昼夜读取 `meta.is_diurnal/diurnal_basis`：省略 `is_diurnal` 按时支约定，并非程序观测了当地星出星没。

交气依赖以TT求解后转换民用时间，读取 `solar_term_dependencies.solver_time_scale/civil_time_method` 及 `future_leap_seconds_assumed_unchanged`。1960年前为历史UT1/ΔT约定，1960年采用[SOFA历史UTC偏移与日漂移](https://www.iausofa.org/2023-10-11c)，1961–1971年用IERS历史UTC漂移，现代使用冻结闰秒表；这些标准关系不认证当地授时或输入钟表。更远未来的闰秒末值假设须按实际字段说明。节气字符串的小数秒是数值分辨率，不能据其位数宣称微秒天文精度或事件应期。完整比较仍有未通过项，见第七轮验收。

交气模型按每个依赖的 `provider/ephemeris_model/solar_model_details` 读取。`fatebridge_analytic` 是具名解析太阳模型，不是Swiss文件计算或现场观测；其原生返回选项为空，不能补造选项或借用另一模型的成绩。原生与解析路径的分钟差异、TT对照及时制局限分别见第三十五轮验收；有限TT通过不抵销旧分钟失败，也不认证全部民用历法或自由文本解释。

核对历法精度时，实际 `swisseph/moshier` 不能沿用 `swieph` 或打包DE440的成绩。第六十六轮直接TT对照保留原113个诊断事件：Moshier有18项超原1秒线，另外四种配置在这组事件上均在1秒内，但各自仍有21项原分钟表数值超差。它是含已知失败的诊断队列，不是总体错误率或物理精度上界。新参考使用JPL惯性视方向与IAU2006/2000A；当前打包DE440与SPK的IAU2000B章动近似可解释约0.063秒的主要残差，不能把数值二分的小数位说成天文精度，也不能据通过TT比较宣称原分钟门槛已通过。普通问事解释不必展开这段模型对照。

`jpl_spk/fatebridge_jpl_spk_solar_v1` 是显式选择的文件太阳模型，读取实际内核散列、覆盖及参考系；不称作Swiss原生JPL返回标志，也不推断默认配置已使用它。第三十七轮完整边界核验把同一4872个DE440对照交气和9744个分钟探针接入实际课盘：Swiss文件路径有一个探针连带改变月将、四位与阴阳取用，显式SPK在可判字段上未见该差异。两套实现共用DE440理论来源，不是独立观测；参考端点未知、HKO原日期差异、历史时钟及未来闰秒假设仍保留。不能从一秒时刻容差通过推断所有课盘边界正确，也不能把这组条件下的旺衰、阴阳取用一致性解释成完整原典断法已认证。

当前默认 `jpl_de440/fatebridge_de440_solar_v1` 的1800—2200适用输入年，其跨年依赖可来自1799或2201。此时 `solar_model_details.adjacent_boundary_context_year` 记录起课所在年，`solar_model_input_years` 保留模型公开输入范围；不把内部边界年称为新增输入年认证。实际来源仍逐依赖读取，不能用配置名代替；第三十九轮首尾跨年验收的96个TT根与6个固定日期不认证全域秒级判界、真实历史授时或未来闰秒。

该例后文称“传送是白虎之神”“白虎无气”时，所指是将神传送的金，不是把图式中的贵神玄武换成白虎。核对原书别名时先绑定四位位置，保留贵神水、将神金的实际区别。

“天门入地户课”按本课将神戌临地分辰识别；“地户入天门课”则读贵神勾陈辰临地分戌，两条不能强行使用同一位置。天魁与天空虽同涉戌支，本条的将神、贵神仍须按实际四位分开。

`patterns.evaluations`保留完整64条三态，命中列表、未决列表和计数须来自同一逐条结果。输出合同会在投影前拒绝这几处互相矛盾的依据；不要只选命中项便把未决从分母删除。`complete_classical_conformance=false`表示当前节录未获完整认证，合同一致性通过也不能将其改写为全书符合或自由文本解释已经满分。

即使摘要没有四位或占日，已给课钤ID仍对应固定的所选课名、别名、页位与条件；来源及适用范围也不能随摘要改写。六条原典疑义保留null，另有58条已实现条件的输入缺项须标为input_unavailable，两者不能互换。缺少ID或原始条件时不补造课名、命中或占日；这种摘要校验不认证原书例图与定义已经全部相符。

核对原书课例的四位重建时，先分开核对人元、贵神与将神。按当前所选公式，切换昼贵／夜贵只改变贵神，不改变按日干和地分遁出的人元，也不改变月将加时所得将神。另一昼夜候选与某个神名相符，不等于整课相符；不能为逐例命中而择优切换、反推另一个日干或替换月将。当前独立拆分见第八十四轮构课诊断。

金口诀本课不借大六壬三传定用。请求中的 `guiren_profile` 仅影响附带的 `liureng` 盘，金口诀仍用自身古本昼夜贵神表。

`waiting_branch` 只表示原书虚一待用的缺支，不自动推出最近某日、某月必成。实际远近时间层及完整合化条件仍未裁定。润下破体的书影/转录异文保留在 `combinations.textual_variants`；原典来源与新验收见第八轮记录。

## 忠实引用与现实核验

引用已有结果时保留同一 `run_id` 和完整业务散列；完整内容读取同 run 的 `result_delivery`，不为取得更多字段重起一课。需要机器核对的结构化事实，可按[同次引用核验](../../../docs/prediction-validation.md#同次结果引用核验)检查路径和值；核验通过不证明自由文本推论或现实预测正确。

`result_delivery` 的全文是本次请求实际保留的payload。摘要 `fields` 调用即使读完交付物，也只能称本次投影结果全文。完整业务须首次 `fields=null`，再读取同次交付，不通过重算或拼接不同run改称完整。

程序的 `classical_acceptance_passed=false` 和 `real_world_efficacy=not_tested` 要按实际范围说明，不把课例回归当现实命中率。传统提示对应哪些现实条件、如何观察及何时复盘应另说清。来源疑文、影印页及专项验收见[六壬与金口诀审计](../../../docs/liuren-jinkou-audit.md)。
