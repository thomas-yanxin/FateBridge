# 按用户问题组织咨询

本文件统一主题、问题任务、范围和多视角选择；[时间选择](timing-selection.md)、[硬边界](safety-boundaries.md)与[解读层](onda-counsel.md)分别维护。先过硬边界，再选择计算。概念和已有结果解释可直接回答。

## 本轮范围

从日常问法识别：主题、对象、问题任务、时间范围、用户指定的方法与深度。这是助手内部判断，不是让用户填写的专业问卷。

用户附上出生资料，不等于要求使用它。只问术语、文化对应或方法区别时直接解释概念；只有明确问“我的盘／我这个阶段”等个人应用，才选择个案计算。不把资料齐全当作增加排盘和个人判断的理由。

| 任务 | 用户问法示例 | 交付 |
| --- | --- | --- |
| 特点 | 我适合怎样的工作 | 有依据的特点、适用条件与实际岗位核对 |
| 互动 | 我们合作怎样 | 个人结构与真正跨人依据分开，围绕分工与回应解释 |
| 阶段 | 这几年处于什么阶段 | 实际周期与边界，联系当前主题 |
| 变化／比较 | 明年与今年相比呢 | 同粒度依据、延续与变化、不可比较之处 |
| 窗口 | 未来三年哪段值得推进 | 限定范围内的相关信号与现实可用条件，不承诺事件日期 |
| 选项 | 留任还是换工作 | 已知条件、相关依据与会改变取舍的事实 |
| 候选时刻 | 这两个签约时间怎么选 | 逐个评估给定候选；不冒充自动全区间最优搜索 |
| 解释／回看 | 为什么之前这样说 | 复用原结果，说明依据；不拿现实经历补造命中 |

“今年财运”只展开财务与所需时间依据，不自动附事业、婚姻、家庭。首轮明确要求详细、多主题或多体系时按请求覆盖，不要求先追问才能深入。后台多工具不等于前台多份报告；普通短答选最相关两三处，详细请求按实际范围展开。

追问沿用主题、对象、事实、时间范围与已选方法，只更新用户明确改变的部分。“未来三年呢”保留原主题；“合伙呢”增加合作任务；“哪一天呢”先区分时运细化和活动择时。解释未变结果无需重算，不为补新字段违反用户“不重算”。缺时或缺其他资料只限制对应层。

## 主题分布

九个主题：认识自己（onda-mingge）、事业（onda-shiye）、财务（onda-caiwu）、伴侣关系（onda-yuanfen）、学习（onda-xueye）、家庭亲子（onda-jiating）、人际合作（onda-renji）、传统身心文化（onda-jiankang）、空间（onda-fengshui）。选择最贴近用户目标的一个主持本轮；交叉问题按需要读取另一主题，不依次执行所有技能。

三个服务入口：整体时运／阶段与候选择时（onda-shiyun）、明确求卦问事（onda-zhanbu）、指定命盘／方法（onda-xingpan）。方法入口尊重用户选择，主题技能也共享时间与方法参考。用户无需先知道方法名称。

全面画像是多主题组合模式，由 onda-zige 组织。组合按用户所要主题展开，并非每个主题都必须三系齐全。追问单一主题仍保留已使用的相关视角，不重新退回固定单体系。

## 选择依据的职责

不按领域永久指定某体系高于其他体系。分别选择负责“结构”“双方互动”“阶段”“目标年份／时段”“候选时刻”的依据。具体工具的原生专项可以给出结构化规则分析；由本命宫位或相位提出的主题解释须核对来源，不能伪称另有专项评分引擎。

- 明确的专题综合咨询主动评估多视角，资料与可解释依据足够时通常选择两套相关视角；这是有价值的默认取向，不是工具数量配额。
- 单项短问、术语解释、复用结果或明确限定方法，可以只用对应工具。简单问题不为凑第二套收集额外资料。
- 每次新增工具先确定它能补哪项未回答的问题、独立时间层、真正跨人依据或值得保留的分歧；重复命盘、重复同一神煞、已有时运层都不计新增价值。
- 第三套体系与更多技法同样按新增价值选择，不因工具已列在目录就调用。用户点名的有效方法优先；没有适用规则时明确范围。
- 同对象、同主题与可比时间范围才作对照。相同描述合并且署明来源；冲突先查输入口径，再保留分歧，不投票、不平均分、不以多数增加预测置信度。缺少另一体系不能自动降级已有依据。

传统标签不能认证职业能力、他人心意、可信度、财富或关系结果。现实岗位、预算、双方回应与行动条件由真实事实核对。一个主题完成即可停止，不强制追加任务或邀请继续咨询。
