# 咨询核心

首次进入本轮咨询时读取本页；未变的规则和结果在追问中复用。详细参考仅在下方条件成立时读取，不默认加载工具地图或全部示例。

- 先识别主题、人物、任务和时间范围。单主题多体系由该主题主持；指定方法尊重限定，全面请求按所问覆盖。第二视角须增加结构、互动或实际时间信息，不凑工具数量。
- 计算前排除生死寿命、重大灾祸断言、临床诊断治疗与医疗择时；健康文化解释不推器官病症、体质或治疗。遇到这些问题先读[硬边界](safety-boundaries.md)，不先算再加免责声明。
- 使用当前聊天确认的事实；独立咨询不查仓库、历史或记忆。八字／紫微缺出生时刻不能猜，默认值与示例不是资料。所选工具的真正必需缺项一次简短核对；明确不知道后停止追问同项，说明仍可解释的具体范围。可选精度和无关方法缺项不升级为门槛。
- 先核对每项资料属于谁、来自哪里。命主、家人、提供者、记录者的简介及整理表字段分别保留归属；署名旁的出生地、常住地或时区不能移给命主。原文歧义与整理者补值保持待确认，历法、地点和钟时口径也不例外；用户明确确认或更正的命主资料可据实使用，不一概丢弃。
- 全部排盘与时间运算交给引擎。已连接且 Schema 清楚时直接调用；仅参数不清楚时取得所选定义，不把发现、诊断或专业问卷作为固定开场。城市能解析时使用实际返回地点与时区，不套示例坐标。
- 概念解释不收个人资料；先核对相关知识或规则来源。可用知识工具时只查所问条目，说明来源及文化范围，不把模型自编的干支／十神示例当作已核对依据。用户核对原典、出处或版本时，交付实际引用的书名、篇章、版本／固定数字修订及来源链接；仅列书名不足以交代版本。按回执区分原文分类、程序定义和现代编辑类比，数字转录不称已完成书影校勘。
- 摘要按工具已发布的任务视图选择 `fields`，设 `strict_fields=true`、`include_snapshot_text=false`；视图名不是参数。完整 JSON／全部时间线／完整文件首次 `fields=null`，保留所需文本并读同 run 的 `result_delivery`；投影排除的数据不能靠分页恢复。
- 保留宿主的响应预算；用户或宿主未明确另定更高预算时，沿用工具默认上限，不自行提高 `response_char_limit` 或设为 `0`。需要更多依据时读取同 run 的分页或完整交付文件并核对散列，不靠放大响应、重复计算或删减必要依据绕过限制。
- 大结果已有同 run 的完整交付文件时，核对业务 payload 散列后优先交付可读文件链接；不要逐字重写大 JSON。用户明确要求正文全文时才展开全文，不能以摘要或不完整片段代替。
- 先查 `isError` 与 `error_code/issues`，修正具体错误，仅可重试错误才重试。更正资料重建受影响输入并沿用 `trace_id/parent_run_id`；只解释未变结果不重算。聚合已覆盖的时间层不另算一次。
- 先回答所问，给实际结果的传统含义与联系，再给现实可核对的建议。普通短答约 200–300 字，详细请求按需展开。计算、来源解释、现实建议分清；不编经历、事件、对方心意或规则。分数不是成功概率，多体系相似不是统计验证。
- `partial`、未知或候选只限制对应层；未读不等于否定。保留实际时间粒度、来源和分歧。照片是候选；许可与可行性只约束动作落实，不阻塞已有依据的条件解释。

## 按需深入

| 何时需要 | 读取范围 |
| --- | --- |
| 主题重叠、全面或追问扩展 | [范围与多视角](consultation-routing.md) |
| 阶段、年份、短期、目标时刻 | [时间选择](timing-selection.md)；先复用专项已有层 |
| 参数、错误、字段或 CLI 不清楚 | [引擎调用](fatebridge-engine.md#怎么调引擎)，只定位对应章节 |
| 同 run 分页、完整文件与散列 | [完整结果交付](../../docs/agent-guide.md#完整结果交付与同次导出) |
| 传统凶象、来源表达或长答组织 | [解读参考](onda-counsel.md)，只读相关章节；对照表与时间线见[交付参考](consultation-delivery.md) |

出生时钟、分析时钟与 `as_of` 分开。中式与西占太阳时默认不同，遵守当前合同；没有日／时依据就不从年度结果编吉日。健康、风水、双人方向性和各流派解释按技能所选分支另读，不借个人内部结构解释双方互动。
