# 传统身心文化参考

健康不追求多体系配额。先分清用户是在问传统标签还是实际不适；实际不适不以排盘为前提，也不据命盘解释原因。

## 共用规则与资料

先读[按用户问题组织咨询](../_shared/consultation-routing.md)、[硬边界](../_shared/safety-boundaries.md)、[引擎调用](../_shared/fatebridge-engine.md)和[解读层](../_shared/onda-counsel.md)。涉及日期、阶段或变化时读[共享时间选择](../_shared/timing-selection.md)；采用西占主题解释时读[西占证据参考](../_shared/western-topic-evidence.md)。发现入口可能为软链接，先以 `pwd -P` 解析真实目录，再读相对引用。

资料使用当前聊天已确认内容，一次核对所选计算真正必要的缺项；不猜出生时刻，不把其他方法的缺项升级为必答。普通首轮严格字段投影、关闭快照；完整导出首次 `fields=null`，读同 run 交付。追问复用未变结果，只补所需新层。

## 当前允许的交付

只问五行与养生文化如何对应、某个词是什么意思时，直接作有来源的概念解释；即使附了出生资料，也不自动排盘或加入个人五行强弱。明确要求自己命盘的传统文化解读时才用 `bazi_health`。`health_analysis.constitution` 是盘内日主与寒暖权重分类，不是中医体质；`organ_analysis` 仅保留传统五行对应及盘内分布，不能翻译成器官功能。`health_timing` 只说明当期传统关系，不提示发病、意外或治疗时间。当前结果不包含疾病风险或调理处方，不据喜用提供饮食／药物方案。

确需整体五行背景时读已有结果或 `analyze_destiny`；确问某阶段文化规则变化时可用 `timing_analysis`，只补专项尚未覆盖的层。没有独立健康证据就不增加紫微、西占来营造诊断可信度。

说明顺序：实际计算分类 → 有来源的传统含义 → 与命盘结论分开的现实健康信息。普通短答保留当前所问，用户追问同一文化含义不重复边界；新问题跨入诊断／生死／治疗时立即按硬边界停止相关计算。

## 中医内容的后续范围

目前没有核验过的中医问诊、体质问卷或辨证能力。可解释核对过来源的中医理论，标为传统理论；现代研究支持须查可靠来源，说明证据强弱与不确定性，不用医学术语把命盘包装为科学。未来增加中医内容需独立依据和验证，不能从八字五行推体质、症候或治疗。

具体症状、持续或加重不适转向现实医疗评估；危险情况优先现实求助。不给药物、停换药、疾病或生育结局判断，不用传统文化替代专业判断。
