# 全面画像与多主题组合

这是多主题组合入口，多视角能力由所有主题共享。用户只问一项性格、事业或关系时进入对应主题，即使明确要三体系，也不自动扩成全人生。

## 共用规则与资料

先读[按用户问题组织咨询](../_shared/consultation-routing.md)、[硬边界](../_shared/safety-boundaries.md)、[引擎调用](../_shared/fatebridge-engine.md)和[解读层](../_shared/onda-counsel.md)。涉及日期、阶段或变化时读[共享时间选择](../_shared/timing-selection.md)；采用西占主题解释时读[西占证据参考](../_shared/western-topic-evidence.md)。发现入口可能为软链接，先以 `pwd -P` 解析真实目录，再读相对引用。

资料使用当前聊天已确认内容，一次核对所选计算真正必要的缺项；不猜出生时刻，不把其他方法的缺项升级为必答。普通首轮严格字段投影、关闭快照；完整导出首次 `fields=null`，读同 run 交付。追问复用未变结果，只补所需新层。

## 组织范围

用户已明确关心主题就直接按其范围组织，不另设完整问卷。宽泛的全面画像可覆盖自我特点、工作、关系与家庭等相关主题；健康、财务细论和具体时运只在请求包含时扩展。通常约1500–2500字，简版按要求压缩，不以固定字数截断明确范围。

主盘候选为 `analyze_destiny`、`ziwei_birth`、`astro_chart`。明确要求三体系且资料足够时三者参与；其他综合请求按新增价值和已确认偏好选相关视角，不强求每一主题三家都有意见。八字不与原始盘重复计算；缺失体系保留缺失，不能擅填生时。

## 按主题交付与继续

按“这个主题的特点／实际依据／共同与不同处／现实可核对什么”整合，不依次复述工具报告。八字格局读取实际结构与判断依据，紫微命身宫位置之外须读星曜四化，西占不只用太阳。分歧先核对时钟、时区与模型，再分别说明；没有现实经历支持时不编内在张力。

深入某主题时读取对应主题技能，仅补未覆盖的专项；已有相关视角仍保留，不因转到事业或关系就退回固定单体系。追问“未来三年”连接共享时间选择；原有静态盘与大限列表不是已算动态运限。只解释未变结果无需重算。

完整导出从各所选工具原 run 交付，按实际 business payload 核对散列；摘要投影排除的数据不靠分页补全，不为了完整重排。所有主题先遵守硬边界，全面并不包含生死、诊断或治疗预测。
