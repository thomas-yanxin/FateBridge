# 事业与工作

先回答这次的工作问题，分清长期工作方式、当前阶段、目标年份与实际选项。普通问题保持聚焦；用户要求综合或深入时主动评估多视角，不把多体系留给全面画像独占。

## 共用规则与资料

先读[按用户问题组织咨询](../_shared/consultation-routing.md)、[硬边界](../_shared/safety-boundaries.md)、[引擎调用](../_shared/fatebridge-engine.md)和[解读层](../_shared/onda-counsel.md)。涉及日期、阶段或变化时读[共享时间选择](../_shared/timing-selection.md)；采用西占主题解释时读[西占证据参考](../_shared/western-topic-evidence.md)。发现入口可能为软链接，先以 `pwd -P` 解析真实目录，再读相对引用。

资料使用当前聊天已确认内容，一次核对所选计算真正必要的缺项；不猜出生时刻，不把其他方法的缺项升级为必答。普通首轮严格字段投影、关闭快照；完整导出首次 `fields=null`，读同 run 交付。追问复用未变结果，只补所需新层。

## 选择能改变理解的依据

## 读结果与回答

事业专项读 `career_analysis.career_structure/entrepreneurship/career_timing/timing_context` 及实际主导十神等；方向细问才展开行业字段。八字总体结构确有需要时用 `analyze_destiny`，不与专项重复讲同一依据。紫微读实际宫位星曜与四化；西占只用实际相关配置及查证来源。

用户问年度变化而 `career_analysis.career_timing.timing_signals` 为空时，按共享时间选择的“专项时间信号为空时”处理：该专项没有命中，不等于其他可用时间视角也不能回答。只补一项能够提供相关阶段或目标年份依据的视角，不以空列表结束整题，也不把它解释为没有机会。

先说明有依据的倾向与条件，再给两三处相关差异和一项可核对的现实安排。用户未提供岗位、收入或创业经历时用条件句，不补经历。明年追问保留事业主题和原有相关视角，新增目标时段；短期问题不由年级依据编月份。具体择时使用给定候选的 `astro_election`，不据此替用户决定辞职。
