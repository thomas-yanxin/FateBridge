# 玄空历史宅盘：规则来源与资料核对

[场景技能](../SKILL.md) · [三端调用与验证](../../../docs/fengshui-xuankong.md) · [有限解释](xuankong-interpretation.md)

`fengshui_xuankong_natal` 计算所选中州派版本的运／山／向数字盘与兼向替星。历史宅盘与年星独立；查询年份变化不改变住宅历史定运。

历史事件与定运区间的交节记录还保留实际星历模型和时间政策；跨界及秒级精度问题参见[时间边界](calendar-boundaries.md)，不将未来UTC假设当成已观测交节秒。

## 规则核实和版本选择

本次锁定一套明确的中州派规则，新增历史影印替星全表与王亭之原书数字盘核对，不能把结果称为所有玄空门派统一结论，也不是《沈氏玄空学》原版的逐页复刻。规则版本为 `xuankong_zhongzhou_v1@1.4.0`；所有起盘计算交给 FateBridge，以下资料用于核对来源、输入和解释范围。

1.1.0 返回 `chart/candidates.*.structure`，说明历史宅运当运数的山／向星落宫、到山到向／上山下水／双星到坐／双星到向及逐宫合十。它是历史数字结构，不能据此直接称当前旺局、布水有效或保证现实结果。来源审计与未解决转录分歧见[专业深度审计](../../../docs/fengshui.md)。

## 定运输入和不确定性

`period` 必须含 `basis`、非空白 `evidence`，并且三选一：

- `period_number`：已确认1–9运；不根据今天补造年代、周期或交节日期。
- `effective_event_year`：1800–2199，已确认交节后的有效事件年。不能把“2024某月不详”伪装成已确认的立春后年份。
- `event_at`：1801–2199，含时区的ISO时刻；`timezone_name` 默认 `Asia/Shanghai`。显示事件时刻所属的历史20年区间，区间不是宅盘到期日。

`basis` 为 `construction_completion`、`first_occupancy`、`confirmed_major_renovation` 或 `expert_confirmed`。专家确认要求显式 `period_number`。大修另须 `qualifies_for_period_reset=true`；这表示调用方已经确认条件，算法本身不鉴定重建资格。粉刷、搬家或当前年换运不会自动更新历史盘。

`period_context.timing`记录历史区间首尾和事件年交节的实际提供者、模型及时间政策。选定模型无法求根时返回503错误，不返回近似宅运或通过确认年份绕过缺失的有效区间。数值保护区内的候选只反映操作政策，不认证物理误差。

实际返回`jpl_de440`时，按端点的`ephemeris_model`区分原打包模型与`fatebridge_de440_solar_historical_v1`。后者补足完整宅运区间所需的1784–2204范围，不扩大公开请求年份；来源与验收见[历史历法覆盖](../../../docs/fengshui.md)。数值模型在交节附近保留候选，也会要求确认，不能一概解释成线性近似回退。依据本次模型、保护原因与候选解读；1秒TT软件对照通过不认证绝对UTC交节秒或现实吉凶。

年份与宅运的状态分别解释：保护区内 `effective_event_year=null`，`candidate_effective_event_years` 保留年份候选，暂取年仅供追踪。同运候选可以确定宅运而不确认年份；跨运的 `timing.candidate_period_intervals` 保留候选历史窗口，不能把其中一个当作唯一有效期。快照和固定释义沿用同次计算记录，详见[有效年分层](../../../docs/fengshui.md)。

缺少宅向或定运资料返回 `partial` 和逐项 `missing_inputs`；仅有坐山卦不能推出确定的二十四山。角度要求磁北，真北输入须在调用前完成用户确认的转换；[地磁参考](geomagnetic-reference.md)只提供待复测换算候选，不自动满足该确认条件；未知规则ID、越界数值、无时区时刻、冲突事件选择、未知字段均为校验错误。

### 角度边界与候选

宅向测量误差使用共享 `house.bearing_uncertainty_degrees`，范围0–7.5°。未提供时沿用点方位计算，不表示已确认现场误差为零。范围跨多个角区时计算所有候选，不只取两端；恰在边界也保留单侧极限候选。候选由山向和下／替模式去重；只有一个选择时 `chart` 有值、状态 `complete`，多个选择时 `chart=null`、状态 `partial`，候选盘不代表多栋住宅。合参同一宅向的误差同时影响八宅，详见[共享宅向误差](house-bearing-uncertainty.md)。

1.1.1按输入浮点数的精确有理数值比较区间端点，不让浮点加减把未触线的端点舍入到边界。每盘的 `bearing_support.regions` 保留全部支持角区及对应理由；同一盘可以同时由中央九度和同宫同阴阳兼向支持，此时 `mode_reason` 标为多角区，不能只解释第一段。端点字符串如 `9/2` 表示4.5°；坐标围绕已归一宅向展开，跨北的负值加360°即通常方位。角区及闭端点来自所选规则和保守工程约定，既不证明现场角度测得准，也不表示候选概率或吉凶大小。

可运行的完整请求与逐宫数字验证见[玄空宅盘工程说明](../../../docs/fengshui-xuankong.md#独立验证与复现)。

例如子向354°是子兼壬，采用替卦；子向6°是同宫同阴阳的子兼癸，仍下卦。7.5°在子／癸山界，返回两种山向候选；355.5°在子兼壬的下／替分界，返回两种起法。4.5°双侧都仍下卦，可得到唯一选择。
