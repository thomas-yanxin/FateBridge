# 反伏数式与父母三般卦

所选版本 `xuankong_zhongzhou_v1@1.4.0` 对既有宅盘增加 `chart/candidates.*.structure.classical_patterns`。所有比较使用同一候选的原始运、山、向数字，历史宅运与当前评价运分开；不据这些名称给出事件、灾祸或财富保证。

## 原典与署名语境

- X10：[历史影印中册](https://www.vr-d.com/pdf-file/%E9%A3%8E%E6%B0%B4%2F%E6%B2%89%E6%B0%8F%E7%8E%84%E7%A9%BA_%E4%B8%AD.pdf)，PDF7–8／印刷156–159，《沈氏玄空学》卷二“论反吟伏吟”。沈氏答问的固定地盘定义、五运特例及祖绵所记另一种运盘比较分别保留。
- X11：[历史影印上册](https://vr-d.com/pdf-file/%E9%A3%8E%E6%B0%B4/%E6%B2%89%E6%B0%8F%E7%8E%84%E7%A9%BA_%E4%B8%8A.pdf)，PDF66／印刷132–133核对父母组定义，PDF71／印刷143核对署名按语的全局16局。

精确底本印记未认证。新取得的中册原文件散列、选页和手工核对列表保存在参考夹具（本地数据：`../../../tests/data/fengshui_patterns_v1/reference.json`）。整理本PDF115将五运列表中的“坤艮”排成“坤申”；历史影印PDF7支持“坤艮”。两个原文件不修改，差异另行登记，不用程序输出替代校勘。

## 三种比较参考不能混合

`ground_comparison.reference_numbers` 是固定洛书地盘，含中五；它不是住宅某一运的运盘。每侧山／向盘分别返回：

| 字段 | 数字含义 |
| --- | --- |
| `same_ground_directions` | 本侧星数等于本宫固定地盘数的宫位 |
| `opposite_ground_directions` | 本侧星数与本宫固定数合十的外宫；中宫没有空间上的对宫，故排除中宫 |
| `whole_ground_repeat` | 九个数全部等于固定地盘，可称本分支的全盘伏吟数式 |
| `whole_ground_reverse` | 九个数全部为固定地盘的对数，可称本分支的全盘反吟数式；中心5只是数值条件 |
| `period_plate_same_directions` | 本侧星数等于本宅历史运盘数的宫位 |
| `whole_period_plate_same` | 本侧九数全部等于历史运盘，不能替代固定地盘比较 |

原书祖绵按语举七运卯山酉向的向星八到乾，与运盘乾八同数；固定地盘乾为六。不能把这个局部运盘重叠改写成“八回艮本宫”，也不能因全盘布尔值为false而抹掉局部匹配。可读快照同时保留全盘状态与逐项匹配宫位。

## 卷二所列局名另作对应

`volume_two_named_refrain` 只对应卷二所列下卦案例。程序依据全盘固定同数、或山星在坐宫及向星在向宫各与本宫固定数合十的数字关系，核对原书的完整列举，不把所有全盘反吟都纳入此名单。

| 宅运 | 原书列举的互为山向 |
| --- | --- |
| 一、九 | 壬丙、丙壬 |
| 二、八 | 艮坤、坤艮、寅申、申寅 |
| 三、七 | 甲庚、庚甲 |
| 四、六 | 乾巽、巽乾、巳亥、亥巳 |
| 五 | 艮坤、坤艮、寅申、申寅 |

共28个运／山向案例。五运这四局没有外宫五入中，也不满足整盘对数；原文在此使用局部对宫语境，不能拿“五入中”公式否定原文列表。一运子山午向虽有向星全盘对数，也不能直接套进这段名单，更不能自动断其现实效果。

替卦继续计算原始数字关系，但 `applicable=false`、`numeric_match=null`，表示不把仅核对过的下卦局名外推给它；null不是“该候选不存在数式”或“不利”。局部、全盘、不同参考盘及不同作者的用语分别解释。

## 父母三般卦

`parental_triples` 逐宫检查本宅运／山／向三个数是否恰为 `{1,4,7}`、`{2,5,8}` 或 `{3,6,9}` 中的一整组，必须三个数各不相同。单纯余数相同、重复星数或三个连续数不能替代。九宫全部满足才是本分支的全局数字条件；逐宫原数及对应组均返回。

原书所列全局下卦共16局：二、五、八运的艮坤、坤艮、寅申、申寅；四、六运的丑未、未丑。216张下卦盘的16个正例和200个其余案例逐一核对。替卦上的同类数学关系可以显示，但不宣称它属于这16个下卦原例。

父母三般卦与普通三般卦、七星打劫、全局合十分别处理。普通连续组的传本文字仍有差异，本分支不把它补成统一循环，也不据父母组匹配推定打劫、外局、当下旺衰或动作已经合格。

首轮按需投影选定 `structure.classical_patterns` 及来源。若返回 `result_delivery`，读取同一运行的完整结果，不能把尚未读取的部分当成false，也不为全文重算。工程验收见[深度记录](../../../docs/fengshui.md)。

## 同宫合十与作者用语的外部核对

`structure.combination_of_ten` 保留历史运、山、向三盘的三组两两比较。每组逐宫显示两数之和，九宫全为十才是该组的全盘同宫合十；某组未全盘成立不排除其局部，也不替其他两组作结论。异宫对角合十没有被这三个布尔值覆盖。

另用[王亭之上卷原书](https://vr-d.com/pdf-file/%E9%A3%8E%E6%B0%B4%2F%E4%B8%AD%E5%B7%9E%E6%B4%BE%E7%8E%84%E7%A9%BA%E5%AD%A6_%E4%B8%8A%E5%86%8C_%E7%8E%8B%E4%BA%AD%E4%B9%8B.pdf)印刷40–41／PDF42–43的六张正向例盘独立核对162个星数，包括山运合十、向运合十、向星固定地盘伏吟、山星固定地盘反吟及两张147／258／369全宫例。数字及限定标题见转录夹具（本地数据：`../../../tests/data/fengshui_structure_reading_v1/printed-charts.json`）。这是原书的外部数字例证；其吉凶与应期断语未因此进入计算规则，也不把既有王氏时令版本的来源范围扩大成整本王氏解释。

七运乙山辛向是重要反例：王氏标作山星反吟，其山星与固定地盘全盘对数成立；但沈氏卷二那段有限下卦名单的数字对应为false。两种结果并存，不能把后者改说成“原典一概没有反吟”。这项差别属于作者及段落作用域，不据此裁定某位作者全书有误。

[固定释义1.1.0](calculation-reading.md)逐候选解释上述已有数式，仍保留普通三般用法、七星打劫、完整现场及现实预测的未覆盖状态。早先1.0.0运行可按原合同核验，但不追授新增覆盖。

## 山星与对宫向星的有向配对

规则1.4.0增加 `structure.classical_patterns.opposite_star_comparison`，由领域服务计算。固定释义1.2.0读取已算数，不自行重新排盘。它与 `combination_of_ten` 的同宫求和是不同的比较：山星在N配向星在S，与山星在S配向星在N是两项不同配对，必须保留八项，不能只去重成四条轴线。

原书PDF43／印刷41的五运申山寅向例明确使用山向对角合十。按印刷数字，N山7配S向3、S山6配N向4等八项均为十；同一候选的山向同宫并非全为十。另一个七运乙山辛向例，固定地盘山星反吟数式成立，但这一山向对宫合十条件不成立；因此该条数式不是所有反吟定义的总判据。来源独立登记为X12，作者王亭之、固定文件散列及范围随规则返回，精确版次与全本仍未认证。

`pairs`以山星所在宫为索引，逐项保留山星宫、向星宫、两数、数和与布尔条件；`all_eight_sum_to_ten`只合取这八项。`center_numeric_pair`单列中宫山向数和，两个空间属性均为false：没有空间对宫，不参加八宫合取。局部不匹配与全八宫条件分别呈现，不挑选较有利的方向。

替卦仍可显示同样的数学关系，但不继承所引原书下卦例的吉凶、应期或完整反吟用法。两例的16项有向配对及两个中宫数字，交叉核对此前独立转录的印刷星数，见配对参考（本地数据：`../../../tests/data/fengshui_opposite_v1/reference.json`）；这些是书中数式核验，不是真实住宅预测案例。

解释对子层时同时保留历史定运、方位、候选ID及模式；可读取 `layers.xuankong_natal.period_context`、`orientation_context`、`candidates`，连同 `rulesets`／`rule_trace`，或读取已绑定完整父候选的 `calculation_reading`。只有唯一盘时才用 `chart` 路径；多个候选不挑其中一组代替全部。只摘出一项布尔条件不能作为完整解释或原运行核验。
