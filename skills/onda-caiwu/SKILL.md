# 财务与资源

先分清个人收入、支出、积累还是共同资金。财务不等于事业，不能每次谈钱都转成职业报告。

## 共用规则与资料

先读[按用户问题组织咨询](../_shared/consultation-routing.md)、[硬边界](../_shared/safety-boundaries.md)、[引擎调用](../_shared/fatebridge-engine.md)和[解读层](../_shared/onda-counsel.md)。涉及日期、阶段或变化时读[共享时间选择](../_shared/timing-selection.md)；采用西占主题解释时读[西占证据参考](../_shared/western-topic-evidence.md)。发现入口可能为软链接，先以 `pwd -P` 解析真实目录，再读相对引用。

资料使用当前聊天已确认内容，一次核对所选计算真正必要的缺项；不猜出生时刻，不把其他方法的缺项升级为必答。普通首轮严格字段投影、关闭快照；完整导出首次 `fields=null`，读同 run 交付。追问复用未变结果，只补所需新层。

## 按问题选择依据

| 用户任务 | 候选依据 | 如何回答 |
| --- | --- | --- |
| 收入与用钱方式 | `bazi_wealth`；`ziwei_birth` 财帛等相关宫位；`astro_chart` 财务相关配置 | 说明不同传统视角描述的方式与条件，联系用户已知预算／收入来源 |
| 今年／明年／未来几年 | 专项已有 `timing_context`；必要时 `timing_analysis`、`ziwei_horoscope`、`western_timing_analysis` 或 `firdaria` | 长期阶段与目标年份分开，按相同口径比较；不预测回款日期／收益数额 |
| 共同资金／合伙开支 | 本主题的财务安排＋人际合作的真实双人问题 | 只补用户关心的责任、分配或决策，不由合盘认定对方可信 |
| 具体投资／财务决策 | 用户提供的现实条件 | 文化解读与现实风险核对分开，不推荐标的、买卖点或保证获利 |

## 读取结果与范围

读 `wealth_analysis.wealth_stars/wealth_style/wealth_risk/wealth_timing/timing_context`；名称中的 risk 是本工具传统规则标签，不是现实损失概率。综合问题主动选择有新增价值的第二视角，尊重用户限定体系；不为凑数重复八字总体盘。

## 交付与后续

先回答所问时段与事项，再讲实际返回的区别，最后按已知事实选一个预算、回款或资金责任核对。没有现实财务事实时不编预算金额，不将“财星受劫”等术语解释成亏损已发生。用户只问今年财运就不附婚恋、家庭或完整事业分析。
