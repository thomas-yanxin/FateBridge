# 原典历法题注的约束核对

本次新增独立审计脚本 `scripts/audit_bazi_source_calendar_captions.py`，检查原典中的相对节令、纪年题注和字面四柱是否在明确口径下相容。不调用生产历法或强弱计算，不重建出生日期，不据人物经历更改标签。

**后续校读更正（2026-10-25）：** 原尺寸裁剪与 CADAL 高清扫描均显示题注为“乾隆三十八年”，此前的“二十八”是读者转录错误。规范数据现已更正；下文的第二项是对首次错误录入的历史诊断，不能继续作为原书纪年错误的证据。首次输入、失败报告与判据仍保留，详见[扫描复核与修订](bazi-source-rescan-collation.md)。以下验证数字均属于当时冻结副本。

核对资料与范围在编写检查器前冻结于 `docs/validation/bazi-source-calendar-caption-constraints-v1/protocol-first.json`。范围为已收集的全部 1,380 条陈述和 558 个命例；在这套转录中选出 6 条含相对交节日数的陈述、1 个含年号题注的命例。此选择不是独立 OCR，也不证明原书没有其他隐含日期。

## 核对依据与限制

采用的按节建月口径来自同册第 13—14 页月建及节气表、第 29 页推月法，以及第 30—31 页跨立春示例；这是李雨田增补层的明确口径，不能擅自归为任氏无条件认可。香港天文台的[六十干支表](https://www.hko.gov.hk/tc/gts/time/stemsandbranches.htm)提供独立的循环表，[二十四节气说明](https://www.hko.gov.hk/tc/gts/time/24solarterms.htm)作为节气资料保存。没有拿民用农历月份说明代替八字节月边界。

纪年参照冻结了中研院史语所历史文物陈列馆的四份馆藏目录：[乾隆二十六年辛巳](https://museum.sinica.edu.tw/collection/17/item/1279/)、[二十八年癸未](https://museum.sinica.edu.tw/collection/17/item/188/)、[三十六年辛卯](https://museum.sinica.edu.tw/collection/17/item/610/)、[四十四年己亥](https://museum.sinica.edu.tw/collection/17/item/609/)。四个纪年锚点按独立六十循环相互一致；这只检查题注约束，不认证命例的真实出生年月日。

本轮没有修改生产历法、强弱内核、知识词条或共享接口。因此不新增生产 REST／MCP／CLI 部署通过声明；测试中的既有知识接口一致性检查只用于防止此次原典资料变动破坏原有行为。资料和图版仍为单读者核对，未获得独立专家认证。
