# 身印回执一致性：本地计算契约修复

本轮修复接收、投影输出时的矛盾检查，不改变旺衰算法、原典标签或权重。408条研究记录的原有实际计算中，3条记录、2个不同命式的身印工程总量为零，均已正确返回占比未定义；此前输出模型却接受零分母的伪造占比、与同次分量相反的浮点占比，以及拼入另一计算方法的回执。不能把这次接收端修复记成3个新算对的原典案例。

检查仅在必要事实都已提供时触发：精确身印总量为零不能有确定占比；浮点占比和比较使用其声明的同一未舍入或旧舍入基准；身印角色、精确分量、旺衰方法及等级须与同一证据链中已提供的回执一致。部分字段缺失仍保持未知。精确有理数与浮点临界值之间的合法差异继续保留，不增设容差，不强行使两种结果相等。

原19例的源标签、命式、月令司令未定和原典身印力度未裁决均保留，17例旺衰分歧仍未解决。既有逐例材料见[原19例条件核查](bazi-original19-source-conditions.md)，月令序位与司令先后不能直接转成根量系数，通关候选也不等于原典条件已全部满足。

新增19例解释验收继续使用已冻结的独立方案与首次结果规则，未经单独授权不启动新增模型调用。旧11题的首次失败、原8192字符且不分页的门槛与后续同次结果分页证据分别保留；分页可完成结果交付，不能把旧门槛改判通过。现实预测数据尚缺，真实效度继续标为 `not_tested`，原典整体验收继续未通过。
