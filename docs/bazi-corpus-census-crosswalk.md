# 旧旺衰语料与全书校读的来源对照

后续进展见[八条来源差异复核](bazi-eight-input-source-review.md)：两条原注公式已在当前全书视图恢复明确位置，六条旧错录仍保留原件，待单独应用当前输入覆盖层。下文保留本轮首次对照的全部数量和未对应状态，没有回写历史结果。原维护命令绑定修订前的审计源码，当前源码变化后会按哈希拒绝运行；其97份冻结输入归档仍可复现原结果。

本轮新增来源对照审计器，把全部367条旧登记记录与558个全书命例按四柱、底本和PDF页码连接，保留1,380条陈述及原26处分歧。没有重算旺衰，没有把全书记录改成新的答案集，也没有减少原失败数。

两套资料的标注口径需要先分清。旧登记有123条明确三档标签，包含《子平真诠》、网络转录和不同研究阶段的材料；全书校读针对1947年李雨田校订本《滴天髓阐微》，对“旺”等词到工程“强”档的映射更谨慎，只有26条明确标签。这两个数字不能直接相减，也不能据此认定哪一套已经正确。全书26条明确标注与历史26处分歧也不是同一集合。

## 全部记录的对照结果

审计器不读取模型的`actual_strength`、`matches`或`assessment`来选择对应项或比较标注。四柱完全一致时保留全部候选；确认同一底本还须有直接书源元数据中的整书哈希，且命例自身的PDF页码相交。相同页码、相似锚句或一个字接近均不足以认定同源。标注比较只是待复核事项。

| 旧记录的来源对应状态 | 条数 |
| --- | ---: |
| 同一底本、命例页码和四柱唯一对应 | 159 |
| 直接书源哈希指向另一部《子平真诠》 | 59 |
| 直接书源元数据不足以确认底本 | 141 |
| 已确认同底本，但未找到四柱完全相同的候选 | 8 |

141条未确认记录不等于141条错录。一些文档只保存了章节文件哈希或来源名称；本轮没有凭名称补认底本，也没有丢弃这些记录。

在159条唯一对应记录中，8条双方明确标签相同，101条双方都没有明确标签，50条旧记录有明确标签而全书记录未给唯一三档。这50条没有变成通过、失败或旧标注勘误。例如旧`DTCW1947-TG-01`与全书`MAIN-C143`均保留“日主弱中變旺”，全书记录却把“旺→工程强档”保留为待审映射；这属于标注政策差异，不能说原文没有旺衰表述，也不能据此删除原模型的失败。

原26处分歧全部按原对象保留，其中有《子平真诠》的命例，不能仅用《滴天髓》的校读覆盖。旧标签、原四柱、原模型结果及不同书源的限制仍各自有效，等待相应底本和语义复核。
