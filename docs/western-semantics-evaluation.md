可以只做当前授权范围内的准备：

```bash
uv run --locked --extra dev python scripts/evaluate_agent.py \
  --prepare-only --snapshot-profile runtime \
  --cases-file tests/fixtures/agent_behavior/western_semantic_cases_v1.json \
  --timeout 900 --output /tmp/fatebridge-western-semantic-preparation
```

输出目录须尚不存在。准备阶段冻结源码、判据和真实MCP参照，`model_invocations=0`、`semantic_acceptance=not_run`。参照run不是未来模型读取的证据；未来审阅须用实际模型捕获日志。新验收说明、完整判据与历史成绩均不进入被测模型目录，公开运行时技能／计算文档正常保留。

启动真实模型会创建八个独立Codex会话，使用已登录账号额度、默认模型、只读隔离目录、真实stdio MCP，最长每例900秒。须先取得当前会话所要求的新增代理授权；准备产物提供具体执行命令供审阅，不读取或传递认证密钥。模型运行、人工语义审阅、原典完整验收和现实预测四者分开报告。
