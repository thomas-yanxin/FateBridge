# 八字藏干根预算的单位边界修复

本轮修复既定工程规则中的一处实际算术错误：根预算恰为1时，浮点和略小于1，导致财根或官杀根的结构条件漏判。系数、单位门槛、关系成立条件、原典标签和既有采用门槛均未改变。这里的预算单位1不是古籍定值，也不代表根的实际有效力量。

首次方案（本地数据：`../tests/fixtures/bazi_root_predicate_v1/protocol.json`）在未发现具体反例时冻结，沿用原518400组固定组合、顺序和输入散列。独立参考使用此前冻结的藏干字表、几何份额和十进制系数，以分数重建实际藏干预算；关系事件和根类仍是给定条件，不获独立原典认证。

完整首次扫描发现1141组单位比较假阴性，全部是精确值等于1、旧浮点值小于1。215组影响财官结构字段，其中109组影响官杀有根透干数、106组影响财根标记；只有3组改变最终工程结构档。24891组输入至少有一个精确单位边界。既有3/4根保留比较未发现不一致，保持不动。

修复只让原有财官结构条件使用同次已经精确重建的藏干根预算。原浮点根量、能量、数值份额均保留；没有增加藏干，没有修改刑冲合会处理，也没有启用此前被拒绝的官杀优势或其他力量候选。新回执 `threshold_arithmetic.physical_root_unit_comparison` 同列精确预算、单位比较、旧浮点标记、旧与新财官结构字段，明确 `effective_classical_root_force=not_adjudicated`。

当前公开v7及现行政策敏感性入口采用该精确比较；历史研究模式继续保留其原实现和成绩，不据此重评已拒绝的候选。

输出模型拒绝修改单位门槛、负预算、精确值与标记冲突、财官透干计数冲突，以及把预算改称原典有效根力。部分字段投影仍可交付。确定性说明仅在财官结构字段实际改变时出现，直接读取这份回执，不重算另一张盘，也不将候选路径解释为有效通关。
