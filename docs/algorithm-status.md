# 当前算法状态与未验收范围

[文档中心](README.md) · [工具与覆盖范围](algorithm-coverage.md) · [数值验收](precision-acceptance.md) · [源码职责](algorithm-inventory.md)

本页回答各体系目前采用什么计算路径，以及哪些差异仍限制使用。调用前从[生成合同](contracts/README.md)核对当前公开字段；收到结果后结合实际后端、时标和规则版本读取[计算证据](computation-evidence.md)。代表请求成功只覆盖所运行的请求和接口。算法验收需要独立参考、明确的输入域、预定的门槛以及完整的失败记录。早期三端比较中印占 D9／D10 盘内度数存在尾数差异，比较期间实现有改动，不能用于同版一致性验收。后续固定版本的定向比较只覆盖所测印占请求与选项。

## 钟时、星历与几何

| 主题 | 当前路径与验证边界 |
| --- | --- |
| 民用时刻 | 重复钟时按已确认的偏移消歧；无定义偏移留下缺项或明确拒绝。名义太阳钟、民用时刻和物理历元分别保留，节气成员按真正的源点比较。见[历法边界](calendar-boundary-audit.md)。 |
| UTC、TT 与 UT1 | 以整数日历、微秒和实际原子偏移求精确点，再按目标格式舍入。1960–1971 的负调整可使 UTC 标签无反像。原 65,536 个现代控制的标量与 SOFA 合成结果相同，但都劣于 SOFA 原两部表示；这是原标量门槛的失败。现行[保留 TT 主点](precision-acceptance.md#retained-primary-tt)另验两部适配；[C04](precision-acceptance.md#modern-c04-eop-round40)的连续 TT 插值及地面框架独立比较，旧线性模型和实测时钟各有适用范围。 |
| 太阳交节 | 选用核实的文件源，或具名内置 DE441；无合法求根来源时返回错误。原版 Swiss Moshier 的 96 点中 12 项超过 1 秒，退役修订模型在更广队列分别有 15 项和 21 项超差。内置 DE441 的对照适用于所测源和输入域。见[太阳后端](solar-backends.md)。 |
| 地平事件 | 自动路径采用 DE440 原始记录和域外有界 DE441，印度太阳日、西占行星时共用有向事件序列。固定自动路径的 14,459 事件满足参考的 1 毫秒 TT／UT1 线。显式原生 Moshier 的原近极 53 根仅 23 根满足该线；局部端点精化得到 34 根，属于诊断。显式原生 JPL 原队列的 364 项时间失败仍保留。见[太阳地平线参考](../tests/data/solar_horizon_v1/README.md)和[近极 Moshier 对照](precision-acceptance.md#polar-moshier-complete-sequence-round56)。 |
| 源记录与日速 | 按实际两部 TDB 选择记录和精确局部横坐标，舍入在递推、单位转换和地月组合后进行。原 DE440 域／记录差异、原生近太阳水星约 0.892 角秒差、Swiss 月球约 0.002607 角秒／来源日日速超差和土星差分步长反例各按原门槛保留。完整 DE441 月球参考原有两项缺证，其中一项后来补证，AD 9999 仍未验收。见[分项精度验收](precision-acceptance.md)。 |
| 宫轴、落宫与地平 | 回退真黄道、真赤道、真交角及恒星时共享同一 TT／UT1 和来源框架。零黄纬投影与球面假设各有前提；原生回传按所选宫制核对，极区未定义分支保留错误。见[宫位与四轴](western-astrology.md#宫位与四轴的独立核验)。 |

| 奇门 | 所选置闰明例以日期序差八表达含首尾九日。固定样本通过当前年表的规则对照；夏至锚异法、前置十二月三日差仍需区分。原独立排盘 38 组中 8 组定局不同，原表两格与九项来源裁定仍未完成。见[奇门规则和来源](qimen-depth-audit.md)。 |

## 现实与临床效度

传统分类、工程指数、量表计分、文本出处和数值复现各有验证对象。工程分数与传统健康类象没有临床诊断、风险预测或治疗效度证据。IPIP 的条目和正反计分属于量表计算，输出无临床诊断或常模百分位。现实预测需要独立观测、事前登记、比较基线与足够覆盖；现有计算及回放未建立这项效度。见[现实预测的验证](prediction-validation.md#可证伪的现实预测评估)与[咨询边界](interpretation/shared/safety-boundaries.md)。

[工具结果未决项](unresolved-calculations.md)说明如何解释缺项和待裁条件。原始工作日志、比对明细及退役版本按[仓库维护](repository-maintenance.md)保存于仓库外。旧批次若有失败、缺输入或未满足运行来源门槛，后来的专项复验仅更新其实际覆盖的结论。
