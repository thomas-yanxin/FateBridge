## 本次取得与原典校读

第102轮重取109-4的34帧清单，其字节指纹与此前相同。原尺寸首次取得第1至7帧，其余27帧失败；所选7帧的urllib后续请求、33帧显式原宽请求及14／33帧更后请求仍失败。旧29帧完整JPEG与33帧1800px预览继续分别使用，不能合称34帧原尺寸取得或全书校勘。

第5帧目录有“閏月小月宿”和“七日等不解界”。目录、所指正文及叶位小字分别核验；篇章先后不等于规则执行先后。“解界”的条名也没有给出可采用的民用换日时刻。正文所选“正供時”“加持物時”“隨時”交代仪轨阶段，不能拆取“供百八時”的“八時”作为一日八分的定义。第7帧“三肘方壇”的肘是尺度，不改读成三时计时。

旧29帧历法段本轮另录12个连续栏串，保留跨栏连接。所见正十二月／傍十二月及虚、星、室三例，支持该见证的字面说明；第一处“其正月”指与闰月相对的正月，第二处“假令正月”与“次二月”相接。它们没有给出闰月复用与小月缺日补配同时触发时的明确组合顺序，也没有现代钟点或端点包含规则。

此前根角色接纳的片段、未接纳疑字与本轮模型工作读法分别保留。新复读把第一处半后字工作读作也，第二处留己形及己／已候选；另有被／彼及末句改／放形的待校问题。这些不是已经取得的人类定字或对旧JSON的勘改，不能静默整理成通顺的通行文，更不能据新模型读法改变主宿、半日或补配优先。完整首录、原字定位、目录叶位的角色分歧见第102轮证据（本地数据：`validation/sukuyo-homa-primary-v102-validation.md`）。

第33帧仍只读旧1800px预览：日期公式及写讫、校合的自述可以登记；人名疑字、不同署记的关系、是否承袭前本，均继续待核。题记自述年代、现存物实际制作年代和摄影卡的平成16年7月是不同证据。摄影卡“写一册”也不是本次材料学鉴定。

## 历本对照的未决冲突

江户东京博物馆90207073的[官方目录](https://www.edohakuarchives.jp/detail-82395.html)题名《伊勢暦（宝暦4年）》，制作年代字段另列宝历3年、1753。先分别记录两个字段，不能由此直接裁定目录错误。实际响应只有无图占位，本轮没有取得该历页。

## 前瞻文件的可靠交付

`scripts/sukuyo_blind_study.py`的draft、context、register、seal、blind-sheet、evaluate共用最终输出步骤。原来直接打开最终路径，已在冻结A用注入ENOSPC复现：留下120字节无效JSON并占用路径。该文件不能通过注册读取；问题是损坏产物可见及重试受阻，没有证明无效注册会被接受。

现在先完整序列化为UTF-8，在目标目录写临时文件，flush、fsync并成功关闭，再以不覆盖的硬链接发布。发布前写入、关闭、同步或链接失败均清理临时文件；不支持硬链接时明确失败，不回退覆盖写。已有文件和悬空符号链接都不替换。它提供完整文件的原子可见性，不认证父目录掉电持久性、外部可信时间戳或研究注册真实性。

硬链接成功之后，如果清理临时路径或打印终端消息失败，命令也可能非零退出，而最终文件已经完整存在。此时先检查该文件内容、绑定及指纹，不把任何非零退出一概理解为未发布，也不删除已有承诺来重试。

在真实招募前可以运行：

```bash
uv run --locked --extra dev python scripts/sukuyo_blind_study.py draft --output /absolute/new/path/draft.json
uv run --locked --extra dev python scripts/sukuyo_blind_study.py context --protocol /absolute/path/protocol.json --output /absolute/new/path/context.json
```

第二条要求已经准备好完整协议；不能拿空草案当已注册研究。context输出仅用于在注册及原始预测签发前绑定完整方案，不能为旧预测补签。未来研究仍须事前冻结实际历法、原典、解释和预测策略文件、独立基线及概率映射，再对互不重叠的配对进行盲态结局裁定。更新来源或解释政策时重新承诺，旧分母、失败、失访与弃权都保留，不把传统关系分数换成概率。
