# 沈氏整理本216张起星图的完整星数校勘

[下卦盘图](fengshui-lower-diagram-collation.md) · [运行来源比较](fengshui-source-comparison.md) · 冻结起星图数（本地数据：`../tests/fixtures/fengshui_replacement_diagrams_v1/reference.json`）

起星图的数字核查从五张王氏例盘扩展到另一底本的全部216张图：九运、二十四山、九宫山向运共5,832数。当前中州计算的声明替卦分支吻合214张完整图、5,829数，三处字面差异保留。216张图全部参与比较；来源本身有重复数字，完整数字验收仍为false。

## 底本与作者范围

底本为[《沈氏玄空学》完整PDF](https://www.vr-d.com/pdf-file/%E9%A3%8E%E6%B0%B4%2F%E6%B2%88%E6%B0%8F%E7%8E%84%E7%A9%BA%E5%AD%A6.pdf)，沈竹礽编、姚国华与柯誉整理，中央编译出版社2011年6月第1版、2016年2月第3次印刷，CIP另记2011.3。917页原文件SHA-256为 `b0c2a7af0a1b94f36cf1cc9f0d2ce4b65e8ea49bd793bc128b8fdc525b5ba847`。不是已认证的民国六卷本影印。

卷五PDF503《附说》另署“古吴吹齑子申听禅编”，说明把左右兼合成216局；图集在PDF511–726。因此只按这个整理本的图集署名和范围登记，不把它们一概归为沈竹礽亲绘，也不把后来中州规则与该编者的全部主张合为同一版本。

《附说》PDF507提及三度以上起星，并讨论先向后山、山向皆替和两向合看；PDF508又讨论不得兼及山向俱替的情形。这些是后续适用条件校勘的依据，尚未完成逐条结构化与反例验收。其“三度”起点尚未确认，不能与现行中央半宽4.5度直接判同或判异；单位与起点的补充核对见[角度来源校勘](fengshui-angle-source-audit.md)。当前比较直接指定私有起盘函数的 `replacement` 数值分支，未捏造一个测量偏角来声称已经符合该书选盘条件。原小图兼向标注全部留存，不以未识别的标注补出现场角度。

## 先转录，后比较

完整转录SHA-256为 `43b04b453c5ae51cb6fc6e7ebb958a6e2da58e853b254e0c69f76e1458dd0fca`。冻结记录早于首次引擎比较，之后未按引擎结果修正任何原图数。

1. 从PDF原生图像及文字标题绑定216个唯一运／山向，保留图像、兼向小图、原始页码、标题与散列。
2. 依原图九宫线定位，确认南在上、东在左；每宫中行左为山星、右为向星，下行为运星。裁字位置不由引擎数字或飞行规律推算。
3. 原尺度及两倍尺度使用同一个Vision OCR实现；5,778字位同读，54字位未自动接受。两种尺度不算两个独立识别器。
4. 助手逐字查看18张数字分类图，另对54个未接受字位查看完整原格，保留全部源字位、裁剪矩形、识别初稿与复核图。45张整图另有人工式抄录交叉检查，其中15个抄录错误经原格复看修正，错误初稿保留。助手复核不等于独立人工专家校勘。
5. 冻结全部5,832数，再首次比较引擎。来源排列诊断只报告重复／缺数，不拿排列、星名或推算结果补字。

保留的研究脚本以 `.py.txt` 归档，字节与冻结时一致；它们是采集过程记录，不作为仓库Python模块执行或自动格式化。`hashes.json` 固定691个原始及复核文件。加载器同时核验完整清单散列、参考散列、原图绑定、每个字位的唯一来源和原始识别过程。
