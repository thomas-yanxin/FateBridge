# 八条来源差异：错录、列位与成对公式

后续进展：下文记录上一轮结束时的状态。现已将6条旧错录应用到独立v9当前语料视图，旧样本和历史结果保持；全部367条配对验证及产品查询索引尚待同步的范围见[六条来源输入修订](bazi-corpus-input-revision.md)。

本轮逐页核对上一轮预定的全部8条记录，使用原扫描8页及CADAL新增扫描的8叶。发现6条旧记录有字形或列位错录，另外两条原注公式明确写出了位置，全书记录将其四柱全部留空过度。两条公式现已通过受限修订层进入当前全书视图；6条旧错录的正确读法和原错误记录另列保存，旧367条冻结语料尚未切换到新的输入视图。

这不是8个独立命例，也没有新增强弱正确率。通关末例在两个研究组重复登记，全部重复记录继续保留。本轮仍由同一读者校读，新增扫描属于同一1947年底本的数字见证，不构成独立版本或独立专家审定。

## 当前已实施的两条公式修订

原注在“任氏曰”之前，两条公式不归为任氏增注。第一条按印文“丙寅戊辰月日己卯癸卯年時”，月为丙寅、日为戊辰，年为己卯、时为癸卯；第二条以同样明确的顺序读取。二者仍是理论式例，不是已核实的历史出生记录。

维护审计器新增严格的成对位置读取器和独立的公式修订路径。它只接受完整的“两个干支＋月日＋两个干支＋年時”锚句，并要求两个指定命例、全部558个命例和1,380条陈述的完整修订前对象与冻结材料完全相等。修订计划被代码中的固定哈希绑定，换写计划并重算其自身哈希文件也不能通过。普通字形／题注修订器仍拒绝补全未知四柱，史姓例和其他未知位置均保留。

本次仅改变`MAIN-C332`、`MAIN-C333`的四柱与位置来源元数据，以及`CENSUS-R945`、`CENSUS-R946`的两段说明。原锚句、原注作者层、理论式例类型、全部强弱标签及禁止档位均保持。其他556个命例和1,378条陈述完全相等。原始批次及此前22份证据索引的1,255个条目全部保留；新增一份公式修订绑定索引。

当前完整位置记录由530条变为532条，原始530条计数另行保留。强弱明确标注仍为26条、强弱未知仍为532条；这些计数指向不同对象，不能把两个新增完整输入记作两个强弱通过。

## 位置明确仍不等于历法一致

在位置读法冻结后，使用先前已冻结的对应表核对两条公式，结果另存，不用来改源字：

| 理论式例 | 符号对应结果 |
| --- | --- |
| MAIN-C332 | 年干—月干相符；戊日卯时的表列时干为乙，原注印癸，日干—时干不一致。 |
| MAIN-C333 | 丙年卯月的表列月干为辛，原注印己；己日寅时的表列时干为丙，原注印戊。两项均不一致。 |

两个公式的四个单柱均属于六十甲子，但柱间关系没有因此自动相符。这里没有建立真实出生日期，也不按对应表把原文改成可通过的命式。此前单列的3条印本输入冲突、原4条问题库存和22条未决记录全部保留，新增公式的符号差异另列，不能称当前所有来源都历法一致。
