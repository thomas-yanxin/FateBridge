# 《滴天髓阐微》扫描缺叶与术语续文

本轮发现并补录了一项资料缺口：旧516页文件在物理页50后，直接跳到正文《通神论》。CADAL07005210扫描的叶51—56继续收录《初学捷径》，叶57—58为原书目录，叶59才对应旧文件的页51。缺口包含“衰旺强弱之别”的编者按、看命三法、五行衰旺取用表及其适用限制。

旧文件末尾的页514—516则是现代横排数字化目录；新扫描叶521与旧页513同为《贞元》结语。这三页仍保留在旧文件物理库存中，不把数字化附录当作新扫描缺失的古文。

## 来源与识别方法

旧底本SHA-256为 `d6a7d1daf6513ce9fb9940ff8331b96804c10cdafbeac00d4d3d0a37229e1803`。新增完整DJVU为 `1d0a16f528ed3074cdefad33b2d2f9233a47199cf88a8b02001c897e16996e60`，来源为[CADAL目录](https://cadal.edu.cn/cardpage/bookCardPage?ssno=07005210)及其[公共数字副本](https://commons.wikimedia.org/wiki/File:CADAL07005210_滴天髓闡微.djvu)。它提供额外数字见证，不据此认证独立版本或独立专家复核。

在提取特征前冻结了两份完整物理页库存、九组已知锚点、图像特征方法和四组缺页惩罚参数。521叶全部本地解码成功，没有跳过失败页。标准库脚本 `scripts/align_bazi_source_leaves.py` 只提供保持顺序的版面候选对应，保留四条路径、每个旧页的三个近邻及所有缺口。九个已知锚点已暴露，不能算作盲测准确率。

四组参数分别得到506、512、513、513个候选配对。对全部路径的缺口并集逐项阅读后，确认封面、理气例、方局近空白页、官杀例、任氏自造题注、女命章和子象例均有对应内容；低缺页惩罚会因裁边和版面差异把对应页拆成两个空位。因此不能挑选某一组参数后，把全部候选配对认定为逐字相同。初始路径及其全部差异继续保留。

首次CLI与C API渲染失败也保留。加载诊断确认系统 `nice` 启动器会移除显式动态库搜索路径；后来直接启动隔离解码器，并在执行前设置进程优先级，才完成全部521叶渲染。最初关于捆绑库缺少符号的推断没有成立，另有更正记录。未接受Xcode许可或进行全局软件安装。

## 补录内容及边界

新增内容归属李雨田增补《初学捷径》，不能归给任氏正文或原韵文。叶51编者按认为“旺、衰”与“强、弱”应分辨，讨论当令、比劫印绶及克泄重等组合，又列常理和旺极、衰极的变法，结语要求活看。旧页50的原始陈述 `CENSUS-R156` 不改，另加续文资格说明，避免半段材料被当成完整定义。

叶52的看命三法分别考察得时、得势、得地，原文还要求对日主、用神、忌神分别考察。五行取用表30行已按源页录入独立补充资料，保留“为上、次之、某元素少”等条件，不用现代数值阈值代填。叶56明确说明它只论五行正常之理，从、化、变格不在此例。后面的历史运事表仅登记其存在与联合条件，未转成个人现实结果保证。

这些内容修补的是来源范围和解释语境。本轮没有改变生产强弱系数，没有把表格直接变成自动喜忌规则，也没有用它给558个原命例或1,380条陈述补强弱标签。原有26处分歧、22条其他未决记录、三项印本输入冲突及四条初始输入问题库存继续保留。原40,219条包络失败、41项边界冲突及五例解释验收均未由本轮资料工作关闭。

资料、完整渲染清单、四条初始路径、缺口阅读、30行取用表、首次失败及验证记录在 `docs/validation/bazi-source-leaf-alignment-v1/`。旧516页普查和既有索引均保持原样；规范库只增加一个有哈希绑定的来源资格说明。全书冻结、原典总体验收和现实预测效度仍未通过。

验证副本上两个测试文件共52项通过：穷举短序列验证对齐全局最优、完整库存与输入哈希攻击、四组路径全部缺口覆盖，以及既有校字／题注保护回归。首次为51通过、1失败，原因是复用副本缺少旧普查索引；在4,980份既有输入字节不变的前提下补齐460份冻结文件，同一套测试通过。最终5,440份声明输入测试前后哈希相同，另有可读回校验的自包含输入归档。测试不加载生产项目模块，不宣称REST、MCP、CLI共享计算或真实模型验收。全书CLI `--require-complete` 仍退出1；它与直接审计函数的完整业务结果相同，两项命令元数据另行严格核对。整个工作区仍有并行改动，不能把副本结果升级为全工作区通过。
