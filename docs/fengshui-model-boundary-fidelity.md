# 风水边界原因与实际太阳模型

风水领域沿用共享交节计算的实际结果。本次修复年界、月界、宅运和命卦在解释模型边界时的信息丢失；没有修改太阳交点、年星、命卦宫数或九运公式，也没有把五秒操作保护改成精度成绩。日时原典的完整选局与现实预测仍需独立验收。

## 实际模型触发的缺陷

显式选择解析模型，在实际计算得到的2024年立春交点运行时，原结果已标记 `provider=fatebridge_analytic`、`ephemeris_model=fatebridge_analytic_solar_v1`、`approximate=false`，并保留有效年或宅运候选。然而后续说明有三处不一致：

| 位置 | 修复前 | 修复后 |
| --- | --- | --- |
| 年界 `boundary_resolution` | 解析模型的保护原因与秒数丢失 | 保留实际模型、原因与操作秒数 |
| 宅运 `confirmation_reason` | 把解析模型保护写成近似立春回退 | 明确为解析模型的数值边界保护 |
| 文字快照 | 识别Moshier，未识别具名解析模型 | 点明实际解析模型及精度边界 |

检查还覆盖日期命卦和月界：日期命卦跨民用日期的保护原先只说明Moshier；月界虽保留了实际解析原因，通用精度政策却只列Moshier秒数。现在两者均补上对应边界的实际模型政策。原Moshier字段与原因保留，不替换成另一模型的名称。

原始失败记录固定了三个解析模型失败和三个原生控制通过；这不是模型预测结果评分。实际立春交点用于软件回归，不冒称现场观测或原典的历史日期例证。

## 一条政策贯穿各层

`boundary_model_policy`集中识别当前受保护的Moshier与具名解析太阳模型，返回实际模型、操作保护秒数、原因和适用范围。五秒仍是保留候选的操作政策；固定一秒数值实现门槛及既存失败记录不变。它不声明五秒为实际误差上界。

| 层 | 结果字段 | 解释责任 |
| --- | --- | --- |
| 年星／带时刻命卦 | `boundary_resolution.uncertainty_reason` | 分开具名数值模型与固定气回退，保留候选年 |
| 月星 | `precision_policy.boundary_model_policies` | 分别列出区间起、终边界的实际模型政策 |
| 宅运 | `confirmation_reason` | 区分Moshier、解析模型与近似回退，不虚构唯一运数 |
| 只有日期的命卦 | `boundary_precision_policy` | 解释可能跨过的民用日期，不补出生小时 |
| 已确认有效出生年命卦 | 无须交节求解时不加上述观测 | 不因运行环境存在某模型而虚构实际调用 |

线性近似回退优先按相邻民用日期处理；即使测试中带有残留模型字段，也不能借它变成具名数值模型保护。未知模型不自动获得这条五秒政策。快照所述模型来自本次结果内的实际分辨记录，不从目录名、安装状态或文件名推断。

## 可复验范围

跨午夜的日期命卦另用明确标为合成几何的测试隔离日期传播；它不是一条真实交节时刻，不能计入天文精度或现实预测样本。六组真实FastMCP协议用例与REST、CLI比较完整业务结果，分别验证年星、命卦和宅运。
