# 人类图参考目录与解释来源一致性

本轮修复解释内容与其来源指纹脱节的缺陷。它影响角色、线固定、回路、Color类别和原典分歧等参考目录的读取与核验；正常星历坐标、既有传统规则及原典结论保持不变。

修复前的实际反例采用虚构1988-03-18当地12:00、Europe/London输入，计算得到6/2角色。在测试原生上下文内，角色目录首次读取后，私有文件被换成另一份有效JSON：六线类别均被改写，缓存仍返回旧类别，指纹却来自新文件。完整原始回执保留该混用状态，旧完整固定解释核验仍通过。测试只改动临时副本，没有更改安装数据，也不认证原生执行真实性。

现在[统一读取器](../src/fatebridge/core/human_design_references.py)将实际读取的不可变字节、解析值与指纹保存在同一记录中。12份运行时目录的字节指纹来自修改前冻结并已核对的参考，冷启动遇到另一份有效JSON也不会自动信任。每次计算和完整解释核验拥有各自的来源视图：实际用到的目录首次读取时检查来源，结束时复核文件及解析值；中途清空缓存不会替换当前视图。未使用的可选周期目录不强制读取。

运行时错误分别为`human_design_reference_changed`、`human_design_reference_unavailable`、`human_design_reference_invalid`及`human_design_reference_identity_mismatch`，统一沿用不可重试的`ephemeris_source_inconsistent`与HTTP 503。重复JSON键、非有限数值及非对象根均不能充当参考目录。完整解释核验遇到来源不一致时返回拒绝，而非通过回执内部自洽来接受错误来源。

来源视图覆盖正文附加星体、1996回路列表、公开回路类别、通道资料、新增官方交叉观察、周期资料、2001深度目录与数值表、Color类别、两幅转录图及角色、来源分歧目录。它不认证这些材料的出版方母版、历史生时、星历生产过程或现实预测。开始及结束检查也不是原子文件读取证明；固定指纹只约束本版已核对目录的身份，不把所记载的原典分歧变成一致。

新增回归保留原来误通过的完整混源回执，并要求在禁止原生重算的情况下拒绝它。全部12份目录分别检查中途改字节、不可读、内存改写、清缓存与冷启动不识别来源；正常18组完整结果保持类型、数组顺序及浮点值一致。首次实现中的函数同名冲突及其失败记录也保留；修复的是读取器调用，原输入和标准不改。详细测试清单、安装包、三种接口、Linux复核与散列见复核报告（本地数据：`validation/human-design-reference-snapshot-verification.json`）。

维护这些目录时，应先核对来源并保留旧失败，再显式更新`REFERENCE_SHA256`及相应证据。直接按运行目录当前内容生成“可信指纹”，会失去本次修复提供的独立约束。原14份参考文件不改，38项专业要求及7项未通过状态继续保留；完整384线线义、完整历法、任意模型解释和现实效度仍须分别验收。
