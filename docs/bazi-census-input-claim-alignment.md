# 原典命例输入与断语引用对齐

标准全集核查现已读取来源绑定的修订覆盖层：8 条原页录入修正进入完整 558 条命例的派生视图；其 8 条关联说明全部核对，其中 7 条修正引用，1 条保持原样。原始 35 个批次及 1,380 条断语不覆盖写入，强弱标签和原来的验收判据不改。

这是[前一轮全量输入核查](bazi-census-pillar-consistency.md)的后续工作。前一轮只建立独立修正版视图，本轮把同一组已冻结的原页修正接入标准全集核查路径，并补齐配套引用。未开展新的命例强弱计算或模型解释验收。

## 可复查行为

```sh
uv run --locked --extra dev python scripts/audit_bazi_wholebook_census.py \
  --require-complete --output /tmp/bazi-census-alignment-new.json
```

使用新的输出文件名。命令会输出完整派生命例和说明，保留每条修订的完整旧对象、来源图像及协议绑定。当前预期退出码为 **1**，完整报告仍会写出：

- `resolved_source_cases`：全部 558 条，包括 530 条完整和 28 条缺项记录。
- `resolved_source_claims`：全部 1,380 条说明，保留此前已登记的独立文字校读。
- `source_case_input_corrections`：8 条原页输入修正的完整旧值。
- `source_case_claim_alignment_reviews`：8 条关联说明核验，7 改、1 不改。
- `remaining_case_input_questions`：3 条图版内部冲突和 1 条待辨字形。

新增覆盖层文件及最终派生命例、说明的散列必须进入今后的全集冻结凭据；遗漏这些绑定或仍有输入疑问时，核查器拒绝开展候选比较。当前没有创建 `collection-freeze.json`，`candidate_evaluation_allowed=false`。
