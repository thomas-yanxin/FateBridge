# 完整局与同目标附合：v69 核查

本轮修复一个关系识别问题：完整三合／三会与局外邻接六合指向同一五行时，旧代码仅因位置集合不同就判为争合。当前方法升为 `season_root_revelation_relations_v8`。完整局仍只核算原有物理位置；附合另留 `same_target_affiliation_only` 回执，额外预算为零，局外支不据此转化。

这项改动不直接裁定从格、用神、有效通关或现实结果。绑定、转化、根量、强弱及特殊结构阈值均未调整。有直接六冲、不同目标争合，以及仅两个六合争用一支的情形维持原判。历史实验的 `_evaluate` 默认保留旧位置争用规则；公开计算和八个敏感性分支显式采用新规则。
