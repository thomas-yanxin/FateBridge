# 原文数值与校记定位的完整性

《大智度论》《法苑珠林》的既有原文、校记、月定义、名义分数和历史计数保留原字节。新增的 `apparatus_pointer_scope` 明确限定：原计数只检查后置 note/app 自身 `target/from/to` 的本地定位 token，以完整 XML 的 `xml:id` 解析，分母不含 `corresp` 等关联属性。全部记录数还包括未带这些自身属性的记录。

T1509 的 `corresp="#0409025"` 没有同名 `xml:id`，但两处 app 的自身起讫能解析，原注、改注及星号可以按编号和内容关联。这些关系分别保存；严格 ID 对照未匹配不等于编号式关联无意义，也不增加独立古本。

原文说明会核对实际来源与修改前参考的指纹。派生名义月长及资格说明保留 JSON 类型，`true` 不能冒充整数1，`30.0` 不能冒充整数30，0不能冒充布尔 `false`。指纹或类型不符时拒绝解释，避免把污染的引用对象当成已绑定原文。

本次 T1509 取得属于旧来源重新核验。没有据检索摘要制造“旦／暮”版本，也没有重接一份重复月表。指针数、来源完整性和合成拒绝检查不证明古代日界、桧尾半日、闰小月先后、全本校勘或现实预测。
