# 多处健全根是否必须有透比劫

现行旺衰结构规则把多处健全根与透干支持合并判断。为追查没有透出同党却被原典判强的命例，本轮冻结了一个新候选：数值分支中，至少两柱达到既有根资格门槛、且透出官杀没有至少两柱健全重根时，可不要求透出比劫而判强。其他结构分支、季相、根损、支持占比、数值系数和原0.75资格门槛均未修改。

这是待检验的工程充分条件，不是古籍给出的定理。候选在完整旧材料上出现退化，因此没有进入生产，也没有继续读取预定的新章节来寻找有利分数。

## 原页复核与机制定位

重新核对保留原页（本地数据：`../tests/fixtures/bazi_qualified_root_capacity_v1/source-recheck.pdf`）中的《秘本子平真诠》PDF22–23及1947年《任注滴天髓阐微》PDF381；另保留前后页作上下文，不声称本轮逐页审阅了所有保留页。两本原书散列分别为`71402a780b0351b54edf121a51bc4a4a4ce5896496c35b954563ee06f1a6f620`、`d6a7d1daf6513ce9fb9940ff8331b96804c10cdafbeac00d4d3d0a37229e1803`。

子平原文区分通根与浮干、长生禄刃与墓库余气，并特别说明阴长生口径；它没有给出“两处根加至多一处官杀根就一定强”的布尔规则。根类的程序映射、工程保留比例及全局承载仍是不同层次，不能把该候选说成原文直译。

不能为了消去这例就加入姓名、四柱查表、特定己巳排除，或把它改标未知。也不能由这一次退化证明所有阴旺根都无效、所有土寄火根都弱或所有月令克身均无救；这些仍需完整的月令、受生、制化及救应机制验证。
