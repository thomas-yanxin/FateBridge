# 八字知识条目的限域编释

当前公开85条：原包72条加13条原典力量语义编释。最新五行逐字段复核（本地数据：`validation/bazi-element-knowledge-audit-v1.md`）修订完整五条元素卡，其余80条逐项保持；原72条现有47条内容修订、25条保持原值，35条仍待完整出处归属（25条未改、6条健康、4条专题部分待校）。五行采用固定数字原文，尚未完成独立书影校勘；全部72条均未完成独立专家验收，库存数量不换算准确率。此前[性情章检验](bazi-mediated-capacity-audit.md)新增三条语义卡，[学业、子女与六亲复核](bazi-topic-knowledge-audit.md)修订14条，各批原快照、来源范围及未决项继续保留。

五行条目分别归属《礼记·月令》的方位时序、礼制颜色和本项数字，萧吉《五行大义》的生数／成数，以及《素问》《灵枢》所选篇章的藏体窍、藏府分类。祭先与在藏不混表，现代行业和额外配色不冒充原典，元素旺弱不测量智力、品德或器官状态。首轮`citation`可直接核对作者、版本／固定修订和网址；逐字段出处在`provenance.entry_curation`。五例真实模型首跑仍有流程与版本交付失败，结果及后续共享说明修订均在上述复核记录中。

## 修订内容与依据

十神首行定义保留已独立核对的五行生克与干阴阳关系。100个干对的环算测试验证的是这项定义及两个计算函数的一致性，不是100个原典命例，也不证明人的职业、收入、关系或身体结果。

其余文字改为所选《秘本子平真诠》的条件分支与明确的编辑说明。食神需分生财、制杀和逢印；伤官需分生财、佩印、带官及金水情境；财官印须核对月令、透藏、根气、位置、去留与救应。旧卡把单个星名直接推成第三者、稳定收入、投资品种或具体疾病等文字已在这十条中替换。其他待审分类尚未因此获证。

有原典依据的条目采用国家图书馆藏本NLC416-11jh010455-35296，沿用既有原典审计的PDF与SHA-256。`provenance.entry_curation`分别记录原典引用`source_refs`和程序依据`implementation_refs`；两者不能互作证明。首行程序定义、原典分支编释和现实边界分别说明，不把编辑文字冒作逐字引文。有出处的普通首轮`citation`保留原始网址，待校勘条目明确返回待核状态。原上游包的构建时间另标为上游时间，不冒作本次词条修订时间。

## 格局词条的确定性错误与条件缺口

十个旧格局词条曾把“四柱某星有力”直接当成格条件，并给出固定喜忌和职业。所选原典PDF26—30先取月令，再察四柱配合、成败及救应，不能省去中间条件。当前词条对应实际`monthly_structure.structure_god`及`evidence_chain.month_command.selected_god`，不把程序取格标签认证为成格。

| 旧问题 | 修订依据与结果 |
| --- | --- |
| 正财格将伤官写成泄财 | 食伤生财的生克关系不能写反；是否适用仍另查身食财、根与位置 |
| 正印格将食伤一概列忌 | PDF28明确列身印两旺用食伤、印多用财等不同分支；保留既有身印反例 |
| 甲日卯月写成日坐羊刃 | 这是月刃资格；PDF86限定五阳干，实际月支位置与制化另查 |
| 刃杀共现就称驾杀成格 | PDF86—88另查根、合去、制伏与财印，不由共现直接裁定 |
| 建禄直接断全局强旺及创业 | PDF89—90以透干会支另查取用；实际禄位、全局力量与现实职业分开 |

这些是选定原典条件的编释及软件范围说明，未完成全局成败算法；完整作者、版本、页码与实现散列分别给出。改词条不增加独立命例，也不把原典旺衰7例仅符合4例改成通过。

## 健康知识与计算一致

八个旧健康条目曾从五行计数直接延伸疾病、调理及治疗时机。当前分析程序只生成盘内符号权重与传统关系，知识卡已据此修订。六个脏腑对应键保留供查询，`review_status=computational_scope_only_correspondence_source_pending`；其`source_refs`为空，程序散列只证明说明所对应的实现。检索到的医籍摘要未完成全文与版本核对，不补造出处。

`七杀攻身`限于克日主的十神关系及制化前提；`调候寒暖`对应所选原典PDF第37—38页《论用神配气候得失》的命理语义。程序现有`constitution.climate`仍是火土权重与水金权重按差值3分组，尚未实现原典按月令、格局和时令互参的调候裁定。知识清理没有改变这项算法，也没有把它验收为完整调候或医疗评估。

## 身与印的语义缺口

首批新增分类`classical_force_semantics`有三个键：

- `身强印旺与印用食伤`：列出原典分开的身、印条件，保留李状元扫描本乙亥与按五鼠遁推导己亥的区别，未声称看见第二版本。
- `身重印轻`：保留茅状元原文与正式v2中和的分歧。
- `身轻印重`：保留马参政原文与正式v2强的分歧，说明身印合计标签不能代替分别判断。

这些例子已在既有34例对照中出现，不是新独立样本。知识条目解释术语与现有缺口，不为未完成的原典力量模型补发通过结论；既有7例仅符合4例的记录保持不变。
