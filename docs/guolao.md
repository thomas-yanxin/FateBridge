## 资料与口径

底本固定为[东北大学图书馆藏《新编评注通玄先生张果星宗大全》卷1–2，陆位辑校](https://touda.tohoku.ac.jp/collection/en/database/library/10020000001141)，
可从[IIIF manifest](https://touda.tohoku.ac.jp/collection/iiif/metadata/10020000001141/manifest.json)
定位逐页影像。图像6、10核对宫主、度主归属；图像11核对五星生克；图像9核对安命、二至例外、逆布十二宫和小限顺序；馆藏卷1–2图像33、34核对天乙/玉堂与岁驾。
资料书目、原图SHA-256和转录项见原典来源回执（本地数据：`../tests/fixtures/guolao-classical-source.json`）。
没有把后世软件或网络白话解释列作此底本原文。

现代天文部分按 [Swiss Ephemeris 官方接口](https://www.astro.com/swisseph/swephprg.htm)
计算。每宿一颗距星作为赤经标志的定义见[国家天文科学数据中心天文学名词](https://nadc.china-vo.org/astrodict/termdetails?id=7873)。
研究锚星的ICRS坐标、自行、视差与视向速度来自CDS SIMBAD，28项查询URL、来源摘录和指纹
保存在[数据来源表](../src/fatebridge/data/guolao/sources.json)。

此锚星集合是**明确列出的研究选择**，并未由陆位本逐星校定。天体与距星均用出生日期的地心视赤经，
按该日实际赤经排序形成首含尾不含区间，处理周回与恒星次序随年代变化的情况。它不采用
白羊零点起等分28宿，也不把黄经直接与赤经相减；输入Lahiri黄道不会移动这套赤经宿界。
现代角度按360度一周，不与历史周天古度直接混算。

七政保留黄经、黄纬、赤经、赤纬和经度速度。罗为月球平交点、计为其对点、孛为平均远地点。
紫气是原有horosa四样本线性拟合虚点，无实体天体对应，也未校准为底本紫气历元。
## 时间与条件

- `guolao_seasonal_anchor_policy`可不传、传`null`或传`term_instants`，均保留v7的交节瞬间口径。另可明确选择`source_solar_days_winter_exclusive`或`source_solar_days_winter_inclusive`，二者要求`use_true_solar_time=true`：以同次太阳和UT1计算的当地真太阳日为单位，计入整个夏至日、小暑日和大寒日；前者从冬至次日开始，后者计入冬至日。它们保留陆位本“冬至日后”的两种待裁解释，不按事后事件吻合选择。算法、夹逼和验收见安命日界研究（本地数据：`validation/guolao-source-anchor-days.md`）。
- 日界选项回显`guolao.life_palace.seasonal_anchor_evidence`，保留两个日界的UT1／TT、太阳黄经、太阳钟面和实际星历来源。出生瞬间与七政四余位置不因选项改变；安命及依赖命宫的结果可以改变。1毫秒是数值夹逼宽度，不能解释为物理时间精度；出生落入数值日界区间、端点安命不唯一、太阳模型或已观察来源变化时返回错误。历史地方日界、实际日出和冬至日纳入问题仍未裁定。
- 果老不再将无法确定的出生时区默认为UTC；须显式提供时区/偏移，或由可解析地点取得。坐标不用于反推民用时区，显式UTC仍有效。来源识别、错误行为和验收见时区来源修复（本地数据：`validation/guolao-timezone-source.md`）。
- 出生记录现可显式提供`birth_second`与`birth_microsecond`，专用果老接口及通用果老盘一致保留；未提供仍取所给分钟起点，不认证真实出生精度。太阳钟面跨界反例、独立半秒星位及验收范围见出生秒数贯通（本地数据：`validation/guolao-birth-precision.md`）。
- 输入民用日期按延伸格里历，带明确时区。1972年起按冻结IERS闰秒表取得TT，再用Swiss Delta-T模型估算UT1；行星按TT，上升与地平位置按UT1。闰秒表有效期之外回显`future_leap_seconds_assumed_unchanged=true`，不编造未来闰秒。当前共享时间模块另支持1961–1971年IERS历史UTC漂移；更早输入沿用Swiss的UT1/Delta-T约定。该历史UTC增补晚于果老v3的Linux冻结快照，验收范围分别记录，未声称建立古代地方时体系。
- `use_true_solar_time=true`保留记录的物理瞬间，以同次地心视太阳赤经及估算UT1视恒星角计算当地太阳时角，取安命生时；false使用记录的民用钟时。太阳钟面为不带民用时区的标签，见`guolao.profile.apparent_solar_clock`的操作数、方法和时辰边界距离。它可改变命宫及依赖命宫的格局，不改变七政四余、宿界与天文上升。不会把经度差/均时差再次加进星历时刻；DST不存在或重复钟时要求明确偏移。估算UT1不是实测DUT1，精确分数和微秒展示也不认证真实出生时间精度。
- 昼夜使用太阳中心的地心几何高度是否不低于0度，不含折射、视半径、地形、观测海拔或太阳视差；这是显式研究定义，临近地平时不宣称等同实际目视日出日落。
- 传统北半球节气季节按太阳回归黄经315/45/135/225度切换，冬令为立冬至立春，不用公历11–1月。南半球不会静默翻转传统季节。
- 实际七政模型可为SWIEPH、Moshier或显式选择的JPL，回显在`guolao.profile.ephemeris_models`。缺少Swiss或计算失败会返回错误，不以近似轨道伪造宿度。

显式配置 `FATEBRIDGE_JPL_FILE` 后，七政的黄道／赤道、黄道偏移、距星传播与地球观测者均通过受管理调用遵守所选 JPL 内核；本命及目标星空都适用。缺文件、原生降级或所需时刻超出覆盖范围返回具名来源错误，不以 Moshier 填补严格选择。年干支还依赖当年节气计算，内核应覆盖实际调用所需的节气扫描窗口，不能只覆盖出生瞬间。

`guolao.profile.ephemeris_provenance` 和目标盘的 `guolao.timing.profile.ephemeris_provenance` 保留七政逐星两种坐标的实际模型与返回标志、四余的非物理模型、距星地球观测者模型及距星原生标志。七政两种坐标的模型不一致时拒绝交付。距星原生标志可能回显 SWIEPH，而实际地球观测者使用 Moshier，因此二者分开；罗、孛的返回标志也不把解析平均要素变为物理矢量。配置与星表临时搜索路径在共享锁内操作并恢复。这里记录返回模型和选择策略，不证明完整文件依赖、连续文件不变或绝对天文误差上界；现代锚星和紫气模型的原典限制仍保留。

七政条目的 `longitude` 与 `longitude_speed` 明确对应热带视黄道，速度单位为度/TT日；所选黄道位置另见 `zodiac_longitude`。`longitude_speed_native` 保留原生速度，光行时、章动旋转和完整视位置导数修正分项分别返回；本命及目标盘的 `profile.longitude_motion` 记录适用模型、原生版本、收敛记录与实际观察到的来源文件。七政不一致的模型或变化的已观测文件会拒绝交付混合速度；这不是完整原子文件读取证明。

既有固定 TT 诊断（本地数据：`validation/other-chart-schools-v16-motion-diagnostic.json`）保留修正前的偏差。当前为经过版本检查的 Swiss／JPL 月亮接入光行时链式导数，为太阳、水星、金星、火星接入完整视位置导数，并保留其他七政的旋转修正。Moshier 不套用依赖质心状态的月亮光行时公式；七政通过共享经度运动层对自己的 Moshier 完整视位置作二进制步长求导，要求连续收敛与正反方向联合检查，果老不再重复叠加求导修正。基础星盘的 Lahiri 路径按自身恒星黄道位置求导；果老此处的七政速度仍为热带视黄道速度。未收敛或原生版本不匹配时明确不施加未验证修正。原生值、修正分项及残差分别保留；这不改善其解析位置理论本身，也不将其他流派的未支持路径自动标为完成。四余模型和传统格局规则未改动。这些分项不构成全域速度、精确留逆时刻、原典整例或现实预测认证。

## 调用与解释

```bash
uv run --locked --extra dev fatebridge astro_guolao_chart \
  --birth-year 1990 --birth-month 4 --birth-day 6 \
  --birth-hour 9 --birth-minute 33 --birth-timezone Asia/Shanghai \
  --birth-longitude 121.47 --birth-latitude 31.22 \
  --fields guolao.profile guolao.life_palace guolao.conditions guolao.bodies guolao.rulesets guolao.validation \
  --strict-fields --no-include-snapshot-text
```

以上为虚构演示资料。按需参数与任务视图见[实际MCP合同](contracts/astro_guolao_chart.json)。
`lunar_mansion_system`使用带版本的研究模型名；输出11体连续坐标和研究宿度。v2变更了安命与依赖它的宫位/格局，`life_palace.longitude/mansion`现为null；天文上升继续仅作为`angles.ascendant`参考。
果老输出不再附带通用西方盘的尊贵、相位、人格模板等字段作为果老结论。
结构化解读从本run实际返回的宫主、度主、月宿、同主条件、所选贵人及格局生成，并保留未验收依赖。
每条解读的`interpretation_evidence`列出同run数据路径和解释政策版本。
格局使用独立版本`profile.pattern_model_id`，逐条附`rule_id`及实际条件`evidence`。
宫位比较只支持同宫或宫位间隔，不能提升为命度相临、精确合相或事件概率。
本轮修正“命登岁驾”的命度措辞、1度阈值的浮点误判及无效输入强转，详见解释忠实度复核（本地数据：`validation/guolao-interpretation-fidelity.md`）。
这不等于已验证任意外部大模型的自由文本解释。首次完整导出用`fields=null`，后续读取同run
`result_delivery`，不重新计算全文。

需要时间层时，在相同出生参数后加明确的目标瞬间：

```bash
uv run --locked --extra dev fatebridge astro_guolao_chart \
  --birth-year 1990 --birth-month 4 --birth-day 6 \
  --birth-hour 9 --birth-minute 33 --birth-timezone Asia/Shanghai \
  --birth-longitude 121.47 --birth-latitude 31.22 \
  --analysis-datetime 2027-06-01T00:00:00+08:00 \
  --fields guolao.timing guolao.life_palace guolao.palaces guolao.rulesets guolao.rule_trace guolao.validation interpretation interpretation_evidence \
  --strict-fields --no-include-snapshot-text
```

`analysis_datetime`须带偏移且不早于出生；未提供时`timing.status=not_requested`，不会默取今天。
`as_of`仍只是执行时钟，不能替代目标时刻。`timing.small_limit`保存出生/目标年支、命宫、逆数结果、
本命功能宫、宫主、来源和换年政策。`timing.transit_bodies`是目标瞬间的地心位置，
不是象征性推运；`natal_functional_palace`只将目标星位对应到本命逆布十二宫。
不需要目标地点，不计算目标上升/宫头/昼夜。研究宿界按目标日期重算；四余和未来闰秒假设分别回显。
太阳钟面选择可改变本命命宫，不能改变目标瞬间的物理星空；不能由小限落官禄宫直接推出晋升。

可选原页月限（本地数据：`validation/guolao-month-limit.md`）接入“小限宫中起生月”的十二月序逆转。
须同时提供`analysis_datetime`及`guolao_month_basis=jie_month`或`chinese_lunar_utc8`；
后者按固定UTC+08现代农历正常月号，出生或目标为闰月时不分配月限宫。
月序取记录的物理瞬间，不取真太阳显示钟面，不更改年小限换年政策；两种现代月制均未由该页裁定。
同run的`timing.month_limit`、解释依据与轨迹给出所选政策、实际输入、来源和未分配状态。
