# 原生节气根的点值换算、根回执与错误闭环

原生Swiss求根后的TT标量现在按明确时间点转换。已选中根的民用时间不可表示、时钟依赖不可用等普通异常会形成结构化错误，不再被通用异常处理吞掉并触发线性回退。没有原生引擎或未找到交点时原有的未验证回退仍保留，不能与已求出根后转换失败混为一类。

## 先保存真实选中根，再核对时钟

事前协议（本地数据：`validation/bazi-native-solar-point-v1/protocol.json`）先绑定原源码和原6,391个请求点。控制仅将太阳黄经替换为经过各请求点的单调函数，实际运行未修改的原生扫描与48次二分循环；在转换入口观察真实选中根，不将它偷换成原请求值。这是合成求根／消费层检验，不是实际天文事件或新增独立观测。

原生浮点二分在747条记录中选中了请求点相邻的IEEE值，其余5,644条相同。全部原请求编号、状态、预期标签及实际选中根分别保留。独立90位Decimal参考在生产修改前冻结，仅解码实际选中点，并使用原冻结原子偏移表；不导入FateBridge时间转换函数。

## 领域错误与公开根回执

新增领域模块`solar_term_clock`，使用既有`datetime_from_tt_point(TTInstant.from_float(...))`。领域异常继承既有来源错误合同，以503、不可自动重试及`runtime.solar_term_clock`路径区分不可表示民用时间和时钟依赖不可用。已有严格星历来源异常原样传播；私有标签、依赖路径和原始异常文本不进入公开错误。

初候选只处理值错误；采用前复查发现依赖异常仍会到达外层通用回退，于是另冻结闭环补充（本地数据：`validation/bazi-native-solar-point-v1/clock-failure-closure-addendum.json`），补齐普通依赖异常。两版源码、完整控制及实际节气结果均保留。6,391份完整控制、576份完整实际结果在两版间相同；依赖错误另外通过明确故障控制验证，没有将首版补写成已完成该闭环。

原生回执现在公开实际选中TT、最终浮点括区间、观察到的模型与返回标志、库版本和点值意图。所测空外部文件环境实际返回Moshier，公开回执及`run_metadata.provenance`均继续标为Moshier，近似标志保持，不改称JPL。括区间是数值求解信息，明确不等于物理时刻精度；未声称所有原生数据源都经过独立验收。

缓存策略另作版本区分。共享错误模块有并行变更，本轮未编辑该文件，冻结验收沿用父快照并排除该漂移。除原生消费函数、缓存标识和新增领域模块外，太阳求根、两段式默认根、解析／SPK换算及强弱算法没有改变。

## 实际节气与三端验证

原始选择固定1900、1960、1972、2000、2026、2100六个完整年份、四模式各24节气，共576项。新旧均观察同次原生私有根回执，解决此前原生144项未向外提供根而无法核对的问题；这些是本次实际观察，不冒充以前已经公开交付的证据。

完整实际配对（本地数据：`validation/bazi-native-solar-point-v1/actual-assessment-first.json`）确认全部选中根不变，576个新民用标签均符合声明的数值换算政策。原生48个历史标签修正，最大21微秒；解析模式相应的48个原生探针标签同步变化，解析自身选中根及标签未变。默认DE440及SPK各144份完整输出相同，未发现其他未解释差量。

独立参考复用已冻结的Decimal算子：1960年为SOFA仿射系数闭式逆算，1972年后为冻结原子偏移，1900年以不同二分法求解同一Swiss ΔT约定。1900年共享ΔT模型值，尚非独立观测；未来偏移亦仍是冻结政策假设。本检验没有认证历史真实钟表、未来UTC或天文根的物理误差上界。

冻结回归179项全部通过，涵盖旧点值／标量对照、默认／解析／SPK、原生正常回执、值错误及依赖故障、缓存和完整／投影REST、MCP、CLI。旧测试对“原生函数完全不变”的断言已按迁移协议（本地数据：`validation/bazi-native-solar-point-v1/test-migration-protocol.json`）保存原文，替换为精确求根数学AST保持、原源码一致及6,391个实际根不变的更具体约束；未直接跳过旧检查或改数值预期。

源码独立MCP验证16次有效调用、4次缺项拒绝、574页同次结果散列及124个实际消费根；基础安装包验证12次有效调用、3次缺项拒绝、430页同次结果及93个根。两者另外各通过8次完整／摘要时钟故障控制，确认错误不会被字段投影隐藏。安装包另有三次实际CLI调用，1,122个包文件精确等于冻结源码，84项适用锁定依赖满足。基础包没有SPK可选依赖，SPK验收仅属源码环境。

格式、导入顺序、三个源文件的类型检查及当前调用合同、场景生成检查通过。运行时1,136个文件、308个验证文件前后散列保持；两版源码增量和内容寻址验证材料实际恢复校验通过。非失败警告原样保留，没有改动测试来消除警告。完整范围见本地收据（本地数据：`validation/bazi-native-solar-point-v1/local-report.json`）。
