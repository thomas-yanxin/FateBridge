# 八字精确预算的消费端复核

本轮修复两类算术错误：既定工程份额恰等于15%或85%时的极端值误报，以及身、印精确预算相等时的浮点大小误判。没有改变旺衰档位、系数、原典标签、关系成立条件或既定采用门槛。身印力量、节内司令和有效通关仍分别列为未裁定，不能从本轮工程修复推导出原典或现实准确率。

## 实际改动

`threshold_arithmetic.energies_exact`沿用同次精确重建的五行预算，另列`day_element`及严格小于`3/20`、大于`17/20`的筛查条件。`assess_strength`读取精确筛查结果，不扩大临界区间。原浮点能量和份额保留。

`force_components.engineering_composition`用完整且日主身份一致的同次精确分量比较身、印；`comparison_basis`注明依据，原浮点比较另存`legacy_float_body_seal_energy_relation`，原占比及`ratio_basis`保持。缺少完整回执时只使用已提供的旧分量，不补算命盘。精确预算相等不等于原典身印等力。

冻结方案（本地数据：`../tests/fixtures/bazi_strength_consumers_v1/protocol.json`）先于测量；实施方案（本地数据：`../tests/fixtures/bazi_strength_consumers_v1/implementation-plan-first.json`）在全部首轮反例保留后冻结。完整518,400个固定组合中，仅3个筛查标记、187个身印预算比较改变；原浮点数值和旺衰判级均不变。独立参考只认证给定关系事件及工程系数下的算术，不认证那些事件或系数符合原典。

3个误报依次为“癸未 辛酉 壬戌 辛亥”的17/20、“己亥 壬申 戊午 辛酉”的3/20、“癸丑 壬戌 辛丑 戊戌”的17/20。更正筛查标记会影响原有普通扶抑候选及事业、学业等派生文字；这不是新取得的原典喜忌判断或职业预测。55个完整场景的410处旧字段差异全部保存；隔离进程仅恢复旧标记和旧回执形状时，旧业务值及类型全部恢复，除本轮明示更新的限制说明。
