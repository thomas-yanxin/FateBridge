# 太乙主客算的数格与分源和数

`taiyi.count_assessment`读取同盘主、客算及实际太乙、二目位置，分别返回缺数、筹分解、长短、孤单数族、杜塞、位置配数与分源和数等级。各层分别解释，不合并为一个胜负分数，也不由模型改写算数或将位。定计数格归属及完整断法仍在总验收范围内，未因本组件而宣称完成。

## 修正未限定的足数标签

此前`main_count_des`、`guest_count_des`把15、25、35无条件标为“三才足数”。现在保留[卷六](https://zh.wikisource.org/wiki/太乙金鏡式經_(四庫全書本)/卷06)明列的无天、无地、无人，不从“未列缺数”推成“原典已认证具足”。十／五／一筹分解另作为明确模型：例如25为20+5+0，该模型不具足；16为10+5+1，该模型具足。具足标签明确写作`三才足数（数理推导）`。不能把模型中零部件直接补成原书的缺数枚举，例如25没有被改写为原书明载“无人”。

5、15、25、35按[《太乙淘金歌》杜塞条](https://zh.wikisource.org/wiki/欽定古今圖書集成/博物彙編/藝術典/第687卷#杜塞)补为`杜塞（淘金歌）`。这是算数类别，不等于已经计算的太乙八门全部落杜，也不新增为卷四五将第四项。原有宫数、算路、将位、关系列表及五将三值条件不变。

卷六“十一以上为长、单九以下为短”没有明定10，本层保持`is_long=null`、`length_label=原条未定`。孤阳、单阳、重阳等数族来自卷六所选组合，不用它们代替按实际方位计算的阴阳和不和。

## 五条文本读法逐项保留

| 所读文本 | 上和明列 | 次和明列 | 下和明列 |

| 四库本卷二王注 | 14、18、33 | 23、29、32 | 12、16、27、34、38 |
| NCL-06604明钞图39 | 14、18 | 23、29、32 | 12、16、27、34、38 |
| 淘金歌韵文 | 14、18 | 23、29；另有缩写“三六二”未裁定 | 12、16、27、34、38 |
| 淘金歌注文 | 14、18、23 | 29、32、36 | 12、16、27、34、38 |

因此23有等级差异，33在明钞未列不等于明钞否定其上和。`literal_rank_consensus`只在所选五条文本全部明列同一等级时返回该字面等级，不是总体和，也不认证五条文本同等可靠。`source_memberships`保留每条成员，`evidence_level`区分书影核读与待覆核转录。

淘金歌三才注文列11个数、未列37；秘书转录列9个数，含37而未列19、29、39。这些未列项均不是否定，亦不改十／五／一推导。秘书另录44、48为阳中重阴，超出当前1至40主客算范围；原字、数值及状态保留在`unadjudicated_source_readings`，没有改成24、28或扩域使其通过。缩写“三六二”也原样保留。

## 按实际位置配数

[卷二阴阳和不和](https://zh.wikisource.org/wiki/太乙金鏡式經_(四庫全書本)/卷02#推隂陽和不和)以太乙八三四九为阳、二七六一为阴；二目立正宫为阳、立间神为阴。阳参照配偶数、阴参照配奇数为和，同性配数分别记重阳或重阴不和。它使用本盘实际参照，不按九宫数字奇偶猜宫性，不把间神并入八门扇区。

每个主客算分别返回太乙宫与对应二目的`contexts`，带实际字段路径和值。比如算33、太乙九宫，位置配数为不和，即使四库王注和数清单列了33上和，也不能覆盖该计算。两种参照的综合权重和完整断语尚未裁定，`overall_harmony_assessed=false`，不输出共同胜率或现实成败。
