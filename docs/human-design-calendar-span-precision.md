# 逐年历法采样与名义太阳圆盘内的视位置分歧

[人类图说明](human-design.md) · 本轮验收记录（本地数据：`validation/human-design-calendar-span-verification.json`）

本轮新增独立采样，发现所选Swiss后端与原定DE440／Skyfield计算流程的一个超差点，保留失败后继续查找原因。没有改动生产星历算法、原122个参考时刻、原228个Moshier超差点、原典数据或2角秒门槛。

## 新参考如何固定

计划（本地数据：`../tests/fixtures/human-design-calendar-span-plan.json`）在取得新参考位置及运行生产对照之前固定：1800—2399年每年3月1日和9月1日正午TT，共1200个出生时刻。使用与原参考相同且散列一致的NASA DE440文件、Skyfield1.55、jplephem2.23和NumPy2.5.4，独立求出每个88度太阳弧设计根，并保存两侧各十个目标的视位置，共24000项黄经参考。

[生成器](../scripts/gen_human_design_calendar_span_reference.py)不导入FateBridge或Swiss。它采用[Skyfield的观测、光行时和视位置流程](https://rhodesmill.org/skyfield/positions.html)，投影到[当日真黄道与春分点](https://rhodesmill.org/skyfield/api-framelib.html)。再次独立生成的JSON逐字节相同。新旧全部TT位置集合互不重叠；原122项出生时刻、2440项位置以及失败报告保持独立，没有以新集合替换旧集合。

这覆盖600个出生TT年份的两个固定季节点，不等于600年全部民用输入、历史时区记录或连续细分边界验收。两侧星体目标仍按原约定：日月地心、行星系统质心。它不是新的官方人类图命盘、出生记录或原典语义真值。

## 对照实验定位到了什么

在失败之后另行固定9个相邻TT时刻，取中心前后1日、半日、四分之一日、八分之一日以及中心。它们是针对已知失败的诊断，不能算作预先盲测，也不替换1200项冻结参考。

中心处天王星与太阳的地心天球角距约0.02928度，以IAU名义太阳半径换算的角半径约0.27019度，目标投影落在名义圆盘内。这不是对真实遮掩、太阳不透明边缘或可见性的认证。在相同9个TT，分别保留Swiss原有压缩星历、Skyfield同一DE440文件及各自黄道口径，单独关闭两套流程的引力偏折后，天王星和太阳共18项黄经差均小于0.00045角秒。天王星中心点的黄经差降至约0.0000368角秒。默认结果的显著差异因此被定位到偏折处理，而不是通过修改时刻或拟合补偿消除。

[Swiss文档附录A](https://www.astro.com/swisseph/swisseph.htm)明确解释：遮掩期间没有可直接观测的行星视位置；它用透明的太阳质量分布延拓这个计算值。所用Skyfield默认源码则采用其点质量偏折公式。两者在太阳盘内的延拓不同。诊断记录（本地数据：`validation/human-design-calendar-span/deflection-diagnostic.json`）保存了默认与关闭偏折两组数值；关闭偏折只是隔离变量的实验，生产算法和冻结参考均未切换。

另取得同9个TT的太阳和天王星[JPL Horizons](https://ssd.jpl.nasa.gov/horizons/manual.html)原始响应。Horizons第31量采用IAU76/80当日黄道，不能把它与另外两套流程的原始黄经直接视作相同坐标约定的零误差真值。它在太阳遮掩附近也显示不同数值，因此没有挑选较容易通过的一套结果替换验收。原始查询、响应、散列、失败抓取日志及控制实验源码均留存。

这不是对哪套延拓符合人类图原始软件的裁定，也不是现实观测认证。仍需更强的计算规范或原软件证据；本轮保留该分歧和原超差状态。

后续公开爻界与历史钟时诊断（本地数据：`validation/human-design-solar-disc-clock-v1/README.md`）取得有限的软件行为证据：1919年火星及2032年木星等公开爻位与Swiss默认相同、与同TT的Skyfield默认不同；1840年另有海王星失败和75秒钟时分歧，不能据此统一全部口径。原22项仍缺九份图表，所有原位置阈值和失败继续保留。新核验器分别显示原始计数及钟时链接，避免把不同瞬间的比较直接归为星历误差。

## 完整回归中的顺序污染

上一轮开始的2356项完整回归实际结束为2348通过、8失败。失败日志和XML完整保留在前轮记录（本地数据：`validation/human-design-primary-source-followup-verification.json`），未用孤立通过的案例替代这次机械结果。

复现表明，一个安装测试将显式“空星历目录”写入全局配置，环境补丁恢复后，全局配置仍指向该目录。后续同进程测试实际转入Moshier，因而没有独立后端参考，周期结果也与新进程的默认Swiss文件路径不同。同一组四项顺序案例修复前为1通过、3失败；增加测试结束时的配置恢复后为4通过。

只新增了安装测试模块的清理夹具；原测试函数、断言和空目录案例的AST保持一致。没有让生产计算忽略显式空目录，也没有删去任何失败测试。原8个失败案例连同触发案例的顺序复核已为9项全部通过；修复后2363项完整回归也已全部通过。原失败的完整运行仍保留。回归期间有无关政余／宿曜源码并行变化，已记录散列，因此不把这次结果称为整个源码冻结后的安装包验收；它也不覆盖后续新增的太阳投影功能。
