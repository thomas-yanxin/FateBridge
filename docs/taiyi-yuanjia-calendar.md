# 梁历表、元嘉平朔与太乙同元历分别核验

元嘉平朔算法能重现所选501—505年历表的63个月首干支、62个月长及1831个逐日干支，但502年闰月标签仍有冲突。月首、月长、月序和完整日期须分别验收；这些相位相符没有恢复王希明的同元四分历，也没有接通梁例原积日。

## 原典与历法身份

《隋书》卷17[固定修订2180305](https://zh.wikisource.org/w/index.php?oldid=2180305&title=隋書/卷17)记梁初沿用宋元嘉历，天监三年诏定历，至九年正月改颁祖冲之甲子元历。该条本轮只核转录，未新核隋书书影。[国立天文台元嘉历说明](https://eco.mtk.nao.ac.jp/koyomi/wiki/B8B5B2C5CEF1.html)亦列445—509年、平朔平气及雨水基准。历法时代归属提供研究依据，不能将所有民用历表、月序及太乙原典宣布为同一算法。

《宋书》卷13元嘉历法的完整所选书影为3图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page3-render.jpg`）、4图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page4-render.jpg`）、5图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page5-render.jpg`）、6图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page6-render.jpg`）、7图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page7-render.jpg`）、8图（本地数据：`../tests/fixtures/taiyi_jinjing_v35/songshu-page8-render.jpg`）。它们是Commons服务器整页渲染，清楚标记渲染尺寸，未称作原生位图或全册校定。原册为CADAL06058834，来源及指纹见检索记录（本地数据：`../tests/fixtures/taiyi_jinjing_v35/retrievals.json`）。

原文443年上元积年5703，另记入甲午纪231年，两个锚一致。元法3648、纪法608、章岁19、章月235；日法752、通数22207；次月加29日和小余399，满752进一日，小余353以上为大月。7图写的是“以通数乘积分”，与当前整理转录的“乘积月”有字面差别；本实现以积月为被乘量属于明确的量纲解释，没有改原字。

## 保留分数与历元范围

验证组件先按入纪年求积月及闰余，再以整分数保留全部经朔小余。雨水平气采用原载1595／304年余，按纪日222070／608展开到同一纪内数轴，逐气加15日、66／304日和11／(24×304)日；月、气分别保留分母。比较时同时保留“以整日分配中气”和“以完整分数分配中气”两项解释，没有按相符数量选择。

这里的六纪甲子、甲戌、甲申、甲午、甲辰、甲寅提供日相位。六十日相位相同不证明绝对儒略历元；本轮没有据一个月首倒填绝对历元，再声称重算出了所有公历日期。历表原儒略日期的整数JDN、星期及干支校核另列，不与算法的相位比较混算。

元嘉朔月为22207／752日，明钞王氏参数为1447／49日，两者相差1／36848日。参数很近仍不是同一历法；不同上元和初始小余也不能互换。禁止用元嘉参数补王氏常数，或以元嘉相符消除金镜初八、积日、始击及授时入纪分歧。
