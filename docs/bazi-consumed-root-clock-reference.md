# 原全量消费根的独立时标核对

本轮进一步区分了原包络失败中的根值、数值表示、时标转换和模型组成差异。对原116,906条保存记录、812,868份单点观察所涉及的全部2,357组实际消费根，先冻结7,071份独立条件时标答案，再调用实际精确点转换函数，结果全部相符。这个结论支持当前显式精确点转换在所选政策下的数值正确性，未关闭原严格包络条件、原41项默认浮点冲突或现实预测效度。

## 完整范围与参考来源

事前协议（本地数据：`validation/bazi-consumed-root-clock-reference-v1/protocol.json`）按原全量保存队列选择资料，未限于上轮4,436条前缀，也未按失败或有利方向筛选。116,124条已知记录中的每条七份观察均纳入根身份映射；782条未知的原来源对象和保存对象保持。全部已知记录各自的七份观察均消费同一组根资料，去重后为2,357组；原次序、ID和全部映射归档。

每组根保留三个TT输入：原Skyfield标量根、此前独立采集的Skyfield双段根、程序实际消费的双段根。独立根沿用已冻结的1899—2101年4,872根数据，本轮没有安装或重新运行Skyfield求根，也没有把其旧单浮点根改写成程序新结果。原根值和原民用标签全部保留。

参考生成不导入FateBridge。1960年以后按未修改的[IAU SOFA 2023-10-11原始资料](https://www.iausofa.org/2023-10-11c)解析分段系数，用有理数闭式反解得到5,079个条件原子时制点。1960年以前的1,992个点使用90位Decimal、120步二分及共同的Swiss `DeltaT(-1)`模型，与生产的固定点/Fraction路线不同；它验证既定UT1/Delta-T约定，不是独立历史钟表观测。TT、UTC等时标的区别也见[Skyfield时间文档](https://rhodesmill.org/skyfield/time.html)。

独立答案（本地数据：`validation/bazi-consumed-root-clock-reference-v1/independent-reference-first.json.gz`）和冻结收据（本地数据：`validation/bazi-consumed-root-clock-reference-v1/reference-freeze-receipt-first.json`）在比较保存标签及执行实际转换前写入并散列。每点的精确有理数TT、方法和限制都保留；未来原子偏移仍为冻结表条件，未认证未来UTC。

## 分开四个环节

令`S0`为原标量根，`S1`为独立双段根，`P`为实际消费双段根，`F`为上述独立条件转换，`C0`和`Cp`分别为原标签和实际标签。逐组保存有符号分解：

```text
Cp − C0 = [F(S0) − C0] + [F(S1) − F(S0)]
        + [F(P) − F(S1)] + [Cp − F(P)]
```

每项都是舍入后的标签差；不能将它当成未舍入物理时间误差的唯一分解。全部正负量与逐项抵消保留，和式本身也不证明哪个太阳模型物理上更准。

| 环节 | 非零组数／2,357 | 最大绝对标签差 |
| --- | ---: | ---: |
| 原标签与同一原标量TT点的精确显示 | 2,330 | 34微秒 |
| 同一Skyfield模型的标量根改为双段根 | 2,331 | 41微秒 |
| 独立Skyfield双段根与实际模型双段根 | 2,357 | 16微秒 |
| 实际消费根标签与其独立精确点显示 | 0 | 0微秒 |

完整分解（本地数据：`validation/bazi-consumed-root-clock-reference-v1/assessment-first.json.gz`）保留每组的原资料、三份参考答案及各项差量。1960年前664组、1960—1971年144组、1972年以后1,549组分别列账，没有将原子时制的独立事实表信用转移到UT1/Delta-T约定。

第一行说明旧标签没有达到同一TT数值点的微秒精确显示，不能直接称为2,330项物理错误；第二行包含数值表示与有限求根的差别；第三行包含不同视黄经模型组成，已有[模型层次审计](bazi-solar-model-layers-audit.md)进一步核对。不能为了逐微秒匹配Skyfield而任意删去太阳势项、替换模型或拟合偏移。

## 实际转换与可复现性

独立答案冻结后，使用先前冻结的实际运行时，对全部三类精确TT输入调用`datetime_from_tt_point`，共7,071次，全部精确相符（本地数据：`validation/bazi-consumed-root-clock-reference-v1/actual-clock-first.json.gz`）。这是实际函数的同点数值核对，没有重新搜索节气根，亦未采用源标签反推答案。

第一轮记录了版本，但未对加载模块和原生二进制做完整前后守卫。按新增的事前依赖协议，在两个独立进程分别复放参考生成与实际转换：参考过程守卫220个加载文件，实际过程守卫399个加载文件，均无变化或新增加载文件；两轮完整参考输出、完整实际输出分别逐字节相同。实际过程有三个明确披露的分时代预热调用，不计作新增验证行。没有声称散列整个操作系统或获得跨平台认证。

首轮七项冻结证据检查通过；增加依赖核对后八项通过，旧检查全部保留。验证覆盖原队列次序、未知、812,868份观察的身份映射、三种根输入、参考先于比较、禁止参考生成读取交付标签、逐组有符号分解及全部实际点结果。首次材料和收据继续保留。

本轮没有改动生产计算或共享合同，因而没有新增REST/MCP/CLI、安装包、部署或真实模型验收。当前时标、TT表示、历法消费与DE440源码与已验收的冻结父版本相同。

## 原失败继续保留

最近一次完整原队列结果仍为54,818条严格失败，原40,219条历史证据不变；正在运行的新全量候选复放也未受本轮只读分析影响。明确区分同根算术、精确点转换与跨模型包络，是继续定位的依据，不能用本轮7,071项相符替代原13项严格判据。

原41项是旧默认裸浮点入口的精确点冲突，区别于本轮的显式精确TT类型。此前仅改默认参数的候选新增14项共享控制失败，已拒绝采用：同一个IEEE值可能是一个明确数值点，也可能是某UTC标签的舍入编码，原数值本身无法恢复输入意图。该候选、原41项记录和两类判据保持；本轮没有重新迁移默认参数，也没有宣布41项关闭。

原26处分歧历史、五例真实模型机械0/5及现实预测未验证的状态保持。本轮缩小了可归责的计算环节，没有给出全书符合、物理精度或权威满分声明。
