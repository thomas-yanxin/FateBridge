# 八字二十四节气TT独立实现比较

首轮将当前计算与独立生成的二十四节气参考逐点比较。数据覆盖1899—2101年，每年24点，共4,872点；包括出生范围1900—2100年前后相邻年份的依赖。本范围不覆盖未设上限的所有分析年份，也不等于全部民用时标和输入边界均获认证。

## 参考及冻结顺序

参考由[Skyfield官方节气接口](https://rhodesmill.org/skyfield/almanac.html#solar-terms)及JPL DE440生成，使用地心、日期视黄经、IAU2000B章动和TT时标。完整DE440的MD5与[JPL公布的校验和](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/aa_checksums.txt)一致；原核文件SHA-256也记录在协议中。

协议（本地数据：`../tests/fixtures/bazi_all_terms_v1/protocol.json`）先冻结范围、1秒门槛、比较时源码散列及独立采集方法；随后完整采集参考并冻结散列，最后才运行FateBridge比较。独立采集器不导入FateBridge，也不采用生产交气点或线性近似作搜索边界。每月前一节气用TT的1日到12日、后一节气用12日到28日作固定包围区间；逐点核对前后节气索引后进行40次二分，参考最终包围宽度不超过1毫秒。该宽度是数值收敛指标，不能直接视为物理准确度。

源码、时标及锁文件在首轮协议中绑定。原生Swiss数据文件的完整清单在首轮之后另外记录，不能用后记录清单证明首轮期间文件持续不变；来源清单（本地数据：`../tests/fixtures/bazi_all_terms_v1/provenance.json`）明确保留这个限制。

## 原始首轮结果

| 实际模型 | 满足1秒门槛 | 超出门槛 | 最大绝对差 |
| --- | ---: | ---: | ---: |
| 加载Swiss数据文件，返回标志为swieph | 4,872 / 4,872 | 0 | 0.060511秒 |
| 强制空星历目录，返回标志为moshier | 4,371 / 4,872 | 501 | 2.097514秒 |

全部比较行、实际模型、民用时刻标记方法和未来闰秒假设保留在不可覆盖的首轮记录（本地数据：`validation/bazi-all-terms-first-v1.json`）。Moshier的失败分布涉及全部24种节气，不能仅报告立春或删除误差较大的年份。该结果尚未使Moshier达到原定1秒标准，不能通过放宽门槛、停用原先支持的Moshier路径或换一套更容易通过的参考来宣称满分。

## 能证明及尚不能证明的内容

这是TT上的独立实现比较，不是观测数据，更不是现实预测实验。生产输出民用时刻后再按同一时标政策换回TT，因此本次隔离验证的是天文交气计算，不能同时验证该民用时标政策本身。1961年前的UT1标记、1961—1971年的UTC漂移、未来未知闰秒及历史时区必须另有证据。

203个立春点与既有风水DE440参考重叠。二者使用同一JPL数据和Skyfield方法，重叠点不能作为另一批独立复现累计计数。此参考集也是开发阶段验证，不冒充未见留出集；后续修复的结果须另外记录，不替换本首轮。

与[线性回退拒绝修复](bazi-solar-provider-audit.md)、[时区回放锚点修复](bazi-timing-anchor-audit.md)、[农历范围补充](bazi-lunar-range-audit.md)共同看待当前历法能力。三项目标要求（本地数据：`validation/bazi-three-axis-requirements.json`）继续保留未证实状态和原典不符记录，不从这个有限组件比较推导全局满分。
