# 八字包络失败的节气根与钟时分解

原严格包络门槛仍失败：旧40,219条证据保留，V33及后续已完成复放的结果为54,818条。本轮没有修改生产计算、原参考、容差、窗口或失败标签；完成了覆盖全部116,906条记录的归因检验。

## 独立对照

使用未修改的[Skyfield 1.53节气接口](https://rhodesmill.org/skyfield/almanac.html#solar-terms)与同一完整DE440内核，从预先固定的半月TT区间重新求取1899–2101年全部4,872个节气。双段TT避免先把小数与大数儒略日相加；两端的节气索引均保留。数值括区间最大约4.9纳秒，只描述有限浮点计算的括区间，未认证该物理精度。

事前协议（本地数据：`validation/bazi-root-clock-factorization-v1/protocol.json`）、首次独立结果（本地数据：`validation/bazi-root-clock-factorization-v1/independent-roots-first.json.gz`）和[实际生成器](../scripts/collect_bazi_split_skyfield_roots.py)分别保存范围、数据和方法。生成过程没有导入FateBridge，也没有使用生产根或旧参考根作为搜索种子。材料已有暴露，不增加独立观测或盲测信用。

另从[IAU SOFA 2023-10-11](https://www.iausofa.org/2023-10-11c)未改动的原始 `dat.c` 解析UTC分段常数，以有理数求解原子时制，并核对原始 `taitt.c` 和 `sofam.h` 中TT−TAI的32.184秒常数。该独立过程没有导入FateBridge、Swiss或ERFA运行库。

在1960年以后的3,408个节气上，旧单浮点TT点与新双段TT点各有一次UTC比较，共6,816个数值点，与当前精确点转换全部相等。1960年前的1,464个根明确保留为本原子时制参考不可用；UTC以前的UT1/Delta-T政策没有因此获得独立认证。未来闰秒仍是假设，表中原子偏移不构成对未来UTC的预测。

## 分开的三个量

| 检查 | 范围 | 实测结果 |
| --- | --- | --- |
| 同一Skyfield模型：旧单浮点根与新双段根 | 全部4,872根 | 最大TT位移约40.225微秒 |
| 旧民用标签与旧TT数值点的独立精确换算 | 全部3,408个原子时制根 | 3,386条不同，最大35微秒 |
| 生产模型与新双段Skyfield模型 | 全部2,357个实际被消费的节气根 | 最大TT差异约16.069微秒 |

第二项是在同一数值点、明确原子时制政策下的标签差异，不认证历史钟表的真实误差。第三项保留模型口径差异，没有把Skyfield值作为拟合偏移。旧标签与旧合同仍原样保留。

普通公历仿射单元中，起运政策会将根差异放大约120倍；在进位、跳时等不连续边界，还须另行分析。源根表示、时间转换和太阳模型差异应分别追踪。
