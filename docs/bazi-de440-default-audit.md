# 默认交节使用随包DE440轨道系数

当前源码及对应构建包的默认`auto`在1800—2200软件年份范围内使用`fatebridge_de440_solar_v1`。原始地球、地月质心及太阳轨道系数随包分发，运行计算无需额外安装NumPy、jplephem或pyerfa，也无需下载、配置外部SPK文件。TT与民用时刻转换继续使用既有时标政策和基础依赖。

这轮针对[上一轮分钟判定](bazi-spk-solar-audit.md)发现的缺口：通过一秒TT门槛，仍可能把整分钟输入分到错误月令。原默认解析路径的四个月界、五个节气侧反例，以及原生Swiss文件路径的一个节气侧反例，均保留原始结果；没有回写成通过。

## 原始系数与生产者

固定方案（本地数据：`../tests/fixtures/bazi_de440_default_v1/protocol.json`）先声明来源、裁取区间、对照全集和门槛，再执行候选。原始文件是[NASA/NAIF完整DE440](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440.bsp)，SHA-256为`a4ce9bf9b3282becc9f4b2ac3cebe03a2ae7599981aabd7265fd8482fff7c4b5`。[DE440论文入口](https://ssd.jpl.nasa.gov/doc/de440_de441.html)列出Park、Folkner、Williams与Boggs的原始研究。

提取器仅选取`0→3`地月质心、`3→399`地球和`0→10`太阳的Type2、参考系1记录，覆盖1798—2203 TDB的完整相交记录，给1800—2200的交点和光行时留出余量。共55,474条记录、17,751,664个原始字节；gzip后16,914,623字节。原有系数、次数、MID与RADIUS逐字节保留，没有采样重拟合、舍入或读取基准交点生成运行数据。

随包文件是FateBridge制作的衍生系数产品，名称、存储格式与原始SPK区分。[来源清单](../src/fatebridge/data/astronomy/de440-solar-v1.json)分别列出本产品生产者、原始内核来源、分段记录和原注释档案，遵循[NAIF关于衍生内核的署名及更名说明](https://naif.jpl.nasa.gov/naif/rules.html)。它不是NASA发布的未修改内核；原始来源与软件验证均不构成机构对FateBridge的背书。

## 时间与参考系

运行器使用标准库读取原始浮点记录，以切比雪夫递推计算位置及解析速度。地心状态由地月质心加地球相对地月质心向量得到；地月质心不能直接当作地心。[SPK Type2说明](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/spk.html)是记录格式依据。

TT通过完整787项Fairhead地心模型及原质量调整项转成TDB，观测者`u=v=0`。系数来自[固定提交的ERFA dtdb](https://raw.githubusercontent.com/liberfa/erfa/9915ba38c9365f8b0738269b8c2ac1fdd5f8dee3/src/dtdb.c)，完整ERFA许可随包保留。原说明的1950—2050比较范围继续公开，不能扩写为本软件所有年份的物理精度保证。

随后进行三次太阳光行时迭代、周年光行差、IAU2006/P03与IAU2000B日期真黄道转换，再在固定月份区间二分求交点。没有使用误差拟合项。根区间宽度是浮点数值分辨率，不能当作真实出生时刻或物理天文精度。

## 策略与失败语义

| 配置 | 使用方式 |
| --- | --- |
| 默认`auto` | 范围内使用随包DE440；严格原生JPL配置优先；范围外维持原生路径 |
| `de440` | 显式使用随包系数，超出声明软件范围拒绝 |
| `native` | 保留原生Swiss／Moshier／严格JPL对照 |
| `analytic` | 保留此前ERFA epv00解析路径及其原始失败 |
| `spk` | 保留显式外部SPK路径，需要可选`jpl`依赖和指定文件 |

首尾年份的相邻交气现采用输入年所选模型：1800年的上一年边界、2200年的下一年边界可读取1799／2201已有轨道记录，并附 `adjacent_boundary_context_year` 与 `solar_model_input_years`。独立请求这些年仍沿用原有范围策略；没有扩展显式模型的公开输入范围。此前显式模式会因提前读取邻年而拒绝合法首尾输入，自动模式会混用原生边界，修复与96根有限核验见首尾跨年验收（本地数据：`validation/ren-calendar-guard-validation-2026-10-23.md`）。原数学报告对应其冻结版本，不能将旧的全域成绩直接移给新版本。

显式`analytic`、`de440`或`spk`与严格原生`FATEBRIDGE_JPL_FILE`冲突时拒绝。随包数据缺失、损坏、时标系数非有限或请求越出实际覆盖时明确报错，不静默换成近似结果。

```bash
uv sync --locked --extra dev
uv run --locked --extra dev fatebridge jieqi_year --year 2022
```

元数据分别返回原始内核SHA、实际载入系数及清单SHA、地心TDB系数SHA和参考系系数SHA。`resolution_provider=jpl_de440`与独立模型名共同标识本路径；原生返回标志为空，不借用Swiss标志。`accuracy_certified=false`保留。

## 首次结果与完整有限验收

首次完整数学结果（本地数据：`validation/bazi-de440-component-first-v1.json.gz`）保留166,422个分段端点／中点、1,024个预声明时标点、512个既有一般时点，以及全部9,624交点和其中原4,872点。数值门槛未出现失败，但运行期间共享错误码文件改变，来源守卫失败，整体未计通过。

另一次加载器故障检查发现NaN时标系数未被拒绝，已补充有限数值校验；首轮覆盖范围断言使用了错误的日期常数，现按原方案日期构造勘正。原测试文件、原失败与修订前冻结补充方案（本地数据：`../tests/fixtures/bazi_de440_default_v1/integration-addendum.json`）分别保留。后续从不可变源码完整复验，不能删除首轮失败或将验证器修正记作天文算法进步。

不可变源码的完整复验（本地数据：`validation/bazi-de440-component-accepted-v1.json.gz`）中，166,422个插值检查全部在原1毫米位置、`1e-5 km/day`速度门槛内；最大位置实现差约0.089毫米。1,024个时标点、512个一般时点和全部9,624交点均满足原门槛，最大交点TT实现差约0.0000805秒，来源守卫通过。

原分钟队列的端点未知项继续保留；年、月、流月、流日十二节窗口与相邻节气分别统计，没有把整张四柱对象存在当作日／时柱也获得独立验证。新旧队列重叠，不累加为独立观测或盲测。

源码主回归129项、证据保护4项、共享消费端14项通过；基础环境未安装上述三组可选库，冻结包内51项通过。源码和包的新进程MCP各对六个旧反例还原同run历法投影，每例14页并验证UTF-8散列。它们不认证任意自由文本或既有长期连接的部署。

综合`analyze_destiny`与标准盘`bazi_birth`分别核对：标准盘加九专题支持REST／MCP／CLI；综合按实际公开范围检查MCP／CLI完整结果、历法投影和数据故障，源码及冻结包各3项通过。未把标准盘冒称综合验收，也未创造综合REST入口。

首次接口套件中的工具键、REST控制参数位置错误与旧默认断言均保留；只破坏原生求解器的旧故障注入现显式选择`native`，原17个接口、8个领域操作及错误期望保留。另对同17个公开入口检查新默认数据故障，未删除失败病例。首轮中断记录与完整复验分别列于本地验收（本地数据：`validation/bazi-de440-default-local-v1.json`）。

运行回执曾使未使用太阳模型的知识查询在轨道数据故障时返回500，现只解析实际使用的独立太阳来源；需要该数据的排盘仍返回不可重试的结构化故障。严格原生JPL选择也不加载未用的随包系数。风水消费端保留原有五秒候选操作窗口；它没有成为交点精度容差。六壬／金口诀与风水的说明区分实际载入系数产品和原始SPK来源。

完整数学回放使用其冻结源码；后续修复仅涉及未使用来源、配置冲突顺序、操作保护和说明，数值函数、轨道数据、参考系、时标及八字消费数学的字节／语法树保护另行核对。最终包919个运行时文件逐项等于对应快照。构建、基础依赖与新进程接口的通过均未替代全仓CI或发布验收。

## 保留的完整目标

这些参考共享DE440数据，插值／时标／参考系和消费端实现分别比较，不是新的独立物理观测。历史钟时、未来闰秒、真太阳时、真实出生记录及全部日／时柱和交运组合仍需各自证据。原接口只接受出生小时、分钟，分钟省略时仍按现有契约取0；小数秒求根不会补足未知出生秒数。

本轮未改旺衰权重、原典标签或采用门槛，也未新增真实模型作答、独立专家审查或现实预测样本。26个原典不同输入分歧与解释验收缺口继续保留，不把默认历法组件改进换算成三项满分。
