# 当日冲空与同日日克的控制资格

第三十一轮解决了一个原典条件被过早留在未知的问题：程序已经确认静爻当日冲空而活动，却又因为同一日辰的五行克制而阻断其动克静资格。同版原例中的寅木因此不能进入已匹配的控制条件。

依据为 NLC 1925 书影（本地数据：`../tests/fixtures/liuyao_scan_v3/sources/nlc-1925-zengshan.pdf`）第 51、58、67、84 页。第 51 页必须区分问者与作者答语：问者套用寅生午的接续相生说法，作者解释午化未而合、未能生辰，辰仍受寅木之克。第 67 页给出旬空被日辰冲起而为用；第 58 页的动克静不先要求动爻自身旺相，第 84 页明确暗动也有作用于用神的分支。此处使用作者的控制答语，没有把上一轮撤回的问者生扶探针改成通过。

新增资格只覆盖原来静止、当前旬空且逢本日正冲、没有原月破、日月反制列表仅含同一日辰已确认五行克制的来源。它解除该来源的日历层控制未知，随后仍审活动资格、其他活动爻反制和目标动静。明动受日克、月破、回头克、合绊以及独立或未知的三刑反制不因此放行。规则不含卦码、公历日期、案例 ID 或参考结果查表。

原旬空身份和日克原始事实继续返回；`source_void_fill_control_condition` 是这项局部资格，`source_void_fill_used` 表示来源日历门槛使用了它，均不等于最终控制已生效。其他动爻或活动目标仍可令最终条件未知。本位回头生的 `source_rescue_used` 不会被冒用。新的资格、来源页、三接口字段及说明由同次结果提供。

这次没有由控制资格推导生扶资格、总旺衰或现实成败。原例的寅木控制条件得到匹配，午火合绊及接续相生路径的限制仍保留；原有生扶层不是本轮新增原典裁决。第 30 轮的问者归属勘误、失败探针和未决记录保持原样。

初始 12 个冻结结构中，原例及四个开发正例共 5 项失败、7 个反例通过。新规则后，26 项领域检查与 28 项三接口检查通过；它们不代表 54 个独立古例或现实预测样本。另有三刑独立反制的压力检查，保留首个审阅断言错误及修正说明：原反制归属为月寅，必须按三刑来源路径识别，不能强认其位置标签为 `pattern`。

还发现第 30 轮公历映射勘误（本地数据：`validation/liuyao-v31/v30-public-mapping-erratum.json`）：2000-06-19 实为戊申，不能与庚申领域案例视为完整同一输入。旧检查实际只验证了相同申支下的三支与说明，没有证明完整干支等价。原始结果不改；新增 2000-07-01 的完整庚申对照，并在本轮全部公历映射中断言月建和完整日干支。公历年份用于工程验证，不是原书年代复原。

五个不适用新资格的旧完整结果继续逐字段比较。兼容辅助先断言所有新资格和使用标志均为假、来源资料准确，才去除新增说明字段、一个来源条目和一个范围句，按明确的 `2.18.0` 版本比较；原控制真假、状态、生克方向、历法值和原始 JSON 均不删除或重写。
