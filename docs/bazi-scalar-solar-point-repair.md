# 解析与SPK节气根的显式TT点值修复

备用解析／SPK节气消费分支现明确按数值求得的IEEE浮点TT点转换，不再让默认兼容入口把它解释为原UTC标签编码。原6,391条消费层控制中，3,930条正常值精确相等，243条不可表示标签全部拒绝，2,218条历史未知与已保存的显式点值结果相同。旧全局标量入口的41项冲突仍按原门槛保留，没有转计为通过。

## 计算改动与完整旧门槛

采用前协议（本地数据：`validation/bazi-scalar-solar-point-repair-v1/protocol.json`）先绑定原源码、完整首败、原点值参考及旧41项记录。解析／SPK无双分量结果时，改用`datetime_from_tt_point(TTInstant.from_float(jd))`。原默认两段式DE440表达式、太阳求根器、时间转换函数及原典强弱计算字节均保持；另更新节气缓存策略标识，防止不同消费语义混用旧缓存。

单浮点模型结果新增`numerical_epoch_representation=explicit_ieee_float_tt_point`及`scalar_jd_scope=exact_value_of_selected_ieee_float`，明确声明输入意图。精确点值语义不表示天文根或出生记录达到微秒物理精度。两段式默认模型仍声明其标量仅为展示值，未把两分量相加后重新用于计算。

完整消费层结果（本地数据：`validation/bazi-scalar-solar-point-repair-v1/consumer-candidate-first.json.gz`）与未修改调用方首败（本地数据：`validation/bazi-scalar-solar-consumer-v1/baseline-first.json.gz`）分别保存。全部原编号、状态和预期不变，新增审计器明确核对归档的原源码和新冻结源码，不通过跳过旧源码守卫掩盖修改。合成控制只隔离求根之后的转换，不冒充真实节气；已知控制也分别通过解析和SPK两个调用分支验证。

## 实际节气配对及历史标签变化

在实际计算前固定1900、1960、1972、2000、2026、2100六个完整年份，每年24节气，依次覆盖默认、原生、解析、SPK四模式，共576项。完整DE440内核、依赖版本、前后运行时均绑定散列。原实际计算（本地数据：`validation/bazi-scalar-solar-point-repair-v1/actual-grid-before-first.json.gz`）与新实际计算（本地数据：`validation/bazi-scalar-solar-point-repair-v1/actual-grid-after-first.json.gz`）保留全部结果。

所有已交付的求根值与数值括区间不变；默认两段式DE440的144份完整节气结果、未修改原生模式的144份完整结果逐项相同。解析与SPK在1900、1960年共96个历史标签变化，最大21微秒，其余实际时间标签未变。

独立数值核对（本地数据：`validation/bazi-scalar-solar-point-repair-v1/actual-grid-assessment-first.json`）使用90位Decimal，未导入FateBridge换算函数：1960年按[所保存SOFA仿射系数](../src/fatebridge/data/knowledge/western-utc1960.json)闭式反解；1972年后按冻结原子偏移求解；1900年用二分法求解同一Swiss ΔT约定，区别于生产中的有理数固定点迭代。后者共享ΔT模型值，不是独立天文或历史钟表观测。

全部432个实际交付TT根与声明的数值换算政策相等，旧96个标签差异不再出现；原生模式未交付TT根的144条保留为无法据所交付根核对，不能用完整结果未变替代根值正确性。配对结果未发现来源、根值或其他数值的未解释变化。

独立参考实现是在发现96个历史标签差异后、执行独立核对前冻结；不是事前盲参考。允许变化路径是针对明确转换语义作的因果核对，没有改原预期、容差或已失败门槛。时序补充说明（本地数据：`validation/bazi-scalar-solar-point-repair-v1/actual-reference-timing-addendum.json`）保留这一边界。

## 共享回归和独立交付

冻结回归159项通过，涵盖原点值／默认标量对照、解析模型、SPK、默认DE440及缓存、完整与摘要三端输出。另有两项历史检查通过：原506条输入、7项首败、4项未知原样保留，未靠重标来源调整提高通过数。显式模型根无法转换为datetime时，错误会传播，不能发布线性近似年作为成功结果。

源码独立MCP进程在默认、解析、SPK三模式完成12次有效调用、3次缺项拒绝、450页同次结果散列及93个实际消费根检查。基础安装包在默认、解析两模式完成8次有效调用、2次缺项拒绝、306页同次结果散列及62个实际消费根检查，另有两次实际安装包CLI调用。安装包1,121个包文件逐字节等于冻结源码，基础环境实际满足84项适用锁定依赖；该基础环境没有SPK可选依赖，不声称安装包SPK验收。

首轮回归155项通过、4项因冻结副本漏带旧回执或散列文件失败；补齐真实依赖后按相同源码和相同断言完整重跑159项通过。stdio首轮仅发布八字族，漏发大运所在timing族；修正测试进程范围后通过，生产工具范围与计算条件未改。一次排错调用还误用不存在的工具名，诊断原文保留。上述统计来自成功的完整验收运行，不把失败尝试删除或汇总成通过。

格式、导入顺序、两个源文件的类型检查及当前调用合同、场景生成检查通过。1,135个冻结运行时文件与验证材料前后散列保持；源码增量和验证输入归档实际恢复核对通过。旧回执、两版测试输入、首次失败、当前工作区合同检查和冻结计算验收分别保存，未宣称全仓回归、所有宿主或部署验收。完整本地收据（本地数据：`validation/bazi-scalar-solar-point-repair-v1/local-report.json`）列出各层结果。

原生Swiss数值根的默认标量消费分支尚未由本轮修改，其错误与降级路径仍需另行验证。54,818条跨根包络失败、旧41项全局标量冲突、24处现行原典分歧及原5例解释机械0/5继续保留。共享MCP未重启，未发布部署，没有新增模型执行或现实预测效度成绩，整体目标仍未完成。
