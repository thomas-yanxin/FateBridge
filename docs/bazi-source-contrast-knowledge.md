# 可查询的原典比较知识

本地新进程现可通过 `knowledge_read` 读取 `bazi/source_contrasts/只换一字与干支联动`，也可只传词条键自动定位分类。词条新增于独立补充包；原有 85 条八字词条、3 条基础概念及其完整服务返回均保持原值。

```sh
uv run --locked --extra dev fatebridge knowledge_read \
  --domain bazi --category source_contrasts --key 只换一字与干支联动 \
  --include-snapshot-text true --response-char-limit 0
```

词条包含 8 条说明，区分逐字与位置差异、配月配时联动、未知早晚子候选、未印完整反事实盘和现实因果证据。其中具体保留壬日辰时甲辰与卯时癸卯的联动，也保留“辛字”比较中年干乙变丁的事实，以及另一组比较同时改变年干和月支的反例。原作者的比较语不能直接变成“只改变一个现实因素”的实验结论。

`provenance.entry_curation.source_contrast_binding` 绑定此前核查的全部 15 组比较、14 条未印完整四柱的关系记录及原有 22 项疑问和 4 条输入问题。原图比较归任氏曰，遁月遁时表及该书夜子规则归李雨田增补，程序差异分析与编辑边界分别列明。新增词条没有调整强弱标签或减少字面差异，未补造反事实出生盘。

知识加载器现在按明确文件名顺序合并两个补充包，并拒绝重复组件标识、覆盖既有分类或同名键。目录可发现新分类；单条查询只带该分类所属补充包的来源，原有词条不会误带新增来源。
