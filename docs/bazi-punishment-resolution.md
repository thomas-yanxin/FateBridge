# 解刑须有同次成立的会合：状态与算术修复

本轮修复了一个可复现的内部矛盾：两个六合都已经因活动六冲被判为`contested_or_clashed`，后面的刑事件却仍沿用最初候选的保护，写成`resolved_by_combination`。完整20,736种四支排列中有8处此类错误，另有8处得到实际会合支持的解除。修复只改变前8处状态，保留后8处。

## 原典与采用范围

目读国图藏、上海世界图书馆发行《秘本子平真诠》〈论刑冲会合解法〉的完整PDF23–25页、印刷14–16页，并保留下一章起页26作为边界。原PDF的SHA-256为`71402a780b0351b54edf121a51bc4a4a4ce5896496c35b954563ee06f1a6f620`。原章区分会合能解、会合不能解，以及解后另生刑冲的情况，不能仅凭字面候选就宣布解除；[完整原书](https://upload.wikimedia.org/wikipedia/commons/f/fe/NLC416-11jh010455-35296_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf#page=23)与本轮原页（本地数据：`validation/bazi-punishment-resolution-files-v1/ziping-p23-first.png`）可核对。

这不是原典对下表八个排列的直接旺衰裁定。采用的修复是内部一致性条件：只有同次实际处于`binding`或`conditioned_transformation`的三会、三合、六合，才沿用既有的全刑组覆盖门槛提供解刑。争议候选、半合趋势及零预算附合不补作覆盖；早先决定六冲所需的候选保护步骤不改。原章没有提供减损系数，本轮不调系数，也不声称穷尽原典解法。

## 为什么默认数值没变仍须修复

这些排列中的相关位置已有活动六冲。默认刑损保留系数为0.9，同次六冲已使用不大于0.9的保留系数，按既有不叠乘、取较强损耗的规则，补上刑事件不会再减少默认根量。因此不能将状态修复报成新的旺衰准确率。

另冻结一个只作诊断的刑损保留系数0.8。在8种排列、全部5,000组阴阳干支配对输入中，旧实现会漏掉更强刑损；修复后真实藏干剩余量与独立分数算术一致。0.8没有成为默认参数，也没有据源标签挑选。输入只是干支内部配对，不是核实过的公历生日或真实预测样本。修改前完整5,000组（本地数据：`validation/bazi-punishment-resolution-files-v1/all5000-before-first.jsonl.gz`）和源码、安装包修改后记录均保留。

算术参考也保留一次明确错误：首次独立字面表把巳中庚、戊顺序抄反，造成根量断言失败。原错误表、首次绑定和失败结果不变；另建校正说明（本地数据：`../tests/fixtures/bazi_punishment_resolution_v1/reference-input-order-correction-first.json`），对照修改前已冻结的物理表纠正顺序。校正在首次生产编辑之后，不能宣称独立算术参考自始完全正确，也不能将这一程序门槛算作完美通过。几何条件参考、原5,000组输入和修改前原始数值没有替换。默认值的完整前后等同性另行核对，不能当作独立算术真值证明。

## 版本、解释和兼容

当前方法升为`season_root_revelation_relations_v9`，公开`punishment_resolution_policy=completed_combination_punishment_resolution_v1`，原先v8结果与失败记录保留。历史实验入口`_evaluate`默认仍用旧策略；当前入口显式选择新策略，防止历史实验被静默重算。半合筛选本身不变，所以候选清单仍使用已有`reconstructed_v8`阶段标识，并明确识别v8与v9；未知版本不借用该阶段规则。

输出校验同时检查原典核对与八字证据链。v9不能在同次没有已成立覆盖时宣称刑已解除；缺少候选清单、缺少旺衰上下文或缺少一个不相关事件的位置，均不能掩盖已经明确的矛盾。可能提供覆盖的关系本身未知时保留未知；旧v8原始回执可复放，不冒作v9已验证结果。
