# 六爻：默认 DE440、年份依赖与显式空值

第二十九轮采用当前工作树已有的随包 DE440 组件，修复实际复现的两处问题：未使用的系数阻断范围外历法计算，以及 CLI 丢弃显式空值后重新填入默认坐标。验收基于封存源，未发布、未部署；当前整个并行工作树未在本轮整体验收。

## 默认路径与原始系数

软件年份 1800–2200 的默认 `auto` 使用 `fatebridge_de440_solar_v1`。原始地球、地月质心和太阳的 Type 2 系数按固定区间裁取、保留原始字节并随包分发，运行时不用参考交点表、拟合修正或外部 SPK 文件。来源核对 [NAIF SPK 文档](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/spk.html) 及 [Park 等人的 DE440／DE441 原始研究入口](https://ssd.jpl.nasa.gov/doc/de440_de441.html)。衍生系数产品及 ERFA 授权分别标识，不构成 NASA 或作者对 FateBridge 的认证。

原 4,872 点和全部 9,624 点（本地数据：`validation/liuyao-v29/fullsolar-result.json`）均通过原 **1 秒 TT** 门槛，最大与既有参考差约 **0.0000805 秒**。原 501 点在新默认路径下全部通过；原生 Moshier 的失败与旧默认近界反例仍是原版本失败记录。两组交点重合、参考共用 DE440，不是两组独立物理观察，更不是绝对精度或真实事件预测认证。

既有组件的 166,422 个轨道端点／中点、地心 TDB 与一般时点比较按内容身份继承，未冒称本轮重复执行。严格整文件身份检查先发现一处导入分组差异，原失败保留；核对后确认导入别名与全部非导入 AST 相同，原始系数字节相同。连续性证明（本地数据：`validation/liuyao-v29/numeric-continuity.json`）区分继承证据与本轮实跑交点。

裸 wheel 在没有 jplephem、pyerfa、外部星历、源码目录、测试或参考交点表的基础环境运行：原距大雪参考交界约 7 毫秒的输入取亥月，四爻午的原月破标记为 false，快照没有沿用旧月破判词。基础开发依赖闭包与上一轮相同。

## 年份与相邻年份窗口

修复前实测（本地数据：`validation/liuyao-v29/before-unused-year-source.json`）：1700、1799、2201、2300 年整年计算，以及 1700、2300 年六爻，在缺少根本未使用的打包系数时全部报 `solar_de440_invalid`；同输入的原生对照可以计算。

缓存标识原先先读取系数，再判断年份。本轮让整年缓存按实际求解年份选择依赖，四柱、流月、流日缓存按实际本地民用年份及其相邻年份窗口选择依赖。1700、2300 年的六爻完整业务结果保持原生对照不变；源与风险描述仍如实保留，未把范围外原生路径提升为已通过 1 秒 TT 的路径。

1799、1800、2200、2201 年的派生窗口会读取声明范围内的相邻年，因此仍须校验该来源。实际需要 DE440 却缺源时继续明确失败；显式 de440 越界拒绝，严格原生 JPL 选择优先且不可用时不能复用默认暖缓存。没有通过忽略异常或静默降级修复可用性。

## 显式 null 与遗漏字段

首次三端比较暴露测试输入差异：接口按现有契约填默认坐标，直接领域对照没有坐标。明确发送 `"lat": null, "lon": null` 后又发现真实 CLI 差异（本地数据：`validation/liuyao-v29/before-cli-null/summary.json`）：REST／MCP 保留空值，CLI 的 subject 文件合并过滤掉空值，重新填回上海坐标，连输入 SHA 都不同。

本轮修复单工具和 profile 的文件合并：显式空值交给原 Schema 校验，显式 CLI 参数仍覆盖文件值，遗漏字段维持现有声明默认。修复后同一空坐标输入（本地数据：`validation/liuyao-v29/after-cli-null/summary.json`）的三个接口都保留空值，输入 SHA 相同。对不可为空的字段传 null，按既有 `validation_error`／422 返回；未知出生分钟不会因文件合并而悄悄变成零。

没有重写旧原生对照。新测试最初两项失败、后续真实 CLI 不一致、原生控制测试的一次跳过及各次具名模型／格式失败均保留。旧原生求解器、原生 JPL 切换和具名解析模型测试改为显式选择所测模型；原输入、参考、准确度门槛及案例身份保留。新增默认路径独立验证，不能把旧原生失败说成已修复。

## 原典与真实模型仍有未决部分

同版 NLC 1925 PDF 的第 74、104 页已整理为六条范围矩阵（本地数据：`validation/liuyao-v29/classical-clause-scope-matrix.json`）：静合起、动合绊、两动合好、本位化扶、动破的逢合应期，以及无生助静破的限制分别列出。一般休囚、月破专章、当前资格和未来应期不能折叠成 `combine=True` 的全局豁免；本位变寅等特定反制也不由泛相合规则删除。

矩阵采用可读标点转写，尚非独立复校的校勘定本。本轮没有部署新的六合／月破数值裁决；第二十六轮误归的静雨例继续撤回，不充当正反例。真实模型仍以 18／20 为准，两个未完成项及未观察到模型核验全文哈希的记录保留，本轮新对话为零。
