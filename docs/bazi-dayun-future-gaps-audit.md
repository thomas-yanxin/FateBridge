# 未来跳时造成的交运状态漏采

出生范围计算已补充未来民用跳时结束的逆像事件。现有三日一年折算、公历年／月／日加法及不存在钟时顺延政策保持不变；新增的是哪些出生输入需要核对，以及如何保留这些输入产生的全部当前大运候选。完整纽约逆行首运来源队列与旧名义月进位回归通过，本命耦合的当前快照回归仍在原进程运行；这些软件控制结果不认证连续范围、物理精度或预测效力。

## 缺陷与来源

[dateutil的说明](https://dateutil.readthedocs.io/en/stable/tz.html#dateutil.tz.resolve_imaginary)规定，不存在的民用钟时按偏移变化量向后顺延。交运钟面标签从跳时区间内部跨到区间结束时，顺延突然消失，已解析的交运UTC时刻可能回跳。文档版本为3.0.0；本轮实际使用锁定的2.9.0.post0，行为另由领域实算核对。未来时区法律仍可能改变，当前加载规则不是真实未来钟时保证。

来源协议（本地数据：`../tests/fixtures/bazi_dayun_future_gaps_v1/protocol.json`）与参考冻结记录（本地数据：`../tests/fixtures/bazi_dayun_future_gaps_v1/reference-freeze.json`）先于应用调用和生产修改保存。来源只读取冻结节令与IANA 2026e的纽约TZif，用标准库整数微秒、公历算术和有效钟时逆像计算；没有导入FateBridge、dateutil或ZoneInfo。遍历297,187个节令／名义月单元并按出生民用日期和偏移细分，保留22,162个逆像事件：22,035个可判定，127个事件相互作用未决，没有按程序成败删例。

首例领域回执（本地数据：`validation/bazi-dayun-future-gap-diagnostic-first-v1.json`）使用虚构输入：纽约1908年4月4日17:29:47，明确UTC−05:00，女性，范围正负一分钟，分析时刻为1918年3月31日07:59:20Z。三个分钟点与旧事件探针均返回已起运；范围内22:30:18.519117Z的出生输入却尚未起运。该点的独立公历算术和真实领域起运时刻一致。尚未起运的出生输入片段不足一秒，分钟一致不能排除它。

完整前测（本地数据：`validation/bazi-dayun-future-gaps-before-v1.json`）完成全部22,162例：22,032个可判定范围遗漏已知状态，22,033个安全距离探针包络遗漏参照；安全距离数值不符为0，另保留2,260项近逆像边界诊断及127个来源未决项。原执行器退出1表示已登记能力缺口，首次结果和逐例回执均保留。

## 修复范围

扩展协议（本地数据：`../tests/fixtures/bazi_dayun_future_gaps_v1/extension-protocol.json`）在生产修改前冻结。领域层提取原有交运钟面算式供实际时间线和逆像共同使用，没有替换折算系数、节令根或原起运政策。出生分区新增原始民用日期与偏移变化，并保留节令和名义月进位切点；太阳钟本命计算与原始民用交运计算分别使用各自的钟时依据。

服务按实际加载的时区对象检查当前分析UTC日附近的整秒偏移变化，再求未来跳时结束标签对于全部13个默认十年边界的出生逆像：首运、11个内部边界及第12期末端。年份逆像保留闰日截断的多重来源。不能通过既定分区内仿射检查的单元保留在 `unresolved_cells`；没有静默改用某个单一结果。

`dayun_future_civil_gap_end` 返回计算括区间和来源；两端及固定邻点进入派生探针，分钟网格与原本命／大运进位探针均保留。`sample_count` 仍只计分钟输入，合并探针按实际UTC瞬间去重。`before_dayun` 解释为尚未起运，内部边界保留相邻 `period`；`beyond_calculation` 表示超出已配置期数，不能解释为寿命。
