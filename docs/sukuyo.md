# 宿曜与宿占：当前历法、规则与来源

[文档中心](README.md) · [API 参考](api-reference.md) · [算法状态](algorithm-status.md)

`suzhan` 宿占与 `sukuyo_compatibility` 双人相性保留实际所选宿主历法、配宿档案与原典条文。历日宿名、天文角距与行为条文各有不同适用条件，不能互换身份。

## 历法与配宿档案

`calendar_basis` 选择现代中国农历UTC+08、HuTime日本逐日参考UTC+09，或NAOJ日本历史月朔参考UTC+09。HuTime逐日参考范围为1872-02-09至2031-01-22，2015年起属于出版方推算；NAOJ范围为公元0001-01-01至1872-12-31，早期纪年含重建，改历末月只有两天。固定参考时区不等于历史地方时；超出范围明确失败，不回退另一历法。

`calendar_profile=t1299_fullmoon27` 按T1299望日逆顺及生日加十三法配宿；`hinoo_t1299_host27` 是具名桧尾研究档案，应用T2465的闰月、小月分宿条件。涉及半日而信息不足时保留候选宿，不选定一个结果。另一宿主出版方异日及校订前后月键分别记录。

当地日期已知而出生时刻未知时，转换到所选宿主时区并保留全部可能日期；不填默认时刻。跨月、岁首、闰月及午夜分别按宿主历法处理。现代月日角距只表示天文角距；历日白黑分不能由角距替代。

## 相性与条文

双人关系保留本命宿之间有方向的模环位置及三九关系，双方位置交换时按原典方向重新解释。候选宿会传播为候选关系，不能把多个候选平均成已确定相性。

原典位置资料还包括三九日、六宫宿、二十七宿四足与十二宫。显式足序只是按宿名查足表，不声称计算了真实出生足位。单个条文的七曜、黑白月日、昼夜、方向、衣着或行为前提须单独核对；原文的相反证言、字形疑读与版本差异均保留。

桧尾、三代格、766年记录、大衍、宣明与符天的研究档案保留具名来源和适用范围。其月首、名义时刻、朔望及积算是限定模型，不将缺失月份补齐，不据研究重建宣称恢复了当年的全部颁历或历史观测。

## 检验范围

`tests/data` 中的宿曜一手转录、书影、出版方历表与独立算式供当前检查使用。名称带“before-code”的独立参考可能记录了生产实现之前形成的原文或算式；它们不是旧FateBridge算法输出的兼容回放。旧协议摘要与旧软件整对象重放已经退役。

当前合成研究协议检验资料绑定、盲法、完整上下文承诺与统计门槛；合成结果不建立现实有效性。来源校读、软件正确性、解释忠实与真实预测分别验收，分数不表示关系成功概率。

```bash
uv run --locked --extra dev pytest -n0 tests/sukuyo/test_sukuyo_profiles.py tests/sukuyo/test_sukuyo_historical_calendar.py tests/sukuyo/test_sukuyo_protocol_context.py
```

具体候选、来源与限制随同一次结果交付；完整资料读取同一run的 `result_delivery`，不通过重算替换结果。
