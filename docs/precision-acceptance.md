太阳根因来自两部分：仅补完整月球仍7／96超差，仅更新地月质心仍2／96；完整修订原96全部过线。新模型使用独立身份 `fatebridge_complete_moshier_solar_v1`，不冒充原版native太阳，也不借用其返回标志。原作者C实现及全部整数系数另行核对，详见[太阳计算](solar-backends.md)。

水星原约0.8916角秒差异来自日盘内偏折约定。JPL自身observer与LT+S原响应、可见性标记及太阳半径提供独立对证。原生透明太阳盘仍保留原结果和原失败状态；新坐标只在显式选择时返回独立 `apparent_model_positions`，不重算原盘日速、宫位、相位或解释。原7070点只含七曜，不能把验证扩展为另外三颗外行星已通过。详见[西占来源](western-astrology.md#参考点模型与日速来源)。

同一个完整DE441源的组合验收另外复现了Venus光行时固定点的相邻浮点两周期。当前以物理光锥方程的符号求相邻TT括区，使用输入double的精确平方距离判侧，选首个非负端点；原20步上限保留，没有epsilon或新增容差。原失败两端残差约−20.117及+20.118微秒，括宽40.233微秒；数值括宽仍不是物理精度证书。

月球超差在几何源速度中已经存在；两种独立系数解包、位置差分及三种真实重编native变体确认，末项遗漏仅能略微改善，不能恢复压缩源丢失的信息。完整DE441路径采用真正连续原记录，保持原常数和每个系数字，不使用测试点缓存或拟合补偿；原Swiss坏点约0.002607角秒／来源日仍失败。详见[月球源精度](astrodice.md)。

原两项缺证另行补证，不改旧参考：AD1中心的19个原探针已补齐，包括1BC负offset；日速差0.000442、位置差0.001316，均满足原线。AD9999中心的6个必要探针仍超NASA实际数据上界，保留未验收，不换成单边模板。最终可报告原135项加独立补证1项通过，另1项未验收；原137文件及补证审计仍按各自缺证状态返回exit2。

## 使用精确月球来源

准备器保留既有完整文件下载功能，并新增连续域准备与验证。输出必须为新文件；下面的10000是不包含的年上界，公历覆盖1—9999年，并保留前后至少32日原记录。约929MB数据放在仓库外，默认wheel不携带，也不会在业务请求中下载。

```bash
uv run --locked --extra dev python -m fatebridge.fetch_jpl --start-year 1 --end-year 10000 --output /absolute/jpl/de441-0001-10000.eph
uv run --locked --extra dev python -m fatebridge.fetch_jpl --output /absolute/jpl/de441-0001-10000.eph --verify-only
export SE_EPHE_PATH=/absolute/jpl
export FATEBRIDGE_JPL_FILE=de441-0001-10000.eph
```

这两项环境设置适用于实际REST／MCP／CLI进程；已有连接不会因准备文件自动刷新。原Swiss文件及公开模型选项保留。显式JPL与太阳 `swiss`、`analytic` 等选择冲突时，按已有合同明确报错。

来源身份依靠NASA官方HTTPS、强ETag／If-Match、准确Content-Range、原头及常数、连续有限记录和逐范围散列；没有宣称核验完整远程2.79GB文件的官方散列。独立审核覆盖全部记录连续性、全部double有限性、55.8MB系数重叠逐字节相同、5个新NASA原记录及36个原生边界状态与独立Chebyshev对照。

来源系数时标为TDB；既有Swiss公共入口采用TT，当前原数值参数及时标约定分别保留。原始记录正确不等于完成全部TT↔TDB、历史UT1或未来闰秒的物理时钟认证。

原96点与新576点数值测试、1800／2200两年各24点三端测试、月球两来源三端测试及水星显式坐标三端测试均分别执行；交付一致性不能代替独立数值线。自包含CI与外部参考队列分别记录，原失败和缺证不因测试程序返回成功而改判。

当前实现与可复算入口：[`moshier_solar.py`](../src/fatebridge/core/moshier_solar.py)、[`opaque_solar.py`](../src/fatebridge/core/astro/opaque_solar.py)、[`fetch_jpl.py`](../src/fatebridge/fetch_jpl.py)、[`audit_complete_moshier_accuracy.py`](../scripts/astronomy/audit_complete_moshier_accuracy.py)。依据包括 [Moshier原级数](https://www.moshier.net/)、[Swiss官方模型与精度说明](https://www.astro.com/swisseph/swisseph.htm)、[NASA原DE441数据](https://ssd.jpl.nasa.gov/ftp/eph/planets/Linux/de441/)及[NASA Horizons坐标定义](https://ssd.jpl.nasa.gov/horizons/manual.html)。
