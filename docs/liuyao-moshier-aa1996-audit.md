# Moshier 地月质心级数更新与完整视位置复验

本轮找到并验证了能消除原队列 501 项超差的计算候选：采用 Moshier 在 AA 5.6 中发布的 1996 年地月质心级数，并将原短月球偏移换为完整 Moshier 月球计算。原 1 秒 TT 门槛、4,872 个输入、DE440 参考、原版对照和全部失败均保留。v36 完成独立研究构建；后续 v37 的[显式领域接入、实际三端和保留的消费端失败](aa1996-solar-backend.md)另行记账，下列 v36 研究记录保持原样。

[作者站点](https://moshier.net/)发布的 AA 5.6 原包内，`ear404.c` 明列 1996 年版本，采用 `g3plan`；三个系数数组各 738 项，参数数组 1,483 项。此前核对的 1995 年 PLAN404／当前 Swiss 表分别为 460 和 819 项，采用另一套参数化。原包与逐文件来源（本地数据：`validation/liuyao-v36/source-reading/reading.json`）固定实际下载内容，版本差异见源表比较（本地数据：`validation/liuyao-v36/source-comparison.json`）。项数增加本身不证明精度，下面的固定队列才是数值证据。

先按预先冻结的协议（本地数据：`validation/liuyao-v36/protocol.json`），分别比较原版、仅更新地月质心、同时使用完整月球。原版仍有 501 项超差；保留短月球的更新方案仍有 15 项，最大约 1.365 秒，其中 7 项来自旧失败，8 项为原本合格的新增退化，全部保留（本地数据：`validation/liuyao-v36/summary.json`）。完整月球组合在原 4,872 点及两批各 256 个一般时点上满足原门槛。不过该阶段保持原版视位置后处理，不能单凭其通过认证完整计算。

随后从项目锁定的 `pyswisseph 2.10.3.2` 官方源码包构建原版对照及完整候选。源码包 SHA-256 为 `c54c305e83dbd5d2b71e58d8a69d8ee41de24c4d3328ce09e2af860a3537624d`；仅候选的 Earth／EMB 分派和地月偏移计算改变。原作者的 J2000 黄赤交角显式转换到原生内部基底，完整月球按每个实际时刻的黄赤交角转换，质量比沿用原生已声明常数，没有从参考残差拟合旋转、系数或修正表。地球速度、光行差及其他视位置处理均由改后的完整原生流程重新计算，未继承旧太阳视黄经。源码、补丁、实际二进制及编译命令均在成对构建（本地数据：`validation/liuyao-v36/full-pipeline/build.json`）中。

完整原版对照在全部原交点上与此前实际 Python 原生二进制的求根结果逐项相同，仍重现全部 501 个失败身份。候选采用独立名称 `experimental_aa1996_emb_full_moshier_moon_native_apparent`。其底层返回标志仍属 Moshier 类别，不能仅凭这一标志将改版二进制冒称原版；实际模型必须同时绑定源码、候选名称与二进制散列。

交点列报告直接 TT 求根差；一般时点列报告视黄经差按参考太阳速度换算的等效秒数，两者分别列示。完整视位置结果（本地数据：`validation/liuyao-v36/full-pipeline/summary.json`）和新增 4,096 点结果（本地数据：`validation/liuyao-v36/fresh4096/summary.json`）保留逐点数据。后者按固定种子在 1800—2200 年分层选点，在读取该批参考、求值候选之前冻结，没有观察结果后改系数、门槛或选择。原 4,872 个交点完全包含在 9,624 个交点内，参考逐项相同（本地数据：`validation/liuyao-v36/reference-overlap.json`），不能相加成独立样本。这些队列共享 DE440／Skyfield 参考框架，是开发验证，不是独立物理观测或盲测。

提供离线重建与回放入口（本地数据：`validation/liuyao-v36/reproduction/replay_portable.py`）：验证已封存源码和参考散列，在新目录重编译两套库，再对全部队列回放，不下载资料、不导入已安装的 Swiss 库。当前实际执行平台及状态见本轮回执（本地数据：`validation/liuyao-v36/README.md`）；脚本中的 Linux 分支尚未运行，不能用 macOS 结果替代它。

v36 当时没有将候选写入正式包或替换当前运行库；v37 后续接入仍未改变默认配置。原 501 项是旧模型的真实失败，继续有效；新候选的通过不能改写旧记录，也不替其他星体、全部历法时制、整部原典或模型解释背书。当前真实模型五次启动的环境失败另见原始记录（本地数据：`validation/liuyao-v35-model-r1/README.md`），额外五次调用等待已发出的明确授权。首轮缺少 Skyfield 的导入失败及资料访问失败也原样保留。
