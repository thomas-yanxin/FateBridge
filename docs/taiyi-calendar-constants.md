# 太乙古历常数：原字、单位与可恢复范围

《太乙金镜式经》卷一的明钞本保存了一组能够互相推导的积月、积日及积时常数，四库本相应数字则有缺文或不相容。这提供了恢复古历的具体线索，仍未形成可从公历日期调用的完整古历提供者。现有年／月／日／时计及五年历史历表不由本诊断替换。

本轮主查[四库原扫描](https://commons.wikimedia.org/wiki/File:CADAL06056494_太乙金鏡式經·卷一~卷四.djvu)第27、30、33—36图，以及[台湾国家图书馆明钞本](https://commons.wikimedia.org/wiki/File:NCL-06604_太乙金鏡式經.pdf)第10、11、13、14图。原书署王希明；明钞藏本号306.6 06604。页码是文件一基图像页，不是古籍叶码。原生像素、各字段读数及冻结要求见V26来源集（本地数据：`../tests/fixtures/taiyi_jinjing_v26/readings.json`），校读者为本项目Codex处理者，未经独立人类专家审定。

## 三个相近数字分别属于什么

| 原位置 | 四库书影 | 明钞书影 |
| --- | --- | --- |
| 時計差法的气法 | 33193 | 32193 |
| 時計差法的辰法整数 | 3682 | 2682 |
| 冬夏至间隔“分日”分母 | 32293 | 32193 |
| 全数 | 二十六万〔阙〕千八百四十三，缺字未补 | 168842 |

四库气法33193与二至间隔分母32293是同书不同位置；不能把32293在所有位置都判作误读，也不能全局替换。此次原生书影确认四库33193／3682，不改旧值。缩略图曾看似32193／2682，原生检查排除了这一初步假设；没有据此更改来源或生产数值。

其余既有异文保留：章月8726／8126、秒法200／100、闰差秒27／17、月法2447／1447、小余36／26。两本同列章岁657、日法49、朔策29、半辰法1341及“十二分之四半”。辰法小分均留“之也”的当前字面转录，数值语义仍未裁定；不因方程只容许一个数就改录为“九”。

## 明钞常数的精确关系

以下使用同一明钞本的数值。只做整数和有理数运算，不以接近现代回归年为校字依据：

- `657 × 49 = 32193`：章岁与日法的乘积对应气法。
- `29 × 49 + 26 = 1447`：朔策及小余对应月法。
- `8126 × 1447 = 11758322`：章月和月法给出章期日数的分子。
- 章期平均年长为`11758322 / 32193`日；减去六个60日周期，余`168842 / 32193`日，对应明钞全数168842。
- 平均年长的一半为`182 + 20035 / 32193`日，对应该本二至间隔；`24 × (1341 + 4.5 / 12) = 32193`也精确成立。

这些关系共用同一组常数，有相关性，不是若干独立的天文观测或有日期古例。它们支持一种量纲一致的解读，不能单独证明本书岁首、积年、日辰与现代公历日期已经接通，也不自动裁定四库异文应改何处。

若进一步要求辰法等于两倍半辰法，明钞所需小分为`9/12`。这是算术候选，原字数义未定，仍记未决。四库辰法整数3682即使允许任一正常真分数，也不能与两倍半辰法2682.75相等；此结果只限定该量纲解读，不能据此擅改原典。

## 尚未闭合的两处关键规则

**次气小余与秒。** 明钞连续栏文字目前录为“每气加一十五日余七千三五秒满二十四从小余一”，四库相应数字次序不同。字组如何分成小余、秒仍未裁定。若把上述平均年等分24气，算术要求每气15日、余7035又`2/24`分；报告将其标为未采用的候选，不能反填成书中已写“二秒”，也不能当作现代定气实刻。

**置闰规则。** 明钞章期要求`8126 − 12×657 = 242`个闰月。若把“每月加闰差及秒”直接读成每个积月固定加`20 + 17/100`、满657减657，无论合法初余取何值，8126月只能产生249或250次进位，不能闭合242。四库同一单步解读产生267或268次，章月却要求842次。

这否定的是这一具体单步解读。原文另有无中气及提前置闰的分支，当前没有完整复原，不能把该诊断写成整部原典置闰法已经证明错误。需要继续校定哪些月加差、触发与重置规则、原文的秒单位和适用历法；不把算术所需步长改写成原书常数。

冻结后另保留“只在平月加差”的探索假设，没有改动原16项判据。明钞按7884个平月可产生242或243次进位，但在扣除应有242次后仍余26.28，未精确闭合；该假设需要的精确步长为`20 + 1/6`，与按百分位近似为20.17相容。原书是否采用此近似、闰月是否跳加及如何处理余差尚待证明。四库同一假设也完整列出，不能只选明钞看似相合的一项报通过。进位次数偶然相合不能代替闰月位置及完整历表验收。
