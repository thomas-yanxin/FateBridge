# 实际动巳与金爻长生：原典交叉裁决与计算解释分层

本轮补上《增删卜易》“卦中动出巳爻”的可见实际动爻分支。最终规则 `zengshan_moving_si_growth_v40 / 40.2.0` 分别报告遇长生资格、原有普通克制许可与尚未裁定的合并效力。普通克制字段的含义和计算保持原值；不能从“遇长生”直接推出免克、得利或现实成功。

## 同一版本中的两项事实

依据为国家图书馆1925年文明书局版《增删卜易》，秦慎安编，394页。固定[原始PDF](https://upload.wikimedia.org/wikipedia/commons/4/42/NLC416-12jh005345-45344_%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93.pdf)，SHA-256：`caac111bc5c5b1c08fd27b3828e7cf6b5430503800f2427d8f2b28809022abaa`。本轮对照本地扫描图像读取PDF第84、85、97、98页；页码指PDF页序。

第97页在“金爻旺相或日月动爻生扶”前提下，依次列出巳日、卦中动出巳爻、金爻本位化巳三种遇长生情形。第97—98页另有休囚无气、巳午火多时论克的限制，没有足够依据将“火多”编成任意数字阈值。

同版第85页“坤之师”例提供关键反证：酉金得日辰生扶，文字仍明确称二爻巳火动而克金，随后通过未日冲动丑土、火生土、土生金解释其关系。因此，第97页的遇长生资格不能自动取消普通巳火克金关系，也不能冒充第85页通关结果。原图见第85页（本地数据：`validation/liuyao-v40/source-reading/page85.png`）、第97页（本地数据：`validation/liuyao-v40/source-reading/page97.png`）、第98页（本地数据：`validation/liuyao-v40/source-reading/page98.png`）。

这是一组文本关系核对，不是对书中事件的独立观测。本轮没有认证全书，也没有处理隐伏巳、仅他爻变出巳或所有通关组合。

## 最终领域计算与输出

- 只将原可见爻实际发动且本支为巳者列入本分支；静巳及仅变支为巳者保留为对照。
- 金爻的独立生扶证据来自月、日的生扶比和，或已有经过资格核对的独立动土链。不能用新增巳长生信用、受方金爻或依赖它的路径循环证明前提。
- 未证明独立根时保留 `null`；不能把材料不足写成“完全无气”。原有动爻空、破、合、回头制及本位变寅／申制寅的先后条件继续生效。
- `control_conditions` 的原 `condition_match`、状态、来源及闭包记录保持原义，表示普通条件许可。新增 `metal_si_growth_condition` 单列长生资格，`metal_si_combined_effect_condition` 为 `null`，表示合并效力未裁定。
- `growth_conditions.lines[*].moving_si` 列出实际巳爻、独立根、原克制许可、长生资格、两页来源及散列。原每日长生字段标明 `day_branch_growth_only`，避免将日支条件误读为所有遇长生路径。
- 解释文本逐项对应上述结果，说明长生资格与普通克制许可可同时存在，合并效力待审。条件分析仅在本分支适用时使用 `2.21.2`；其余上下文维持 `2.20.0`。

本轮还修正了独立重算控制条件时丢失临时上下文导致的输入迭代顺序差异。最终不增加新的长生反馈闭包；先完成原普通条件闭包，再附加本分支证据。

现有强弱汇总没有吸收这项尚未裁定的合并效力。本轮保留原汇总计算，不能把原分值称为已经综合动巳长生与通关的最终作用，也不能将新增资格换算成成功概率。

## 保留的错误实现与裁决过程

首次实现把“有独立根而遇动巳”处理为免克，专项测试曾通过。第85页直接反证此自动豁免，R1/R2的实现、输出、测试及冻结预期全部保留，不将这些通过记录作为原典符合性证明。

R3尝试将合并效力未知写入原有普通克制许可字段，造成原“坤之师”期望 `true` 的回归失败。这混淆了两个字段层次。R5恢复原许可字段的含义和计算，未知效力独立返回；原测试期望仍为 `true`，未作修改。修订依据与散列分别保存在原典裁决（本地数据：`../tests/fixtures/liuyao_moving_si_v40/profile-adjudication.json`）和字段语义裁决（本地数据：`../tests/fixtures/liuyao_moving_si_v40/permission-adjudication.json`）。这些均为实现后裁决，不能标为先验盲测。

## 验证与限制

最初35个工程上下文在生产修改前冻结，按7种预先声明的结构与5个月日上下文构造，结构取字典序首个合法装卦组合。日历映射脚本不导入FateBridge，使用既有DE440/Skyfield TT参考、ERFA时制转换与NAOJ日柱锚点；35个上下文只有5个真实日期，并非35个独立观测。后续新增2个寅／申先后回归和第85页反证例分别记录冻结时间与用途。

最终源码的62项专项测试通过；同一62项在实际构建的Python3.12安装包中再次通过，未安装erfa或jplephem。包含独立进程stdio MCP、本地REST TestClient、CLI入口、全文及严格字段投影。安装包先在无测试材料、无原典PDF的目录通过独立进程完成实际CLI调用，再复制测试Python模块；复用的只读夹具目录单独记录。重复执行不增加独立案例数，协议调用也不算真实模型解释复验。

20,480个完整结构上下文逐字段验证原控制契约保持一致，其中17,120个不适用上下文的完整业务输出逐字节规范化散列一致。只从控制契约比较中移除9个明确新增的直接元数据字段，其余值、状态、来源和闭包记录均参与比较；新增谓词另由专项断言验证，不能单靠旧字段散列自证正确。

原55个六爻测试文件及断言的散列保持不变。完整旧套件重跑状态、未完成的磁盘故障执行、全部原失败及最终执行结果见本轮验收回执（本地数据：`validation/liuyao-v40/README.md`）。Ruff、格式、11个生产／生成器文件mypy、规则生成器与按需合同检查均通过；4,618个声明快照文件无漂移，179个天文／历法相关文件与修改前相同。装卦、起卦及结果构建函数AST未改，仅六爻解释函数变化。
