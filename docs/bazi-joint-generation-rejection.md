# 通关联合相生候选：反例检验与未采用决定

本轮没有采用新的旺衰规则。一个同时检查天干路径、地支连续相生与日主禄旺根位的候选，在旧408条语料中看似改善两条记录；两条其实是同一个字面输入的重复登记。进一步穷举发现，它在四个输入中会破坏自身采用前提，因而拒绝进入默认计算。原十九例仍有十七例分歧，未将实验判强记作修复。

## 为什么检查这一机制

重读《滴天髓阐微》1947年本《通关》PDF197–200完整四页、四造及上下文。首例癸酉、甲子、丁卯、丙午明确论杀生印、印生身、时归禄旺，并说四冲反为四助。197–198页同时要求区分隔位、合住、损坏与岁运引通，不能只凭图上存在相生链判为有效通关。

现行算法仍按普通六冲扣根，数值模型主要相加身印的工程能量。事前协议（本地数据：`../tests/fixtures/bazi_joint_generation_v1/protocol-first.json`）因此冻结一个联合候选：四支本气顺向或逆向连续相生，日主在下游有实际禄旺根；非日干只有身、印、官杀，并有实际相邻透干接引路径；没有已经记录的合绊或争合；每个普通活动六冲都有真实相邻中介。候选不查询案例ID、四柱例表或参考标签，不调整系数、阈值或既有源标签。

算术实验使用冻结运行时的独立模块副本，没有改写公开计算。先取消满足条件的冲损，再试验一个另列的结构判强。副本中的v8标识只指保留的算术版本，不能冒作默认v8结果；反事实配置说明（本地数据：`../tests/fixtures/bazi_joint_generation_v1/counterfactual-provenance-clarification-first.json`）保留所有覆写范围。首个运行因相对导入缺少包名而失败，原脚本和错误日志保留，修正仅涉及包名。

## 数值反事实没有自行给出原典判强

首例的身印工程能量占比约为：

| 计算配置 | 工程份额与判级 |
| --- | --- |
| 公开默认v8 | 28.05%，弱 |
| 仅取消候选所对应冲损 | 31.74%，弱 |
| 另做去除冲、刑扣损的诊断 | 仍为弱 |
| 联合候选另加结构规则 | 判强；属于实验规则，未采用 |

这些份额含身与印，不是日主本体力量或现实概率。这只能说明所测“去掉扣损”反事实仍不足以复现该例，不能声称任意调整损耗都不可能，也不能把直接结构判强包装成数值模型已经算对。

全部408条首次结果（本地数据：`validation/bazi-joint-generation-files-v1/full408-first.json.gz`）原样保留127条既有标签、281条未知和三项禁止档位约束。开发结果有两条记录改善、无已知标签退化，但只有一个不同输入，且原文此前已暴露；没有新增独立符合度信用。其余三个《通关》命例及原有未知标签没有补成有利答案。

## 完整适用范围中的四个反例

另按独立字面表枚举518,400组六十甲子、五虎遁及五鼠遁内部关系一致的输入。它们不是核实过的公历出生时刻，也不是现实预测样本。1,120组先满足地支和禄旺形态，最终只有五组满足联合候选。

其中四组改算后会激活半合，使候选的“没有支组合消耗路径”前提失效：

| 字面四柱 | 取消冲损后出现的半合 |
| --- | --- |
| 癸酉 甲子 丙寅 甲午 | 日时寅午，火 |
| 癸酉 甲子 丁卯 乙巳 | 年时巳酉，金 |
| 癸巳 甲寅 丙子 丙申 | 日时申子，水 |
| 癸巳 乙卯 丙子 丁酉 | 年时巳酉，金 |

这四组没有新作原典旺衰裁定。反例否定的是当前候选实现的前提自洽性，不证明原典通关原则错误，也不证明这些命式必须弱。仅看改算前的事件列表，会把“当前因冲而没被生成的半合”误作条件全清；取消冲损又会改变后续关系。这是联合关系决策必须解决的问题。

剩下的一组恰是已暴露的原典首例。没有事后过滤四个反例、改窄规则只留下这一例，或转而寻找有利章节来采用候选。完整穷举首次结果（本地数据：`validation/bazi-joint-generation-files-v1/all518400-scope-first.json.gz`）及全部失败均保留。

首次探针的`known_classical_label:null`表示当时没有做源标签查询，不是宣告既有标签未知。事后来源交叉表（本地数据：`../tests/fixtures/bazi_joint_generation_v1/scope-source-label-crosswalk-first.json`）另保留原典首例的两条既有强标签；其他探针未增添强弱标签。原始探针不改写，未查询、原典未知与未验证保持区别。
