# 武经同书十六神名位与跨书冲突

《武经总要》四库本后集卷十八的十六神定义，明确写有“酉为大族、乾为阳德、丑为阴德”。这补上了此前“大族”缺少名位依据的问题，也揭示了它与现用金镜卷二参照表的阴德／阳德位置相反。两种资料不能按哪种更接近程序就择取哪种。

底本为[CADAL06047941卷十七至十八](https://commons.wikimedia.org/wiki/File:CADAL06047941_武經總要後集·卷十七~卷十八.djvu)，原生第145页（本地数据：`../tests/fixtures/taiyi_wujing_names_v47/native-page145.png`）；[在线定位](https://www.shidianguji.com/zh/book/SK1390/chapter/1l94vald3plie)只帮助找到段落，读数以书影为据。全册DjVu指纹为 `99cf1d151489b054916cb4aa72ca44616af518b622c8f3a81012ebdd5904af78`，原生PNG及RGBA指纹见来源记录（本地数据：`../tests/fixtures/taiyi_wujing_names_v47/provenance.json`）。复用此前无增强解码，本轮重新核验文件和RGBA，没有重新生成图片。

同书16名位表（本地数据：`../tests/fixtures/taiyi_wujing_names_v47/name-profile.json`）及完整比较协议（本地数据：`../tests/fixtures/taiyi_wujing_names_v47/protocol.json`）在新程序比较前冻结（本地数据：`../tests/fixtures/taiyi_wujing_names_v47/freeze.json`）。读者为已知原有程序和差异的Codex主代理，属于非盲语义选读，无独立专家复核。只归一化明确列出的隂／陰、徳／德、呂／吕、藂／叢字形，不推广所有太／大异名。

本轮对全部144局的288个天目／始击槽位统一使用同书定义，其余1152槽位沿用V46书影补读层源值。45条既有补读及旧录文保留，未新增逐局书影校读。名字即使能定位，原文没有明确角色的阳48天目、阴13始击仍未知；阳25“大将义”的分词也不由新表补齐。名称后的掩、击、迫等附文完整保留，定位相符不等于断语相符。
