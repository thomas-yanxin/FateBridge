# 金钥匙附例：积日算路与月计名义年修正

《太乙金钥匙续集》末尾的“太乙筭例”给出了一条完整的乘除算路。V39据原图复算七个明确中间数，并以1561年完整历表核对；据此修正默认金镜月计重复减年的问题。原书梁例积日、完整王氏古历和三式联合断法仍未验收完成。

## 原图提供的约束

[金钥匙原PDF](https://upload.wikimedia.org/wikipedia/commons/1/19/NLC892-411999021066-66022_%E5%A4%AA%E4%B9%99%E9%87%91%E9%91%B0%E5%8C%99.pdf#page=47)第47页，内嵌主图（本地数据：`../tests/fixtures/taiyi_key_accumulation_v39/key47-000.png`）及另存馆徽（本地数据：`../tests/fixtures/taiyi_key_accumulation_v39/key47-001.png`）直接提取，未改字、缩放或拼图。主图本身是完整书影展开，不冒称已合成PDF的其他叠放对象。目录网站转录中的“寞法／說月”等字不作为数值修订理由，原图读数另存。

该段旁注辛酉年癸巳月，正文先积至嘉靖三十九年，再加“今年”月份，末举五月一日庚申。它使用与金镜明钞相同的四个常数，但属于后出的附例，不能当成新发现的唐人原稿。

七项均可复算。同年积年多一的明确对照支，七项均不同；没有只留相符分支。章岁余555／657与日小余35／49继续分别保留，不能相加或舍去后补日。

原文大数采用万进分组，例如“七萬零七百八十八萬七千零七十六”按`[7,788,7076]`分组为707887076；全部源字保持，不把重复的万字先判成错刻。乘除的量纲与原文附在数后的“分／日”字也分别记录，没有据算法默改原文单位。

源月名癸巳由23257410按甲子为1读取相符；源日名庚申由707887076按甲子为0读取相符。同一段不能套一个通用编号偏移。原文“周法”未在所选句中重复数值，除60得月余30、日余56，除360则为330／356，全部并列；未凭余数认定原典错误或推广统一纪元。与梁例707501061、初八甲申所需的编号关系仍须分别解释。

## 默认月计修正了什么

V32曾把大雪发生公历年直接作为待减一的取年，明确交付但尚未校定其原典关系。新附例明确使用所求名义年前一年的积年；《武经总要》1044年段（本地数据：`../tests/fixtures/taiyi_jinjing_v32/wujing-page133.png`）的“甲申年前十一月”提供另一个年标约束。大雪锚年已经是天正十一月窗所求名义年的前一年，再减一年会少十二个月。

当前`jinjing_month_jie_360_v1`保留配置ID，规则实现版本升为1.2.0：

```text
counted_year = cycle_year + 1
annual_accumulation = 1937281 + counted_year - 724
accumulation = (annual_accumulation - 1) * 12 + month_offset + 1
```

`cycle_year`仍是大雪锚年，`counted_year_basis`改为`nominal_year_after_tianzheng11`。同次回执、结构化摘要、文本、二目及主客算、门盘均取修正后的完整积月，未仅改显示标签。

- 1561-05-15 12:00固定`+08:00`的代表钟面同时处于历表普通四月及所选巳节月。原默认23257398修正为23257410，与附例明确数相符；这不是原书提供的确切钟时。
- 1043-12-15的代表钟面对应该书1044年“年前十一月”：周内序由229修正为241，庚子元25局。1044-12-15是另一年段，不能因过去某个配置恰好相符就换日期。
- 金钥匙月计使用另一套完整祖数。它在1561四月代表钟面的完整数为121865730，与附例数相差98608320，差为360整周；这项相位相等没有把两个绝对祖数认成同一个。

现代节气边界、日／时计和历史年表仍分别使用各自配置。此次修正的是十二节月起元的年标，未将朔月、闰月或金镜古日积数接入默认月计。`source_year_label_adjudicated=false`继续表示完整原典年界尚未裁定，局部取数补证不认证完整古历。

## 新算例仍不能通过全年历法

沿用已保存的1940年313页历表（本地数据：`../tests/fixtures/taiyi_jinjing_v8/sino-western-printed313.jpg`），本轮另行抄录完整1561年13个月和1562年正月终界，共14月首、13月长、384日。原表为闰五月；五月初一是儒略历1561-05-14、推算公历1561-05-24，确为庚申。

继承V38的八组朔气诊断轴，不按这一日匹配择法。四支本年取月仍无法包含所求冬至，月份身份未知。完年整日支条件闰三月、完整分数支闰四月，均与原表闰五月不同。两支按已过日数解释时都只有10／14月首日名及265／384个完整有效日期相符，月长分别8／13、7／13，均未通过。

尤其在整日支，707887076虽可算出，条件置闰却把它标成四月月首；原书和历表指的是五月初一。不能只拿数或日名相符就省去月份身份。这项失败与已修正的十二节月取年是不同层次，不能相互抵消。
