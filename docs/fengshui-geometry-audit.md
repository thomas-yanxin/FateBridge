# 实测空间几何与有限搜索

[风水能力](fengshui.md) · [实测工位合同](fengshui-workstation-layout.md)

本页说明空间计算的职责、独立参考和数值门槛。规则作者、版本和来源由 `rulesets/rule_trace` 保留；现场事实、几何可行性和动作许可分别判断。

## 计算及支持的边界

| 所有者 | 职责 |
| --- | --- |
| `spatial_angles` | 精确周期角组合、方向区间、角差、切向角半径与高精度三角分量 |
| `spatial_geometry` | 刚性变换、点对方位、闭凸有限射线、完整足迹方向、入口近远比较、后向交点及中心距离 |
| `spatial_scene` | 位置和角度误差投影、开口相对方位、平面／高度／活动区及显式观察的复合评价 |
| `spatial_visibility` | 凸棱柱深度裁剪、透视遮挡锥、显示面裁剪、阴影面积并集、朝面与声明视野 |
| `spatial_desktop` | 显式所选 BTB／WOFS 条文、实际坐者参考系、植物状态与来源适用条件 |
| `spatial_domains` | 显式点或十进制网格、包含边界的中心裁剪、参考系及有限组合资格 |
| `spatial_search` | 每个姿态独立重算、实体及附着物许可、完整回执、Pareto 前沿和显示截取 |

`AREA_EPSILON=1e-12` 是平方米数值容差。角点射线沿矩形包络角径向延伸，实体是否有尖角须独立确认；显式靠背线段没有高度，不能据它补出眼高处遮挡。中心落区不替代完整足迹碰撞评价。

Pareto 比较使用逐条已知规则维度、改变物件数、移动距离与转角。参与规则维度未知时不可比；至少一项严格改善且其余不差才支配。`max_results` 只截取显示，完整已枚举前沿和回执保留。

## 角度与内部参考系

`compose_degrees` 先作有理周期归约，保留有限输入的微小角及极大角，不先进行可能溢出的浮点求和。正余弦沿轴或对角附近残差求解，使用私有90位上下文及4096项缓存。`GeometryFrame`／`GeometryRectangle` 保存内部工作角；最终 `plan_facing_degrees` 浮点只用于交付，不重建内部状态。

点对方位从原坐标的精确差值计算。重合点返回未定义方向；观察点位于门洞线段上时，正角宽透视模型的 `entrance_visible` 保持未知，已有非零端点仍可提供左右关系。显示面端点重合不能证明整屏在视野内。

## 可见性、阴影与闭有限射线

入口角区包含目标、遮挡物顶点以及两者交点，以保留近远次序改变。显示阴影先取眼至显示面之间的实体深度片，再以精确有理锥面裁剪；阴影面积采用并集。目标正角宽、观察点资格、明确不透明与高度事实各自生效。

角点与背靠共用闭凸有限射线裁剪，保留边界接触、内部起点、共线重叠和最近非负参数。角点方向直接取矩形向量，背向取正向量的负数；距离平方和长度资格保留精确数，最后才交付浮点距离。公开 `PlanSegment` 仍拒绝重合端点，内部退化控制不扩大公开能力。

## 完整工位职责与足迹方向范围

桌面罗盘方向采用完整凸足迹与可平移闭误差圆。足迹包含原点或误差域触及原点时，足迹保留全部方向；点落宫保持未绑定。非零方向弧与罗盘角误差沿同一工作角计算，不把各自舍入后的角相加。工程规则为 `workstation_layout_v1@1.2.0`，作者版本独立保留。

附着物随桌发生实际位移或转动时读取对应许可；微小非零转角不能当作零，未知许可保留确认，明确禁止则阻断。几何结果只判断登记方案资格，不执行现场动作。
