# 月令司令事实与解释验收：v70

本轮补强月令输出约束，未新增司令算法，也未调整旺衰系数、阈值或原典标签。原十九例的完整数值、身印分量、司令资料及通关路径保持原样，其中十七例旺衰分歧仍未解决。解释必须忠于计算，还要求公开接口不能发布彼此矛盾的计算事实；这些工程约束不计为新增原典符合度或现实效度。

## 发现与修复

此前 `BaziEvidenceChain.month_command` 只有通用字典类型。以原十九例分别构造八类错误回执，旧校验全部接受，形成 152 个完整首次反例（本地数据：`validation/bazi-month-command-integrity-files-v1/first152-accepted-contradictions.json.gz`）：

- 把尚未裁定的司令改为已裁定，并虚构选择规则。
- 改错分日合计，或宣称 380 与 360 相等。
- 在同次原文、书影观察和月令中混用不同月支。
- 把未采用的表格次序宣称为已裁定，或直接填入所选司令。
- 把文献所指天干放进不可能的藏干位置，或替换常规月藏干目录。

现用专门的月令／分日类型表达已知事实，在完整输出校验阶段拒绝这些矛盾。无论读取全部结果，还是只请求一个无关字段，错误都不能靠字段裁剪隐藏。遗漏字段不补值，显式未知仍保留 `null`；未知天干身份不伪作“已核对但未出现”的空数组。

首版补强后又发现五个局部读取反例（本地数据：`../tests/fixtures/bazi_month_command_integrity_v1/first5-partial-cross-binding-counterexamples.json`）：缺少重复月支字段时，已知藏干目录、月支或月柱藏干观察之间仍可矛盾。首版源码、wheel 和验收结果保留；最终版继续跨已提供的同次事实核对，不用缺项消除矛盾，也不推填被省略的字段。

## 原典依据和保留的分歧

本轮重读已留存的《子平真诠》PDF73与《滴天髓阐微》PDF170–171；读稿边界与原页哈希（本地数据：`../tests/fixtures/bazi_month_command_integrity_v1/source-boundaries-first.json`）保留。这是开发者核对，未冒作独立专家复核。

《子平真诠》分别讨论身重印轻与身轻印重，身印总和不能替代二者各自的轻重。《滴天髓阐微》将原注与任注分层，任注明言司令出见仍可置而弗论。故本轮只约束资料及回执一致性，不从“司令字出现”推出其可用、身旺或有效通关。

此前留存的《三命通会》完整数字章节和 CADAL 书影继续分层保留：26日、32日的月分日合计，数字本380与所述360的年合计，以及未指认的艮土／坤土均未改写。没有把藏干序位当作司令次序，没有把分日表当作已采用历法，也没有从原典相对节后日数推造出生绝对时刻。
