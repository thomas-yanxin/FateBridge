## 计都原始坐标与过早舍入

原实现先以浮点执行`(罗睺坐标 + 180) % 360`，随后才以该派生值分宫、分宿。虽然分类函数已用精确有理数，舍入丢失的原始信息无法恢复。例如原黄经`29.999999999999996`的精确对点仍在210度之前，浮点加法却可得到210；直接分类会由辰宫跨入卯宫。原赤经`9.999999999999998`也可在对点计算时提前落到190度宿界。

修复只改该计算所有者：从原生罗睺值精确求黄经／赤经对点，最后交付浮点；保留两项源值和明确派生对象，宫宿分类使用源值重建的精确对点。本命与目标星空通过同一`body_placement`消费，不在服务、CLI或模型中复制规则。专用果老输出模型具名声明这三项来源字段。原宫宿表、研究宿界、旧解析模型及古籍验收政策未改动。

原始坐标标量采用最近binary64并规范360到0。宫宿内展示仍使用已有半开区间约束，不能把这类有意保边显示当成最近标量误差。对点恰在浮点舍入中贴界时，源值可解释显示值与精确归属的差别。
