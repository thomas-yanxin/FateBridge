# 未知钟时的宿占历日结果

`suzhan`允许省略`time`或给JSON null。历法、参考历日、半日与闰小月重建候选继续由现有领域函数计算；`chart`与`astronomy`为null，`params.calculationMode=calendar_date_only`，`birthTimeImputed=false`。经纬度和盘式选项没有用于该日历层。空字符串和错误钟时仍报错，不转成未知。

已知钟时继续计算星图；未知钟时不以00:00、中午或示例值代替。输入钟时未知、日历候选已定、原典半日已声明是不同事实：明确选择前半可以使某日主宿确定，但不会得到物理星图、宫位、瞬时月宿或现代角距tithi。现代已知09:00也不自动证明古籍所说前半。

跨参考日期时，应读取每个`candidate_days`以及其中的`candidate_mansion_days`。支持范围之外的日期支继续保留，候选完整性为false；可支持的支不升级为唯一主结果。默认闰月政策未定时，即使只列出一个宿名，也不能据此称已定。未提供本命宿不虚构个人三九日。

REST可以提交`{"date":"2024-08-04","time":null,"zone":"+08:00","calendar_profile":"hinoo_t1299_host27"}`；CLI省略`--time`。MCP使用同一请求Schema；已运行的客户端是否载入新定义须另行确认。这些是虚构工程夹具，不是个人命理判断或现实预测样本。

该功能扩大缺钟时资料的可交付范围，没有新增古代日界、闰月补配先后或原典权威认证。古代平明、桧尾半日端点与原典异文仍按各自来源标为未定。计算可复现、接口测试通过与现实预测效力分别验收。
