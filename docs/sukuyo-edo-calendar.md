# 日本近世历法期别与置闰资料

`calendar_basis=japanese_naoj_historical_utc09`的近世结果，在`calendar_reference.edo_calendar_method_reference`交付具名历法时段及来源比较。它以实际算得的阴历年选择文献期别，不以出生公历年或年号名称选择；没有改动宿主月日、闰标志、干支、宿名或原典半日。

[NAOJ馆藏说明](https://eco2.mtk.nao.ac.jp/koyomi/exhibition/030/)列貞享暦1685—1754、宝暦暦1755—1770、修正宝暦暦1771—1797、寛政暦1798—1843、天保暦1844—1872。因此宝历三、四年仍处于貞享暦时段；公历1755年初仍可能是阴历1754年，须依据实际返回的阴历年。本字段是具名文献时段，不能认证该日全部原始颁历或具体地方时。

同一馆藏说明选录了1755年颁历以今夜、今暁区分夜半前后的注法。这是该文献的日期用语，不是T1299平明、桧尾半日的钟时定义；不能把夜半、天文合朔或中气时刻直接移作宿曜换日边界。

## 十行比较与三项作者判断

[内田正男《宝暦暦法置閏の疑問》](https://www.asj.or.jp/geppou/archive_open/1973/pdf/19730306.pdf)第67—68页讨论了颁历置闰与所述规则的差别。当前来源记录保留第3表全部十年：1773、1775、1778、1781、1784、1786、1789、1792、1794、1797，并将作者第2表指出的1773、1775、1786三例与其余比较年分开。

表3左侧是颁历闰月，右侧的月名是按规则置闰后的翌月；它不是另一套闰月名。定朔、中气小数保留原串，未转成现代钟时。作者区分事件时刻先后与时刻所属历日；1792、1794等后例也保留，不能只取三例拟合一条普遍的“中气早于朔就移动闰月”规则。

`intercalation_research`在宝历／修正宝历文献期别内保留全部十行与当前年对应记录。`author_rule_applied_to_primary=false`，`calendar_labels_changed=false`；现行NAOJ月号没有被作者认为应有的月号替换。论文所述原颁历、算书和作者计算未因此获得本次独立复核，不增加独立历史观察，不规定T2465闰月复用与缺日补配的先后。

## 原定月大小与实际覆盖

[NDL大小对照表](https://www.ndl.go.jp/koyomi/chapter2/s1.html)将1872年十二月列为大月，而本系统历史参考因明治改历只覆盖十二月初一、初二，`source_month_length_days=2`。`reform_month_length_reference`同时保留原定30天与实际覆盖2天的差别；不能把它改标为数值相等，也不能补出已停用的旧历日期。

本轮逐行保存NDL年顺／大小顺两表的全部215个正文行，各自折合189年；它们是同一出版物的两种排列。2337个月号／大小对照有2336条长度相同，上述30／2差别继续单列。另存NAOJ1752—1754三年37条月首对照，全部与冻结表相同。这些均为来源／表值比较，不是独立古代观测、原82743／165486门的替代或现实预测准确率。

原典日界、前后半的现代映射、闰小月补配优先及完整历史颁历校勘仍未解决。
