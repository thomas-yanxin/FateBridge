# 通关部分事实一致性与原19例复核

本轮修复输出校验和关系分类的一致性，没有采用新的旺衰、根力、司令或通关算法。19个冻结的矛盾输入此前均被合同接受，修复后拒绝；3个合法对照继续接受。它们是人工故障注入，不是19个真实命例计算错误，也不增加原典符合数。

已给节点引用所包含的天干、干藏层与柱位，不能因省略冗余五行、位置字段而失去校验。已给节点的合绊或根状态，也不能因另一个节点缺项而被路径改写。一个柱位只能有一个透干，已给藏干必须能够属于同一地支；单纯存在木火土等生克链仍不证明有效通关。

校验只判断已给事实能否同时成立，不补入缺失字段，不调用旺衰求解器，不把未知力量改成强弱。有限物理候选使用项目既定藏干目录；这只是目录合同一致性，不是该目录已获原典认证。未知关系的分类与保留上下文统一为 `unclassified`，不再因为种类不是“天干合”就误作地支合绊。完整未知事件仍保留在关系上下文中；`no_binding_recorded` 不能解释成所有通关条件已清除。

依据仍沿用既有的《子平真诠》身重印轻、身轻印重标注，以及[1947年《滴天髓阐微》书影](https://commons.wikimedia.org/wiki/File:SSID-11335994_%E6%BB%B4%E5%A4%A9%E9%AB%93%E9%97%A1%E5%BE%AE.pdf)和[《三命通会》卷二书影](https://archive.org/details/06066038.cn)的既有月令、通关校读。此次在线只重新核对来源元数据，未重新校勘19例全部原页，不作新增原典标签。名义分日表与反对机械分日的原文仍并列；没有节后日数的命式不补出生日期、不择表取分。

逐例复核覆盖19例的259个物理节点和1797条路径出现次数（包含本气子集的重复展示，不是独立样本）。身与印的成员、透藏位置及同次有理数能量分别核对；没有把身印总量当作日主强度。原19例仍有17例不符，XX-16与FJ-08为先前已符合的两例，本轮新解决数为0。完整逐例表见验收记录（本地数据：`validation/bazi-passage-partial-facts-v1.md`），原文条件及来源记录散列见审计数据（本地数据：`validation/bazi-passage-partial-files-v1/audit-final-first.json.gz`）。
