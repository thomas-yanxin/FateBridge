# 大运分析时刻、十年闰日裁剪与未来回拨

本轮修复了出生时间范围内短暂大运状态被采样漏掉的问题。新增独立闰日队列中，3,225条原本遗漏已知状态的记录全部恢复，未新增状态遗漏、旧状态丢失或旧包络收缩。严格跨根包络仍有失败，原40,219条证据及后来完整复放的54,818条失败均未删除或改判。

## 原因和计算修复

现有政策把每个十年边界分别锚定到初始交运墙钟，再增加对应年数。初始墙钟从2月28日末进入闰年2月29日时，投影到非闰年的边界会从2月28日末退回2月28日零时。出生时间的三个分钟样本可能跨过这段短暂状态，却全部落入同一种状态。[dateutil年数运算](https://dateutil.readthedocs.io/en/stable/relativedelta.html)约束目标日期的有效日；这项离散跳变必须单独处理，不能由连续线性插值补出。

生产层补充三类有限事件：实际分析时刻的初始交运墙钟逆像、十年闰日裁剪逆像、未来民用回拨结束的逆像。所有13个配置边界分别处理；非闰裁剪负向控制和同名墙钟不同fold的控制同时保留。[PEP 495](https://peps.python.org/pep-0495/)区分回拨的两个时刻，逆像核对使用实际UTC分析瞬间，避免把同一个墙钟标签的另一次出现当成当前状态变化。

单点时间线的日历加年、fold选择及不存在钟时的前移规则提取到共享函数，原规则未换成新口径。原分钟网格保留，事件探针另计；数量和频次仍不是概率。未来钟时逆像不再被冗余的分析逆像切点切碎，避免相邻微秒括区间被隔断。版本标识为 `dayun_analysis_clipping_and_civil_probes_v3`。

例如冻结的UTC工程控制，名义出生时刻为1900-01-18 02:14:18、范围正负1分钟，分析时刻为1914-02-28 23:59:59。三个分钟点全部给出第二步大运；但参考出生探针02:14:49.396351的十年边界在分析时刻之后，实际仍属第一步，稍后闰日裁剪又回到第二步。这个按现有政策计算的短暂区间只有约8.3毫秒，原分钟样本无法发现。修复后同时交付第一、第二步候选；该数值不代表出生记录或天文模型达到毫秒精度。
