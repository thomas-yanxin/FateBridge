# AA1996 太阳后端的显式接入

`aa1996` 现已接入领域历法服务，使用 Moshier AA 5.6 的 1996 年地月质心级数、完整 Moshier 月球和重新计算的 Swiss 视位置流程。当前配置版本为 **1.1.0**，实际模型名是 `fatebridge_moshier_aa1996_solar_v1`，与原生 `moshier` 分别记账。默认 `auto` 配置未改变。

来源与计算方法见[作者级数研究](https://github.com/thomas-yanxin/FateBridge/blob/99a5cecea99201823fc7e00d55a80dd9fd490c59/docs/liuyao-moshier-aa1996-audit.md)，接入记录见第三十七轮（本地数据：`validation/liuyao-v37/README.md`），内部运期范围与来源标签修复见第三十八轮（本地数据：`validation/liuyao-v38/README.md`）。本次没有用参考残差拟合修正表，也没有将宽松的候选保护时间当作数值门槛。

从项目根目录构建到一个尚不存在的绝对目录：

```bash
uv run --locked --extra dev python -m fatebridge.fetch_aa1996 --output /absolute/new-aa1996-build
```

构建器下载并校验固定版本源码，核对 32 个计算源码文件，再调用本机 C 编译器。目录内保留原包、来源许可证、构建命令、日志、二进制和 `manifest.json`。可用 `--swiss-archive`、`--aa56-archive` 指定同散列的本地原包。失败目录保留，重试使用新目录。

从 1.0.0 升级时，需要用当前模块在新目录重新构建。1.1.0 扩展了已验证的内部工作范围，来源配置散列随之变化；旧构建不会被静默赋予新范围，加载时会明确失败。32 个计算源码文件及算法保持原样。

启动所需配置为：

```bash
export FATEBRIDGE_SOLAR_TERM_MODEL=aa1996
export FATEBRIDGE_AA1996_MANIFEST=/absolute/new-aa1996-build/manifest.json
```

安装后的模块入口相同。默认 wheel 不包含本次改版的原生二进制或第三方 C 源码；运行请求不会触发编译、下载或替换已安装 Swiss 库。实际执行平台是 macOS arm64；Linux 构建分支尚未执行，Windows 尚不支持本构建器。

加载器校验模型、平台、ABI、配置和二进制散列，将已校验字节复制到私有路径，核对计算入口实际所属映像，并将模型／源码／映像散列写入计算回执。原生返回标志 `260` 仅表明使用的选项和类别，不能独自证明模型身份。缺失、篡改、错误 ABI、来源变更、错误返回标志和非有限结果会失败，不会静默换成其他太阳模型。

单独年份 API 维持 1800—2200 年；1.1.0 另允许风水内部运期端点使用 1784—2204 年范围。在修改范围前，原二进制通过原有全部 10,104 个交点的 1 秒 TT 检查，范围外 480 点最大差 0.786719 秒；升级后正式服务再次执行同一完整队列，最大差 0.899854 秒。原 4,872、扩展 9,624 点及冻结一般历元队列也分别保留验收。交叠队列不能相加；等效时间误差与交点时间差分别报告。这些结果共享 DE440 参考框架，不是绝对 UTC 观测或现实预测证据。

六爻、六壬与金口诀已通过本地 REST／CLI／真实 stdio MCP、投影及同一 run 全文取回检查。v37 留下的 58 项运期端点失败在 1.1.0 中已修复；v38 的 R1 和 R2 均完整通过原 14,364 查询与 4,788 个消费事件的数值门槛，原失败记录未覆盖。运期和日期型命卦的保护原因现在明确标识 AA1996，避免将候选保护写成近似回退或其他太阳模型。五秒保护范围仍是操作性候选保留，不是新的精度门槛。

原生 Moshier 的 501 项失败继续有效。完整原典符合性、最新真实模型解释复验、全部平台与部署验收分别保持原状态；本次不授予满分或权威认证。
