# 巳寅申条件不能只作提醒

同版[1925年《增删卜易》影印](https://upload.wikimedia.org/wikipedia/commons/4/42/NLC416-12jh005345-45344_%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93.pdf)第98页明确，巳爻遇寅长生而所列日月、动爻或变爻又逢申时，要论刑而不论生。旧程序只生成提醒，仍把该寅日同时列为木生火和已核长生，再把长生资格送入元忌支持条款。提醒并没有改变实际计算。

新增`conditional_analysis.penalty_conditions`，逐爻记录所列范围内的寅、申来源及明确排除的别爻变支、静位变盘支。日月与实际本位变支直接取事实，原爻活动采用同次资格；明动只确认位置，不认证刑害效力，暗动未知则保留未知。活动资格更新后再次核对三支上下文，避免先算出的长生资格停留在旧活动状态。变爻只按本位，伏神另建自身上下文，不借飞神的变支。

在巳爻寅日，三支条件已核时，`growth_conditions.condition_match=false`，共享强弱层不再把同一个寅日当作已确认生扶或长生。原始五行生向、阶段位置及23条元忌公式保留，综合原子、实际源资格与摘要读取新资格；其他月令支持、回头生、旬空和反制继续存在。申活动未定时，不提前确认长生，也不把未知当作假。

第83页三刑专章明确提醒独犯三刑的有限经验。此次只把三支条件列为总作用待审，`effect_condition_match=null`，不生成确定刑害、临床或现实凶事。新待审反制也不能触发“无扶受克来源不匹配”的确定否定：那一分支仍需已有明确反制，而不能只凭本轮未裁定的刑。月令有扶的原事实仍保留；本条既不靠加减分断旺衰，也不以多个来源票数判断成败。

伏神层同步区分原始`hidden_calendar_generates.matched=true`与所列条件下`qualified_matched=false/null`；受生门槛和摘要读取资格。公开输出可沿`penalty_growth_source_path`和伏神`reception.penalty`回查。三端真假与未知叶子、同次全文、源路径和文字均单独检查。

后补动变来源反例还揭露一处归因错误：寅、申都来自动变，原待审项却把午月写成反制来源。现在只在日月确实参与时使用日月标签；动变独立构成的关系以`location=pattern`记录查询主体，真实寅申参与者另列并回指同次来源。它仍是未裁定的三支总作用，不是虚构午月克火。`source_rescue_used`如实保留实际引用本位回头生的事实，文字据具体反制类型说明待审内容，不把该许可写成已消除刑害或存在并未发生的日月克制。原始文字记录（本地数据：`validation/liuyao-v20-attribution-text-before.json`）和首次回归失败均保留。

当前贯通的是寅日的长生与同一日生扶排除。本位变寅或其他动寅提供生扶时，与三刑条款的先后裁决仍未完整校核；旧章节的回头生许可不等于已经通过这一未审分支。三支结构的识别范围与生扶排除已落实的范围不能混同，本轮不据新增字段宣称全条或全书完成。

原始资料、引句勘误、十条开发结构和现代日期映射见资料说明（本地数据：`../tests/fixtures/liuyao_penalty_v20/README.md`）。现代输入及书中月日结构都不是盲测事件或现实预测证据。固定源码、原始失败、三端及构建验收见第二十轮记录（本地数据：`validation/liuyao-depth-v20-verification.json`）。原全时期Moshier超差、火帝旺绝位未校、全书综合及自由模型解释等缺口不由本轮消除。

## 最终验收

归因修复后的固定副本包含727个包文件，源码与支持文件在验收前后散列一致。637项六爻完整回归、80项星历与时标检查全部通过，均无失败、错误或跳过；24项静态、来源和生成契约检查通过。构建wheel的包文件集合及内容逐项匹配该副本，37项隔离包内检查通过；本地候选构建（本地数据：`validation/liuyao-v20-candidate-builds/README.md`）已保存，没有发布。

共享回归627项通过、2项失败，均为风水月星输出缺少`bundle_version`，原失败保留。先前634通过、1项追踪登记失败的候选，以及补登记后通过635项但仍存在未覆盖归因错误的候选，全部保留在候选历史（本地数据：`validation/liuyao-v20-candidate-history.json`）。最终结果重新执行于归因修复后的源码，不将先前绿灯重标为新源码的验收。

两版对照（本地数据：`validation/liuyao-v20-attribution-before-after.json`）确认18条阶段位置、23条原公式和原始生向未改，实际长生资格与依赖强弱如实重算。64静卦对照（本地数据：`validation/liuyao-v20-attribution-no-triad-continuity.json`）保留全部64个卦，55个三支条件均不存在的卦，在预先列明版本号、范围说明及新增追踪条款等例外后，旧字段投影未见差异；另外9个适用或未决卦单列，不算预测成功。

15个历法与时标依赖字节未变，六爻日期计算相关函数AST也未变，既有73414日期及730日期子队列通过连续性证据（本地数据：`validation/liuyao-calendar-v20-attribution-continuity.json`）继承，未重复计入新样本。2026年两环境各24节气与144个公开边界探针重新检查通过，原全时期Moshier的501个超差点不被替代。当前共享技能文档仅梅花天气段发生并行更新，六爻及共享条款对照（本地数据：`validation/liuyao-v20-live-skill-scope.json`）保持一致，未覆盖其他工作的改动；本轮也不认证整个实时工作树。
