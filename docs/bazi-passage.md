# 通关路径、同柱藏印与原典实数

[八字判定](bazi-assessment.md) · [真实根量](bazi-complete-bureaus.md)

通关需要中介，还涉及位置、合绊和实际力量。
本轮依据李雨田校订兼发行、上海大东书局经售的1947年4月初版
[《任注滴天髓闡微》书影](https://upload.wikimedia.org/wikipedia/commons/d/db/SSID-11335994_%E6%BB%B4%E5%A4%A9%E9%AB%93%E9%97%A1%E5%BE%AE.pdf)，
补充原局生克中介及透藏计数，并保留尚未正确计算的原典旺衰。
版权页PDF3明确区分发行者与经售处；旧冻结夹具中的书目角色误记另存
勘误（本地数据：`validation/bazi-ditian-imprint-erratum-v1.json`），不覆盖其原始记录或命例标签。

## 位置与层次

《通关》PDF197–199论中介、隔位、合绊及四冲反助。
`classical_passage`逐项记录实际天干和全部藏干，分别列透干、本气、全部藏干及跨层路径。
相邻、隔位、越位和同柱步骤保留不同状态，剩余根及合绊直接读取同次计算。

《官杀》PDF215的`壬辰 壬子 丙寅 癸巳`说明寅印纳水生身；
PDF216的`戊午 己未 壬申 辛亥`说明坐下印绶引通财杀。
印在日支、身在日干，不能因为三节点不占三个不同柱位就漏掉该候选链。
新增`mixed_paths`保留这些跨干支及同柱节点；位置事实仍不独立裁定通关效力。

`remaining_root_state`只说明提供的真实藏干预算是否尚有正量；
合成贡献不冒充藏根，缺少账本时为`not_supplied`。
`effective_passage`保持`not_adjudicated`，本模块不改能量、根量或全局强弱。
本表只算原局，不含运年接通判定；不能从静态路径填造某运年已经化杀或由弱转强。

## 一杀四制与印不透

原书PDF217的两例“一杀逢四制”，其中“杀”只数七杀，“制”涉及食神与伤官。
PDF218的`甲寅 戊辰 壬辰 壬寅`为“五杀逢五制”。
这些实数不能套用藏干0.5的旧加权计数，也不能当作有效力量或制杀成功。

`star_occurrences`读取同次十神星位，每个非日干项和每个藏干项各数一次，透藏分列。
日干是被评对象，不额外计为支持票。缺少类别不补零，数量类型明确标成实数。
原书另一例“印虽不见”同时有两辰藏乙印，因而不能解释成没有藏印；
首轮计数可分别核对透干为0和藏干为2。

## 调用

综合及九专题发布`evidence_views.passage`、`passage_hidden`、`passage_mixed`和`star_occurrences`。
复制所选视图的`fields`，配合`strict_fields=true`和`include_snapshot_text=false`；
视图名不是请求参数。首轮通路视图只带透干、本气与摘要，完整数组不裁成有利片段。
全部藏干和跨层路径可能较大，按同一run的`result_delivery`分页读取。

结构化引用核验需要完整原结果。投影视图不能独立认证完整结果散列，不能为让核验通过而放宽这一点。

GS03原文最终判日主坚旺，当前规则仍未表达隐藏印化杀的相对效力。
GS12明说火旺之极，但整段最终以癸水仍通根判戊癸合而不化；先前把假设性的化火为忌写成实际成化，现已更正。相邻GS13换丑为巳才明确判化，不能为了补齐合化功能把两例都转换。原始首跑和错误标签继续保留，[现行校勘复核](bazi-current-collation.md)另按最终结论检查。
这些是后续要补齐的计算问题，不通过删案例、改源标签或把未知填成符合来消除。
