# 六爻历法扩展核验：AA1996的21项失败与实际节月影响

本轮冻结1684—2304年每年全部24节气，共14,904个TT交点，检验将AA1996输入扩展至1700—2300年及相应运期端点的可行性。扩展未通过原1秒门槛：候选仍有21项超差，且其中8项在原生Moshier中本来合格。生产AA1996范围保持原样，全部失败保留。

已有显式SPK生产路径在同一完整队列上通过，最大TT差约80微秒。本轮增加了适用范围的实测证据，没有修改默认选源或生产计算，也没有将这次工程核验升级为全历法、全原典或现实预测认证。

## 资料、预先冻结与独立参考

[Moshier作者站点](https://moshier.net/)提供AA5.6；项目先前固定下载的`aa-56.zip`中，`ear404.c`明确标注December1996，并列有相对DE404的地月质心级数残差。源码原包、实际编译源与二进制均保留。[JPL的DE440论文](https://ssd.jpl.nasa.gov/doc/de440_de441.html)说明其覆盖1550—2650年；本轮使用既有完整DE440内核，未下载新星历，也未从参考残差拟合补偿表。

在产生新参考和评估候选之前冻结全部14,904条查询、原1秒TT门槛和原始输入散列（本地数据：`validation/liuyao-v41/protocol.json`）。区间包含原有1784—2204年的10,104点，并新增4,800点；不在观察失败后删年份或缩小区间。候选求根从固定月内TT括号开始，不用参考根作初值。

独立参考使用Skyfield1.53、NumPy2.2.6和完整DE440，固定IAU2000B、日期黄道视位置及40次二分，不导入FateBridge。内核SHA-256为`a4ce9bf9b3282becc9f4b2ac3cebe03a2ae7599981aabd7265fd8482fff7c4b5`。参考逐点文件（本地数据：`validation/liuyao-v41/reference.json`）与实际环境（本地数据：`validation/liuyao-v41/reference-environment.json`）分别记录。

重叠10,104点中，10,103点逐位相同，1872年第11号节气相差80.466微秒。新旧两份数值均保留；原10,104点和原4,872点还使用各自原参考重新验收，未覆盖原值。求根括号仅表示本次浮点函数的数值分辨率，不是绝对物理精度。

冻结后、候选评估前，另加来源身份核对修订（本地数据：`validation/liuyao-v41/identity-amendment.json`）：用`dladdr`核对实际计算映像，并重放原501、范围外原17项失败身份。原评估脚本及原协议均保留，数值算法、查询和门槛未改变。

## 完整数值结果与退化

| 同一固定队列 | 原生Moshier对照超差 | AA1996候选超差 | 候选最大TT差 |
| --- | ---: | ---: | ---: |
| 全部14,904点 | 1,912 | 21 | 1.305807秒 |
| 原范围10,104点 | 1,196 | 0 | 0.899854秒 |

| v39的1700／2300年48点 | 原17项 | 0 | 0.900015秒 |

21项均位于2240—2298年，详细身份和误差见完整汇总（本地数据：`validation/liuyao-v41/comparison-summary.json`），所有原始求根结果见逐点JSONL（本地数据：`validation/liuyao-v41/observations.jsonl`）。原501个失败身份与原17个范围外失败身份均完整重现；AA1996对原4,872点仍无超差。

成对转移表（本地数据：`validation/liuyao-v41/failure-transition-matrix.json`）显示：1,899项原生失败在候选中合格，13项两者都失败，另有8项原生合格而候选失败。因此，不能把“1,912降至21”称为修复后只剩原来的21项。此扩展仍被判为不合格。

实际生产年份API随后对全部14,904点分别运行原生Moshier和显式SPK。原生仍为同一1,912项超差，最大2.632213秒；SPK为0项超差，最大0.000080467秒。见生产路径回执（本地数据：`validation/liuyao-v41/production-summary.json`）及完整输出（本地数据：`validation/liuyao-v41/production-observations.jsonl`）。实际原生API与研究对照库的全部根最大差160.933微秒，失败身份一致。

这些队列有包含关系，不能相加为独立事件数。SPK与参考共享DE440谱系；通过是本队列的TT数值证据，不认证历史UT1、未来UTC或未来闰秒。

## 误差发生在哪一层

按事后诊断协议（本地数据：`validation/liuyao-v41/diagnostic-protocol.json`），对全部14,904点分别比较ICRS真几何位置和日期黄道视位置，没有只挑21个失败点，也没有把参考位移回填候选。

AA1996新增21项的几何黄经差平均约0.04235角秒，视位置差平均约0.04454角秒；两者之差平均约0.00219角秒。见几何分解（本地数据：`validation/liuyao-v41/geometry-summary.json`）。误差主体在几何位置层已经存在，单靠UTC标签修订不能消除；目前尚未进一步分离作者EMB级数、月球项、参考系及DE404／DE440模型差别的各自贡献，不能把全部误差直接归给某个系数。

## 实际六爻节月与接口核对

对全部21个新失败点，取严格位于参考交点之前的最后一个整数民用秒，冻结输入及期望节月表（本地数据：`validation/liuyao-v41/boundary-consumer-protocol.json`），再调用本地REST、独立stdio MCP及独立进程CLI。未来时制统一采用明确的测试情境：假定TAI−UTC一直为37秒。这不是对真实未来UTC的预测。

| 实际返回的来源 | 21例中与固定参考月支不同 | 当前节气不同 | 三接口事实一致 |
| --- | ---: | ---: | --- |
| 本机已配置Swiss文件星历，`swieph` | 1 | 1 | 是 |
| 空星历目录强制Moshier，`moshier` | 9 | 19 | 是 |
| 显式SPK，`fatebridge_jpl_spk_solar_v1` | 0 | 0 | 是 |

结果分别见原生文件星历／SPK（本地数据：`validation/liuyao-v41/boundary-consumer-results-r3.json`）和强制Moshier（本地数据：`validation/liuyao-v41/boundary-consumer-results-r4.json`）。189个结构化观测的实际模型标识逐条核对；不能把请求`native`直接叫作Moshier。Swiss文件批次未在调用时固定具体SWI文件的字节身份，只能据实际返回标志确认来源类别，不能将该批次提升为该数据集的完整精度认证。

2260年清明例尤其说明验收边界：测试输入位于固定参考交点前约9.536毫秒；Swiss文件模型的根比参考早约66.867毫秒，于是按其模型已经进入辰月，而固定参考仍属卯月。数值差满足1秒门槛，并不保证交节附近每个输入都与参考分月一致。原模型内部自洽、与某份固定参考一致、真实未来历法正确是不同证据层。

AA1996原1.1.0的年份和TT范围保护在全部21例上仍明确拒绝越界，见保护与来源核对（本地数据：`validation/liuyao-v41/guards-and-sources.json`）。未用无来源的跨域回退掩盖这21项失败，也没有把42次预期拒绝算成42个天文精度样本。

## 保留的失败与交付状态

首次参考启动缺Skyfield，后用固定版本uv隔离叠加环境执行，未同步或改写原基础环境。初次REST字段参数把列表拼成字符串而得到422；第二次CLI误用重复`--fields`，只保留最后一个字段，审阅脚本因此失败。正确CLI语法为单个`--fields`后跟多个值；调用脚本、原始拒绝、缺字段输出和修订结果均保留，没有将调用错误记为领域算法故障。

本轮冻结3,466个源码／脚本／测试文件，未修改生产计算。此前v40的455个封存证据文件逐字节保持不变；本轮未重跑旧共享套件，不能把此前1,032通过／原14失败写成本轮新结果。真实模型没有新增调用，原典整体符合性、模型解释有效复验和现实预测也未因此通过。

来源、完整性、失败索引、复现与封存入口见本轮完整回执（本地数据：`validation/liuyao-v41/README.md`）。下一步应优先解决更广年份的高精度太阳来源及近交节的解释敏感性，继续保留这21项失败和8项候选退化；不能靠缩窄区间、经验残差补偿或改写原验收数据取得满分。
