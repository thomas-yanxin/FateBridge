# 六壬与金口诀：规则、输入与验证范围

[文档中心](README.md) · [API 参考](api-reference.md) · [算法状态](algorithm-status.md)

`liureng_gods` 与 `jinkou` 提供有限的盘式规则、同课条件及来源轨迹。先核对时刻、地分、昼夜贵人和所选规则，再阅读三传、四位及条件事实；完整字段见[API 参考](api-reference.md)，咨询取证见[占式参考](interpretation/zhanbu/ren-evidence.md)。

当前支持的课内关系包括六壬三传、旬空、十二运、干支相加与三合名义局体，以及金口诀四位、遁干、阴阳用位、得气、破支和课钤条件。支未齐、原文未裁或条件缺失时保留未知；支齐不证明实际合化，用位不等于完整综合用神。

### 显式约定与未解决事项

- `is_diurnal=true/false` 可在 REST、MCP、CLI 明确选昼贵/夜贵。省略时卯至申为昼、酉至寅为夜。未自动计算当地星出星没；原文特别指出昼夜长短随季节变化。
- 金口诀 `di_fen` 应来自已确认的方位或起课方法；省略保留软件按时支的回退，并返回 `di_fen_source=hour_branch_fallback_not_observed_direction`，不把它当现场观测。
- 月将用实际民用瞬间判断中气；真太阳时校正用于日时柱，不把太阳钟的偏移再次应用到天文事件。已核对 2026 年 12 次交中气及不同时区的边界，未认证全部历史历法。
- 季节旺衰采用辰戌丑未整月土旺的工程口径，未认证季末十八日土旺等异法。课内已实现十二例共有的唯一不受克规则；多候选、日下旺衰、无克从旺取用及全部格局的综合裁决未覆盖，不能把阴阳用爻规则当作完整断课法。
- 金口诀转录本“甲子日亥时巳位”例称勾陈；按同本夜贵未逆行应得朱雀。保留冲突，等待刻本校勘。
- 辛酉课例称四位纯阳，但同本天乙己丑属阴。程序保留贵神固有属性，不为匹配此句改表。
- 神煞、旺衰、动爻提供传统结构依据，不把医学、灾祸、生死断言转成产品预测输出。

以上疑文登记在参考集的 `unresolved` 中，审计会明确列出。没有因疑文而修改预期标签、删除失败来源或把不支持算成通过。

### 四柱、民用钟与实际星历

完整结果把日干、日支、月建、月将、四位、旬空、季节旺衰及阴阳取用接回同次四柱，六壬天地盘、天将、三传旬遁与十二运保留相同锚点。公开字段投影核验实际可读依据，不能把另一占日的完整课盘接在本次四柱下。

`analysis_utc_offset`与命名时区共同选择重复民用钟；错误偏移及跳钟缺失时刻拒绝。日时钟面与年／月UTC瞬间分别参与缓存，星历目录、文件、库实例及实际返回标志均属于计算环境。例如哈瓦那2021-11-07两次00:30分处立冬两侧，应分别使用戊戌、己亥月；两次月将均为卯。Metlakatla的分钟边缘参考仍有发布时间不确定性，不能把时区表示核对当新增天文观测。

### 交气时间尺度与边界序列化

太阳视黄经交点在TT求解，再经共享时间尺度层转换民用标签：1960年前保留UT1／ΔT历史约定，1960年采用[SOFA历史UTC偏移与日漂移](https://www.iausofa.org/2023-10-11c)，1961—1971年采用IERS历史UTC漂移，1972年后采用已声明闰秒表。未来闰秒在表到期后保持末值属于假设，实际依赖公开转换方法、到期日及是否触发。小数秒避免先舍入后判断边界，其位数不代表微秒物理精度。

原紫金山天文台126年3,024个公布分钟标签按原30秒线比较：原生Swiss有3,003项符合、21项未通过，最大差30.905079秒；有文件解析和无文件默认配置各22项超差。原4,536组中气边界对符合，同一队列DE440 TT对照在原1秒线内。早期整秒舍入得到的3,019／3,024不作为当前成绩。既有JPL原始响应12个太阳坐标中10项符合原0.1角秒线，1900与2099两项未通过；它们不是12个独立交气时刻。

IMCCE OPALE保留三条来源时间路线：初始504项原生／解析各1项历史UT1超差；文档时间约定244项分别4／3项超差；按来源自身钟差转换TT的288项均在原1秒线内。它们复用原PMO事件，不能相加为新增独立观测，也不能抵销分钟标签失败。

### 完整年表队列与历法依据

香港天文台1901—2100年200份年表覆盖73,049个日期，日柱、所测时柱及年／月柱和月将日期约束比较均未发现差异。原72,723个库内农历标签一致，另326日由同一HKO来源的月首资料接入核对；同源接入不计作独立天文证据。交节当日的前后两种可能作为未定探针单列，不把年表日期当精确交气时刻。全部4,800个节气日期在四种配置下均保留7项近午夜差异，不改交界求一致。

月将与节气按民用瞬间，真太阳钟只用于日时柱；`calendar_policy`声明实际输入、钟面、23:00子初换日与归属日期。天文求解失败返回依赖错误，不以线性回退起课；跨夏令时的间隔按实际瞬间计算。来源日期正确、提供者可用与物理精度合格分别核验，完整历法域仍未认证。

### 遁干与原书标签缺项

64课四位图的128个神将遁干栏位均未明示，字面标签新增0、符合率保持null；不把公式推导当作原书答案。原课钤重跑仍54符合、4不符、6未判，四位重建46/16/2，旺衰书影11/12，旧缺口不抵销。

### 神将遁干、合与旬的分层

新增金口诀干元类当日五子遁干比较，区分贵神固有干、神将本支五行与当日遁干；不把干类财动同类补进四位五动。六组原书合例的天干均合而只有一组支合，两遁干支自身旬与占日旬也分列，候选五行不改写成已合化。修复旧输出合同接受将当日壬干替换为固有丙干的缺口，错误在投影前拒绝。金口诀规则集1.7.0，旧公式120个有效输入和原四位结果保留。

字面起点、条文及局部示例与规则展开分开验收，1,440模拟环境的5,760项生克与3,600对甲子属性比较符合；不算新增现实事件。原旺衰书影仍11/12，完整合化、五种位置合、综合取用与自由文本验收仍未完成。

### 四位位置生克及相生与隔位克的并存

新增金口诀六对完整位置关系及十四条原文结构，涵盖内外战、合局、上下次第生克、两位同克与五比。各条件保留方向、全部／任一要求及原页，逐位相生仍可同时有隔位克；合局不混作三合或合化，合比不混作一类朝元。金口诀规则集1.6.0，原四位、旺衰与取用保留。完整日下五态和统一取用优先级经重新查阅仍未裁定，原旺衰书影重跑11/12、退出1。

十四条定义、三十项模拟正反探针符合；625种五行组合的8,750项结构与3,750项两位关系符合，不作新增古例。

### 德禄马定位与同次课盘事实

补齐《探原》明示的天德、月德、日德、日支德、日禄、驿马、天马。按天盘星支反查地盘，输出实际天将、旬遁、两种空及入课入传；月序明确以节换月月建寅至丑索引，不能误作农历月或月将。阴干日德及天德寄支不拿日禄替代，旬空不补遁干。六壬规则集1.4.0，金口诀本课仍1.5.2，快照与摘要同步返回定位事实。

80项字面表项符合，其中10项日禄复用；8,640组模拟环境的60,480次定位核对符合，不是新增古例或现实命中。完整历法、完整原典和自由文本语义目标仍未完成。

### 六壬十二运与月建五行

发现 `twelve_life_element` 实际只有月建五行，快照却将其写作十二长生。现新增 `life_stages`，按直接读取的《探原》PDF93–94十干长生、禄、墓及阳顺阴逆计算十二阶段；戊己随丙丁，不静默混用作者所引《大全》五行墓口径。四课上神、三传本支及所坐地盘均回到实际日干定位，另列墓乘长生、长生乘墓结构。月建五行使用 `month_building_element`；`life_stages` 单独承担十二长生事实，旧重复别名已移除，快照和核心摘要使用对应事实。六壬规则集1.3.0，金口诀本课规则不变。

10组原文定位的30项字面检查、120项规则展开及复用定位的20个上下加临例分别符合，不当作170个独立样本。完整三项目标仍未验收。

### 旺衰依据的书影差异与综合用位合同

直接核对并冻结卷上15页，含贵神休旺所主全部十二例。天乙例书影PDF130图式末位为木，网上转录为水，书影仍称土旺且解释中提到水；差异未裁定，不推定某方错字或改预期。现算法代入原始书影为11/12符合，天乙例保留火、木两候选未定；原网上转录12/12单列，不将两个文本的同十二例重复计为新样本。另订正无克从旺条文为PDF18（页脚17），旧冻结语料不改写。

`comprehensive_position`只允许null；`internal_strength.source_evidence`与`use_evidence.source_evidence`区分转录、归纳推导、书影疑文和条文位置。日下完整五态、无克从旺与阴阳取用的统一优先级尚未裁定，不能由合同允许一个数值就当作原典已证明。

### 六十四课的命中、未命中与未决

### 解释忠实与现实预测

结构化事实引用可使用已有 `fatebridge.validation.claims.verify_calculation_claims`，绑定结构化引用的 `run_id`；提供另行可信保存的完整 `trusted_payload` 时，逐值核对完整结果。当前测试核验金口诀贵神名称，拒绝错引为旧值、跨结果或篡改完整结果；自由文本是否忠实仍需独立人工或盲评，不能由结构化校验代替。

1. 固定一个可客观裁定、有限时间窗内的单一事件目标，写清未发生和无法裁定的条件。
2. 在收集结局前冻结完整样本队列、规则/代码/解释策略、概率校准方法、对照基线和分析计划。不能从传统旺衰或动爻直接编造成功概率。
3. 分开开发、校准和锁定测试集；若同时研究六壬和金口诀，预注册比较方式和多重检验处理。
4. 由不了解预测的人裁定结局，记录可信外部时间戳和原始证据。拒答、缺失、不利结局仍计入覆盖率，不事后筛选“有缘”的样本。
5. 报告覆盖率、Brier 分数、相对基线的改进、置信区间及适用范围；用新独立样本复现。比例区间参照 [NIST Wilson 方法](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。
