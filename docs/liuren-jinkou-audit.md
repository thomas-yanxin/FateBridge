# 六壬与金口诀：规则、输入与验证范围

[文档中心](README.md) · [API 参考](api-reference.md) · [算法状态](algorithm-status.md)

`liureng_gods` 与 `jinkou` 提供有限的盘式规则、同课条件及来源轨迹。先核对时刻、地分、昼夜贵人和所选规则，再阅读三传、四位及条件事实；完整字段见[API 参考](api-reference.md)，咨询取证见[占式参考](interpretation/zhanbu/ren-evidence.md)。

当前支持的课内关系包括六壬三传、旬空、十二运、干支相加与三合名义局体，以及金口诀四位、遁干、阴阳用位、得气、破支和课钤条件。支未齐、原文未裁或条件缺失时保留未知；支齐不证明实际合化，用位不等于完整综合用神。

## 输入与来源

### 输入与字段索引

三个工具使用 `analysis_second` 保留已给秒数；`analysis_utc_offset` 配合 IANA 时区消歧。完整输入以实际 Schema 为准。摘要复制工具 `evidence_views` 中对应任务的 `fields`，设 `strict_fields=true`，不把视图名作为参数。

### 显式约定与未解决事项

- `is_diurnal=true/false` 可在 REST、MCP、CLI 明确选昼贵/夜贵。省略时卯至申为昼、酉至寅为夜。未自动计算当地星出星没；原文特别指出昼夜长短随季节变化。
- 金口诀 `di_fen` 应来自已确认的方位或起课方法；省略保留软件按时支的回退，并返回 `di_fen_source=hour_branch_fallback_not_observed_direction`，不把它当现场观测。
- 月将用实际民用瞬间判断中气；真太阳时校正用于日时柱，不把太阳钟的偏移再次应用到天文事件。已核对 2026 年 12 次交中气及不同时区的边界，未认证全部历史历法。
- 季节旺衰采用辰戌丑未整月土旺的工程口径，未认证季末十八日土旺等异法。课内已实现十二例共有的唯一不受克规则；多候选、日下旺衰、无克从旺取用及全部格局的综合裁决未覆盖，不能把阴阳用爻规则当作完整断课法。
- 金口诀转录本“甲子日亥时巳位”例称勾陈；按同本夜贵未逆行应得朱雀。保留冲突，等待刻本校勘。
- 辛酉课例称四位纯阳，但同本天乙己丑属阴。程序保留贵神固有属性，不为匹配此句改表。
- 神煞、旺衰、动爻提供传统结构依据，不把医学、灾祸、生死断言转成产品预测输出。

以上疑文登记在参考集的 `unresolved` 中，审计会明确列出。没有因疑文而修改预期标签、删除失败来源或把不支持算成通过。

### 四柱、民用钟与实际星历

完整结果把日干、日支、月建、月将、四位、旬空、季节旺衰及阴阳取用接回同次四柱，六壬天地盘、天将、三传旬遁与十二运保留相同锚点。公开字段投影核验实际可读依据，不能把另一占日的完整课盘接在本次四柱下。

`analysis_utc_offset`与命名时区共同选择重复民用钟；错误偏移及跳钟缺失时刻拒绝。日时钟面与年／月UTC瞬间分别参与缓存，星历目录、文件、库实例及实际返回标志均属于计算环境。例如哈瓦那2021-11-07两次00:30分处立冬两侧，应分别使用戊戌、己亥月；两次月将均为卯。Metlakatla的分钟边缘参考仍有发布时间不确定性，不能把时区表示核对当新增天文观测。

### 交气时间尺度与边界序列化

已加载历史UTC漂移系数更新时，交气UTC及所消费的月将边界同步更新，不能让新来源回执配旧缓存数值。1960／1969的合成加2秒控制验证同次边界传播；默认资料结果保持。该控制不是两条新增天文观测，历史标签和反解错误继续按各自适用层保留，见[分项验收](precision-acceptance.md)。

民用钟折叠审计分别报告时刻／符号数值、当前时区文件回执和原冻结TZIF身份。当前54项时刻与实际来源回执相符；原冻结身份门槛仍为30／54，哈瓦那、Campo Grande和Cuiabá的24条身份差异及原失败记录保留，不能据当前数值相符宣称旧文件相同。原五个天文分钟、七个投影及F04分钟边缘不确定性保持。

TT后续诊断现在从[可重现独立参考包](../tests/data/solar_tt_de440_v1/README.md)读取1899—2101年的完整4872根；这些值与原Bazi参考逐点一致。原1秒比较线和刊载分钟失败保留，旧原始路径及迁移后侧件的身份另列，缺失provenance不被声明已恢复。新参考含生成源码全文、原始内核及软件身份，当前读取不再依赖已移除的原生成器或失效侧件路径；原秒边缘跨清单缺口仍未解决。

太阳视黄经交点在TT求解，再经共享时间尺度层转换民用标签：1960年前保留UT1／ΔT历史约定，1960年采用[SOFA历史UTC偏移与日漂移](https://www.iausofa.org/2023-10-11c)，1961—1971年采用IERS历史UTC漂移，1972年后采用已声明闰秒表。未来闰秒在表到期后保持末值属于假设，实际依赖公开转换方法、到期日及是否触发。小数秒避免先舍入后判断边界，其位数不代表微秒物理精度。

原紫金山天文台126年3,024个公布分钟标签按原30秒线比较：原生Swiss有3,003项符合、21项未通过，最大差30.905079秒；有文件解析和无文件默认配置各22项超差。原4,536组中气边界对符合，同一队列DE440 TT对照在原1秒线内。早期整秒舍入得到的3,019／3,024不作为当前成绩。既有JPL原始响应12个太阳坐标中10项符合原0.1角秒线，1900与2099两项未通过；它们不是12个独立交气时刻。

IMCCE OPALE保留三条来源时间路线：初始504项原生／解析各1项历史UT1超差；文档时间约定244项分别4／3项超差；按来源自身钟差转换TT的288项均在原1秒线内。它们复用原PMO事件，不能相加为新增独立观测，也不能抵销分钟标签失败。

### 完整年表队列与历法依据

香港天文台1901—2100年200份年表覆盖73,049个日期，日柱、所测时柱及年／月柱和月将日期约束比较均未发现差异。原72,723个库内农历标签一致，另326日由同一HKO来源的月首资料接入核对；同源接入不计作独立天文证据。交节当日的前后两种可能作为未定探针单列，不把年表日期当精确交气时刻。全部4,800个节气日期在四种配置下均保留7项近午夜差异，不改交界求一致。

月将与节气按民用瞬间，真太阳钟只用于日时柱；`calendar_policy`声明实际输入、钟面、23:00子初换日与归属日期。天文求解失败返回依赖错误，不以线性回退起课；跨夏令时的间隔按实际瞬间计算。来源日期正确、提供者可用与物理精度合格分别核验，完整历法域仍未认证。

### 独立边界来源与完整秒级队列

当前秒级及分钟条件传播使用[自包含边界资料](../tests/data/ren_boundary_sources_v1/README.md)，和完整独立DE440节气TT资料共用。新参考保留生成源码、独立钟及规则助手、原始来源文本和所有输入，不再要求已搬迁的旧路径或缺失过程报告才能读取数值。原guard清单、旧Ren协议及分钟协议的三个既定身份差异作为生成时观察保留；新复现没有恢复或改写这些旧承诺。

1800—2200年全部19248个整秒／下一秒输入已独立重建；民用标签、输入TT与十类规则期望均与旧资料相同。1872年夏至两个探针的参考TT相差80.467微秒，原记录不变。按完整新参考区间核对，1952年立秋整秒输入位于区间下端；新资料保留不确定标记，不沿用旧数据“全部区间外”的说法。1899—2101年9744个原分钟标签与共享钟输入保持，全部条件状态按独立TT根重新分类核对；这不是独立UTC认证。

在实际自动DE440、空外部星历目录配置下，对全部19248个输入逐个调用领域服务。当前／下一节气、年／月／日／时柱、月将、金口诀四位、四季旺衰及阴阳用位十类结果全部相符；输入钟最大差40.233微秒，符合原200微秒线，无计算错误或模型来源差异。重叠事件不增加独立天文观测数。1960年前仍共享Swiss历史UT1／ΔT模型，未来闰秒末值延续仍属假设；原22个PMO分钟失败、原典分歧、其他模型臂及现实预测另行验收。

同时完整核读六壬历法边界与太阳钟模块11个函数／方法和错误类声明，区分来源资格、民用标签、缓存及交付说明。公开回执列实际文件、模型、覆盖与参考系；文件身份在内部检查，不要求业务输出散列。旧一次性秒探针生成入口已由具备明确输入／输出、拒绝覆盖的当前生成器替代，独立规则助手继续复用。


四种太阳配置另按12个原整秒标签、两个工具、源码和新安装环境实际运行，完成576次成功REST／CLI／新stdioMCP调用，三端投影及快照一致，源码／安装载荷逐字节相同。Native控制有4处严格判定与DE440参考不同，1936年雨水下一秒在参考区间外、1952年立秋整秒在区间内；最大TT差约0.093663秒，未因符合1秒数值线而改判通过。只给两份原生档案时的1800年跨档粗搜索原有6次实际错误；原输出保留，后续共享求根器已修复，见[已知原生缺口](solar-backends.md#原生跨档粗搜索的已知缺口与修复)。

## 盘面规则与同课条件

### 盘面结构与计算规则

| 问题 | 当前行为 |
| --- | --- |
| 金口诀把占时当地分对应的贵神，借用大六壬天盘神将 | 在日干昼夜贵人起位上，按本法顺逆直接数到地分 |
| 贵神的五行来自占时支 | 使用十二贵神固有干支：例如玄武壬子、太阴辛酉、天乙己丑；与落地盘位置分开 |
| 用神按大六壬课体和“最旺位”决定 | 按四位阴阳取用：三阴取独阳、三阳取独阴、两阴两阳及纯阴取将、纯阳取神 |
| 四大空亡写成地分五行 | 按日旬：甲子/甲午水空，甲寅/甲申金空，甲辰/甲戌无；另保留旬空 |
| 地分五行当季节，“囚、死”还被颠倒 | 按明确月建约定算季节旺衰；我克者死、克我者囚；不混成概率 |
| “纳音引气”等没有计算的泛词充当神煞 | 返回实际旬空、四大空亡、月破，以及有位置和生克依据的五动三动 |
| 六壬 `ganzhi` 实际拼了两个地支 | 按日旬遁配干；旬空支 `dun_stem` / `ganzhi` 为 null，另列本空、坐空和落地盘位置 |
| 贵人逆行被说成天盘逆布；六害被说成涉害法 | 天盘仍顺布，贵人另列 `guiren_order`；关系与取传法分别说明 |
| `with_day_branch` 实际比较日干寄宫 | 现在比较真实日支；寄宫仍单列 `anchor_branch`，不冒充日支关系 |
| 男起癸酉、女起己卯，且按公历年差算行年 | 男丙寅顺、女壬申逆，按民用日期的农历年差加一；正月初一换岁；性别未给不套男式 |
| 未知节气或非法地分可回退成貌似正常的盘 | 未知节气拒绝用月建代替月将；非法地分经 Schema 和领域层拒绝 |

大六壬九宗门三传的既有 720 局期望值保持不变。全组合回归继续遍历 60 日 × 12 天地盘偏移 × 12 绝对时支，共 8,640 组；校验范围是三传，不含全部课体解释。

金口诀增加 `motions`、`ruleset`、`rule_trace`；六壬增加 `ruleset`、候选/比用/涉害深度轨迹。四位条目注明阴阳、遁干、旬空、四大空亡、月破、是否用位。`intrinsic_ganzhi` 是贵神固有属性，`dun_stem` 是当日日干的五子遁，两者不等同；六壬三传则使用日旬遁。

### 遁干与原书标签缺项
