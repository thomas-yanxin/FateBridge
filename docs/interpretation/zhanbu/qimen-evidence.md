# 奇门盘面证据

只对本次已读结果解释，沿用同一次 run。默认规则是时家转盘、中五寄坤二；`ju_method=zhirun` 是置闰，`chaibu` 是另列的拆补约定。`calendar_policy.astronomical_term` 是实际民用时刻的节气，`ju_term` 是定局用气，置闰时两者可以不同。规则与来源见 `rulesets`，解释链在 `rule_trace`；不能把在线转录的部分规则验收称为整部原典认证。

- `xun_head/kongwang` 为时旬；`day_xun_head/day_kongwang` 为日旬。不能混用空亡范围，也不能把双支宫中一支空亡说成全宫空。
- 真太阳时读取整条 `calendar_policy.solar_time_adjustment`：经度差＋均时差－夏令时＝总修正；`civil_input_instant_utc` 是原实际时刻，`apparent_solar_label` 只是日时取用标签，不据标签再次移动交节时刻。均时差方法按种子计算时保留的记录读取；`UTC_as_UT1` 未使用实测DUT1，不能称亚秒认证。距最近时辰／23点换日的秒数是标签几何距离，不是测量精度、误差界或确定性。独立JPL核对有近边界一例在5秒容差下不能认证日时归属，不能因名义结果相同就称已精确验证。`not_applied` 不补写均时差；`missing_seed_adjustment_provenance` 不能从总修正量推断算法。整条结构化引用可用 `verify_qimen_solar_time_quotes` 核对，但不证明自由文本解释忠实或现实预测成立。
- `zhifu.star` 保留天禽的身份。某宫 `star=天芮` 且 `hosted_stars=[天禽]`，可以承载天禽值符；不是字段矛盾。`heaven_stems`、`earth_stems` 同时保留主干和寄干，不能只读单数干而丢掉寄宫格局。
- 中宫的独立门、神、转动星与天盘干为 `null`。天禽与中干在天芮所在宫读取，不补造“中门”或第二个值符神。
- 门宫关系读取 `rule_profiles.door_palace_relation` 与宫级同名证据，命中门迫时还读整条 `qualification.door_palace_evidence`。`door_pressure/verse_door_pressure` 固定按歌诀门克宫；正文另外将门克宫称吉迫、宫克门称凶迫、门生宫称和、宫生门称义。歌诀门迫为否不等于正文没有凶迫；吉迫不是吉利、和义不是现实结果或人的品德评价。同五行在本段未另命名，不补成该段原文“比和”。`printed_example` 只在所列11个门宫组合上保留原文分类；景门临兑被本段列“吉门被迫”仍附“不吉”，不推广为景门恒吉，更不转成成功概率。
- 宫内 `evidence` 直接给出门迫、宫克门、时旬空支及九星旺衰。首轮一起读 `rule_profiles`，以实际 `season_profile` 为准：默认 `yanyi_vol1_verse` 采用卷一赋，同五行为相、星生月为旺；卷三表 `yanyi_vol3_table` 将这两项对调；卷三正文 `yanyi_vol3_prose` 还将月生星列休、星克月列死。三种都保留各自章节，不能混成一套口诀，也不按结果挑吉利口径。旺衰用实际月支的五行，不用定局借用之气代替月令。
- `god_profile=yanyi_text` 默认按卷三正文用白虎、玄武；`yanyi_diagrams` 按已核卷四圆图用勾陈、朱雀。`god_sequence_index` 只是从移动值符星宫起阳顺阴逆的序位，不证明名称同义，也不能套用六壬十二天将。`evidence.god_interpretation` 保留所读神义及附加条件；勾陈、朱雀目前只据图排名称，未移植白虎、玄武正文解释。螣蛇、白虎、玄武的“得奇门会合则不忌”条件尚未自动判定，不能只凭神名直断吉凶。
- 三奇得使、天遁等组合须一起读取 `qualification`，明确条件已观察到或未满足、同宫冲突及 `source_disagreements`。乙辛得使不能覆盖青龙逃走；天遁结构不能掩盖门迫；玉女守门按值使到地盘丁判断。原典例局与规则不一致时，同时交代原文与实际盘面，不改盘迎合原文。
- 三奇入墓另核 `rule_profiles.wonder_tomb` 及宫内 `evidence.wonder_tomb`。正式匹配固定按卷二王璋明确列举乙坤、丙乾、丁艮，主干和寄干均参与。同段首句可字面读作乙丙丁临乾六戌宫，但该释读与优先关系未解决；`unadopted_literal_candidate_matched_stems` 只是候选，`candidate_adopted=false`。候选在乾宫命中乙或丁，不自动补成正式入墓；本宫两种读法恰同也不证明全书已统一。整条入墓格的 `qualification.tomb_evidence` 保留上述限定，组合格另给证据路径；不能按哪种更吉、更符合想要的结论而换法。它与字面时干支入墓是不同层。
- 飞鸟跌穴、青龙返首、天乙伏宫格、天乙飞宫格须读取 `qualification.identity_binding`。这里的甲／直符按本时旬首所遁六仪及原宫、移动宫取用，不统一换成戊，也不借日旬代替。寄干在复数数组中同样参与。飞鸟跌穴可与荧入太白同时匹配；须一并解释同宫冲突，不能以格名直接判吉。当前独立原例是所列甲子旬算例，其他五旬是按已声明规则推算，不能把1080盘内部遍历称为1080个原典例局。大格、小格按庚癸、庚壬干对读取，小格的别称伏格不等于伏吟或伏宫。
- 六仪击刑读取 `rule_profiles.six_instrument_punishment`、宫级同名证据及整条 `qualification.punishment_evidence/punishment_instrument_identity`。当前暂定保留广义六仪落所刑宫的原有匹配：甲子戊卯震、甲戌己未坤、甲申庚寅艮、甲午辛午离、甲辰壬辰巽、甲寅癸巳巽，主干和寄干均核。每个仪自身所属六甲与本时旬首分别列出；不要把甲辰仪壬误说成本时甲子仪戊。原文“六甲直符”未明写仅本旬，另列的 `current_zhifu_matched` 是尚未采纳的本时直符窄读候选；同段阳一局甲己日卯时原例能区分两法。`source_scope_adjudicated=false`，不能称广义已认证，也不能据窄读候选删除广义匹配。不得按哪个更吉或更符合结果选取法；不能与庚加己的刑格混名，更不能断现实灾祸。
- 首轮一起读取盘级 `source_disagreements`。卷四十八局1080时数表目前有2处直使宫数差异，卷二另有1处门名、1处阳五壬申天盘庚宫位差异；六仪击刑另有未裁定的范围解释，区别例及两种计算在规则口径和宫级证据中保留；命中对应时局时，摘要和快照均保留原文、计算值及来源。另一古籍引文支持坤二，不消除所选《演义》离九文字，也不解决日甲取法。卷四原始5宫是寄宫前数值，不能把它与显示的坤二直接判为矛盾。1078行观察符合不等于全盘各层、整部原典或现实预测已经通过。
- 首轮一起读取 `stem_context`。非甲日干按字面直取，庚加日干为伏干／日格、日干加庚为飞干；别称不算两份证据。日甲的 `status=unresolved_jia_identity` 只列日甲本身藏仪与时旬藏仪两套候选计算，`adopted_candidate=null`，即使某个候选符合一例也不采纳，不能把未正式输出日格说成没有相关结构。时格独立核时干；其原文别称伏吟格不等于整盘星伏吟或门伏吟，仍以 `structure` 对应字段为准。
- 三诈读取 `rule_profiles.three_deceptions`、各宫 `evidence.three_deceptions` 和整条正式格局。2.11.0按现行时家转盘天盘乙丙丁（含寄奇）、开休生门、对应太阴／九地／六合完整同宫命名真诈／重诈／休诈；不是任意得二就补出正式名称。`verse_exactly_two_components_present` 仅是歌诀太阴三要素的盘面观察，不能扩到任意神；歌诀得二亦吉与正文门合太阴无奇不利的解释优先未决。`prose_partial_case` 保留缺项类别，不据缺项自动判吉凶；十分、七分不作概率。丁休太阴同时见人遁与真诈时，`overlapping_evidence_group` 表示共享事实，不算独立印证，也不把所有真诈等同人遁。保留 `coexisting_rule_names` 及门迫、入墓等已有证据，完整三诈名称不覆盖限制；没有综合认证为全盘吉。诈是古籍格名，不据此认定他人欺骗、关系事实、现实收益或医疗效果；五假未由这个规则判断。
- `structure` 分开给出星伏吟／反吟与门伏吟／反吟，另列五不遇。`patterns` 是命中的条件，不是现实吉凶结论；逐项核对 `facts` 与宫位。未匹配、未实现、未读到是三种不同情况。
- 五假读取 `rule_profiles.five_jia`、宫级 `evidence.five_jia` 和整条正式格局。2.12.0明确采用天盘干（含寄干）、实际门与所选八神：天假是景门合乙丙丁临九天，地／神／鬼假分别是杜／伤／死门合丁己癸临九地。丁己癸不是三奇，不用本时干或地盘干替代。杜门合丁己癸临六合／太阴是原文另列的未命名旁例，不能套地假名称。人假原句写惊门合六合下临九天；同一八神层不能放两个神，但这不证明人假不存在。另段己为六合只支持未采纳候选，保留 `human_jia.adopted_match=null`，不能改字作六壬、自动把六合当己，或因候选未中就断定没有人假。四类完整名称不覆盖同宫门迫、入墓等证据；古代进谒、隐伏与祭祀丧葬语境不成为现实成败、神鬼、临床或丧葬择时判断。
- 时干支入墓读取 `structure.hour_branch_tomb` 与整条 `stem_context.hour_branch_tomb`。当前只核卷二正文六组字面时柱：丙戌、壬辰、丁丑、癸未、戊戌、己丑。己丑是正文补列，不因歌诀只列五组而删去。跟随实际采用的时柱；真太阳时跨时辰后可能与输入钟表时不同。这里不能借甲的藏仪替代字面时干，甲辰藏壬不等于壬辰；也没有判断天盘时干落墓宫。它是时间条件，没有伪造落宫或塞进宫位格局。未命中本表只能说未命中所选六组，不等于所有入墓法都不存在。原文禁忌不构成现实失败、伤害或医疗后果判断。
- 岁格与月朔格分别读取 `stem_context.year/lunar_month_start`。岁干只在立春年与农历年候选一致且非甲时直取；两种年界不同会保留候选，不输出正式岁格，不能解释为不存在。月朔干取本农历月初一的日干，不取八字月柱天干；核 `anchor_date/calendar_year/lunar_month/is_leap_month`，闰月取自己的初一。该月历按输入时区的民用日期读取现代离线历表，不因23点子初换日或真太阳时跨日提前换月，也不是计算真实合朔时刻。岁干、月朔干为甲时仍只列藏仪候选，不自动采纳。超出农历支持范围不猜锚点。岁格／月朔格与其他格局可能共用同一庚加干事实，`shared_evidence_group` 相同不算多份独立证据；不据格名判断家人、损失或现实成败。
- `door_hexagram/fushi_hexagram` 是软件派生卦，未认证为该原典规则；不能借它提高结论置信度。
- `fly/fei/mirror/reverse` 与非零 `palaceShift` 不支持，必须按错误纠正，不能改个名字继续输出所谓飞盘。

交付先说相关宫实际组合及其传统提示，再给用户可核实的条件。`assessment.real_world_efficacy=not_tested` 时，不写现实成功概率、保证成败或最优分钟。风险词不能直接变成灾祸、诊断、治疗或人生断言。真实模型解释是否忠实还需单独的行为验收，结构化证据和快照一致不等于任意模型都会正确解释。
