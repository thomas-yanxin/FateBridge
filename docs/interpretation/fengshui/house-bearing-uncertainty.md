# 同一宅向的误差与八宅候选

同一住宅的宅向测量误差同时影响八宅坐卦及玄空山向，不能在玄空保留候选、在八宅却当成精确朝向。使用共享 `house.bearing_uncertainty_degrees`，表示调用方独立提供的有界误差半径；只有实际提供 `facing_degrees` 时才有意义。八宅支持0–180°，玄空仍支持0–7.5°。

宅向误差只在该住宅的 `house` 事实中声明，显式0与未提供分别保留。只在 `xuankong.house` 提供宅向而显式请求八宅时，复用该同一住宅事实，不能报成没有宅向。

省略误差沿用已有点方位计算约定，不证明现场误差为零。WMM的一倍标准差不是现场总误差上界，不能擅自填入此字段。该输入也不补出户型立极、家具位置或真北到磁北的现场确认。

## 离散支持与确认

八宅在正误差半径下枚举整个闭区间经过的所有八宫，包含实际触及的两侧边界，跨北向也完整保留。计算以传入浮点值的精确有理数运算，不另加epsilon扩宽区间。半径0保留既有八宫左闭右开点约定；玄空二十四山的原有分界候选政策独立保留。

`house_bearing_closed_interval_v1@1.0.0` 作者为FateBridge，是工程区间传播政策；S4只提供八卦方向映射，不表示古书规定了浮点端点或测量误差统计。`house_orientation_context.nominal_sitting_bearing` 只是名义角对应的参考，不代表每个候选的确定坐卦。

`layers.bazhai.house_candidates` 分别返回 `candidate_id`、坐卦、完整八方星表和各自的 `bearing_support.regions`。有多个支持坐卦时 `house=null`，候选及对应判断为 `candidate_only=true`；区间内只有一个坐卦，或调用方另已确认坐卦且与区间相容时，可返回唯一 `house`。这只是离散坐卦已确定，不认证原始角度或现场误差。确认的坐卦可位于区间的另一侧；与整个区间都不相容则拒绝。

每条宅盘用途判断与布局作用域带有 `house_candidate_id`、`house_sitting_trigram`，不能和同宅另一候选或住户命卦混合。例如名义宅向22.2°、半径1°，支持离／坤两种坐卦；南宫在离宅为伏位、在坤宅为六煞，床位基本星性匹配分别为true／false，均保留为条件解释。

## 方案与交付

不确定宅卦的作用域不进入“已确认作用域共同匹配方位”交集，独立已确认的住户命卦仍可说明。交集只代表那些已确认作用域，不能将它写成所有宅卦候选都同意。候选方案保持相同宅向区间，在新位置分别读取每个候选的星表，并保留候选身份；搬动许可和空间可行性不能把未确定宅卦变成ready。

首轮按实际请求保留 `rulesets/rule_trace`，并读取 `layers.bazhai.house_orientation_context`、`layers.bazhai.house_candidates`、`layers.bazhai.placement_findings` 及实际需要的布局分支。仅在本次存在区间分支时请求这些可缺路径。可解释候选依据与分歧，不等待全部行动条件齐备后才交付普通解释。
