# 西占在生活主题中的证据读取

先按[本轮范围](consultation-routing.md)确定所问主题、单人／双人与时间任务；计算交给引擎，解读保留具体流派及来源。不把通用宫位象意当成新增专项评分器，也不照搬固定相位优先级或按性别指定伴侣模型。

## 按主题查相关依据

| 用户主题 | 可核对的本命依据 | 如何保持问题范围 |
| --- | --- | --- |
| 自我特点 | 日月上升、相关星体／相位、实际古典条件 | 选能解释当前问题的区别，不单用某一星体定义整个人 |
| 事业工作 | 与职业问题相关的第6／10宫、MC、星体与相位 | 日常工作、职业方向与实际岗位条件分开 |
| 财务资源 | 第2／8宫及相关配置 | 个人收入、共同资源、消费分别讨论；不预测收益或荐标的 |
| 伴侣关系 | 第5／7宫、日月金星等实际相关配置；双人用真实跨盘相位 | 单人描述不当成未来伴侣已知事实，不读他人心意 |
| 学习成长 | 第3／9宫、水星等实际相关配置 | 学习方式、深造与考试阶段分开，不承诺录取 |
| 家庭亲子 | 第4／5宫、月亮及问题相关配置 | 命主视角、孩子本人与双人互动分别取证；不推生育结局 |
| 人际合作 | 第7／11宫及具体关系相关配置；双人跨盘依据 | 朋友、团队、合伙按真实关系选择，不强套恋爱模型 |

这是需核对传统来源的读取索引，不是各宫／行星与现实结果一一对应的判定规则。用 `knowledge_registry`、`knowledge_read` 或已核对的可靠作者来源查证实际解释；不确定就说明范围，不能让来源查表替代个案计算。

## 字段与解释来源

本命工具读 `houses`、`planets`、`aspects`、`angles` 和实际 `classical`。宫头星座守护星与 `classical.topic_almutens` 的宫头力主不是同一概念；采用哪种规则须明确，不用一个字段冒充另一个。没有经过验证的宫主星结构或叠宫输入就不声称已完成整条链。

福点／精神点、朔望、命主力主、恒星、行星时及关系中点／映点等明确细问，读[深层证据按需卡](western-deep-evidence.md)。它提供新增信息、真实字段与范围，不把所有高级字段塞进普通首轮。

## 事业方向与转职时间的取证

首次确定任务后，`western_timing_analysis` 事业补证可选 `career` 卡，与所需 `stage/annual/short_term` 卡的字段合并去重；卡名不是请求参数。必须先保留 `analysis_context`、法达主／分运及真实起止、年小限、已有返照字段和行运实际 `hits`，再挑相关命中。目标时刻或太阳位置只是定位信息，不能单独支持职业变化判断；未读命中不等于没有命中。

阶段主星、年度主星、短期相位分别回答不同时间问题。要把命中解释成工作议题，须连接已实际读取的本命职业配置和可靠解释来源，不因最紧相位就自动列为事业主证。当前返照是有限点位，不能补出返照第十宫或完整相位链。没有新增职业依据时，保留原有有据视角即可，不凑第二体系。
