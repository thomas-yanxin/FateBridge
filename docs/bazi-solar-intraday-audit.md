# JPL 日内均时差参考扩展

此前的73,414个逐日正午点只能覆盖一种日内时刻。原v1日内协议因网络失败留下零新增比较；该记录保留，没有改写为成功。网络恢复后，v2先冻结当前候选、源码环境和原五秒门槛，再采集连续23小时间隔的官方参考，完整冻结后才作比较。

## 采集与转换

网格从1900-01-01 00UT起，到2101-01-01之前止，共76,606点，覆盖73,414个日期及全部24个UTC钟面小时。每个日期并非都有24点。3,192个正午点与旧集重叠，不能相加当作独立重复。

使用[JPL Horizons官方API](https://ssd-api.jpl.nasa.gov/doc/horizons.html)，取太阳、格林尼治赤道、无折射站心观测，第34项视太阳钟面和第49项DUT1。九个分块的23小时相位连续，完整JSON回复、表头、参数及散列均保存。当前回复使用DE441，未冒称DE440。

每行按实际打印钟面求视太阳时与平均时的差，作午夜回绕后再减可取得的DUT1。另一个测试用Decimal秒数算术独立重算全部76,606行，核对午夜回绕、差值符号、缺测及原始数据对应，避免由同一浮点转换式同时制造参考和答案。

## 固定候选结果

| 目录配置 | 比较点 | 原5秒门槛内 | 未达门槛 | 最大绝对差 |
| --- | ---: | ---: | ---: | ---: |
| 冻结的35个Swiss数据文件 | 76,606 | 76,606 | 0 | 0.840531秒 |
| 空星历目录 | 76,606 | 76,606 | 0 | 0.839660秒 |

最大差均在2100-12-16 18UT。候选使用当前冻结的`swiss_time_equ_utc_instant_v1`；其他源码和包装层已经不同于早期v1，因此另立协议，没有冒称原候选文件从未变更。两种配置是同一参考的两个环境对照，不能算两批独立天文样本。

`time_equ`不返回实际模型标志；1900、2000、2100三个日期的`calc_ut`预检在完整目录返回Swiss标志、空目录返回Moshier标志。预检不能证明每次均时差调用实际使用的模型，报告因此只称“目录配置”。

## 口径及未完成部分

[Horizons手册](https://ssd.jpl.nasa.gov/horizons/manual.html#observer-table)明确第34项只提供站心视太阳时；候选均时差采用地心口径，观察者效应并未因此消失。这里比较的是预先声明的有限参考口径，不能把最大差直接宣称为全世界任意出生地点的绝对误差界。

23,649点没有DUT1，保留null。其余数值也并非全是实测：本批EOP表头报告数据覆盖至2026-10-21、预测至2027-01-15；手册说明预测区间之后沿用最后一个预测值为常量。2100年的该值不证明未来地球自转已知。1962年以前UT标签与候选将UTC近似UT1的用法也须分别说明。

这是已暴露连通性试探后的扩展核对，不是新盲测。协议、候选及参考冻结时间分别保留；采集器散列在采集完成后记录，不冒称采集前已留密码学证明。旧正午资料、失败的v1及本次日内资料分别计数，不改变[全部节气TT比较](bazi-all-terms-audit.md)中Moshier的501个失败。
