# 八字时标的重复舍入与边界语义

本轮修正底层 `datetime_from_tt` 在普通现代时刻逆算UTC时的重复舍入。给定同一个TT数值和冻结闰秒政策，先在约二百四十万天的大儒略日上减偏移，会再次丢失微秒分量。当前实现用精确有理数保留输入，最后一次舍入到Python日期时间的微秒分量；原典强弱公式、轨道系数及节令求根未改变。

[美国海军天文台的说明](https://aa.usno.navy.mil/data/JulianDate)指出单个双精度儒略日的时间分辨能力有限。[ERFA的TT到TAI实现](https://github.com/liberfa/erfa/blob/master/src/tttai.c)使用双分量日期保护精度；其[日期编码说明](https://github.com/liberfa/erfa/blob/master/src/dtf2d.c)还单独处理UTC闰秒。这里的修正是冻结政策下的算术改进，不涉及未来闰秒预测或机构背书。

## 两种输入约定必须保留

已有接口允许用舍入后的单数JD编码已知UTC边界。例如，名义午夜的编码值可能比精确的数学边界早几微秒。该浮点数同时也可以被使用者明确指定为一个精确点；两种约定得到的UTC标签可能不同。

默认模式保留原来已发布的名义边界约定，识别全部冻结原子偏移起点及正闰秒起点，不使用个案编号或扩大时间容差。底层Python接口的 `exact_epoch=True` 明确选择精确点解释；它不是REST、MCP或CLI排盘请求参数。历史转换分支及其原有精度约定继续保留。

首候选将全部单数JD改作精确点，虽然通过新的数值参照，却新增28项闰秒边界退化；共享检查共32项失败。该版本已经回滚，代码、首次失败及输入原样保存。父版本复测确认另外4项共享失败已经存在；修订版仍保留这4项，没有据此宣布全仓通过。

## 独立参照与实际结果

冻结协议（本地数据：`../tests/fixtures/bazi_tt_utc_exact_v1/protocol.json`）先于生产修改。采集器不导入FateBridge，用80位十进制精度、确切TT−TAI常量和冻结原子偏移表计算答案。它保留全部4,872个既有节令TT、1,024个既有通用TT，以及全部28个原子偏移起点、27个闰秒起点两侧的IEEE相邻值，共6,391条；其中2,218条早期历史输入明确未裁定。

41条差异没有被删例、改成未知或记为通过；显式模式通过不能转给默认模式。本地回执（本地数据：`validation/bazi-atomic-utc-local-v1.json`）保留两个模式的独立结果、首候选失败、父版本复测、三端与安装包证据。首次stdio检查因固定256页上限提前停止，随后改为按声明长度、递增游标、唯一URI和散列核对完整同次结果，计算输入与结果未裁剪。

以上端到端数量只对应散列固定的源码及由其构建的安装包。收尾时共享工作区的同一文件另有两处钟时观察标签变化，已保留；`datetime_from_tt`函数的语法树仍与受测版相同，但没有将冻结版本的整套验收转计给变化后的共享工作区。

完整DE440与Skyfield 1.53的4872历元分解还分别测量了TDB、坐标框架、偏折与光行差的模型差别，结果在只读分解回执（本地数据：`validation/bazi-solar-root-decomposition-first-v1.json.gz`）。这些变体没有作为新参考根或生产偏移采用。

## 尚未关闭

蒙罗维亚231条复测保留原14条包络失败；1,617个起运结果、实际根和公历偏移与修复前逐项相同。

116,906条跨时区队列已在冻结新源码上完成，原门槛验收仍失败（本地数据：`validation/bazi-dayun-future-clocks-exact-atomic-acceptance-v1.json`）：包络失败从2,695条变为40,219条，782条来源未决完整保留。数值检查、已知状态及声明逆像事件的保留检查通过，不能抵消包络失败。

保存结果的独立复算（本地数据：`validation/bazi-dayun-future-clocks-exact-atomic-root-sensitivity-v1.json`）在全部812,868个探针上，用各自实际采用的根及独立整数钟时算法重算交运，逐项相同；580,620个同根安全探针没有包络遗漏。随后修订前后回放（本地数据：`validation/bazi-dayun-future-clocks-atomic-replay-v1.json`）确认全部探针采用的TT根没有变化；665,840个现代探针的UTC转换全部符合独立十进制参照，147,028个早期探针输出保持原样、仍未裁定。现代探针中664,601次重复舍入偏差得到修正；这些重复使用2,357个TT值的探针不是新增独立天文样本。

这两项事后诊断将分歧定位至实际根的UTC标签与冻结参照标签之间，未证明连续区间极值完整或太阳根的物理精度。三天折一年使节令时差在起运日历偏移中乘120；再经过夏令时跳变，微小标签差异也会影响边界探针。不能据此回写旧参照、放宽门槛或把40,219条失败改记为通过。完成回执（本地数据：`validation/bazi-atomic-utc-closure-v1.json`）保留两版数量与全部未决项；源码、安装包、首次失败与修订记录按散列归档，并实际恢复核对全部1,094个冻结文件。

单数JD的量化、完整连续区间覆盖、真实出生记录、未来钟时规则及物理UTC精度继续各自验收。原典仍有26个不同输入分歧，未增加独立原典外审、模型作答验收或现实前瞻样本；总目标未完成，现实预测保持 `not_tested`。
