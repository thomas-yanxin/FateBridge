# 唯一子卯对的单端解刑：条件修复与未解反例

现行方法升为`season_root_revelation_relations_v10`。本轮修复一项会影响默认数值的条件错误：唯一实体子卯对中，一端已经被同次成立的六合、三会或三合覆盖，旧模型仍要求两端全部覆盖才停止扣刑损。现在这一单端条件可解除该子卯事件；另外两组三刑、重见子卯、半合趋势及争议组合不借此扩大解除范围。系数、阈值、藏干和原典强弱标签均未调整。

## 数值变化和独立复算

独立关系参考核对全部20,736种四支排列，只有预声明的300种唯一子卯形态改变刑事件状态。每种再遍历十个日干，共3,000个合成探针；生产数值与首次隔离候选一致，也与此前已冻结的独立有理数预算重建一致。独立参考在观察候选结果前核过全部十二支藏干顺序、十干五行，并与修改前不可变物理表一致；没有重复前轮事后改正参考顺序的过程。

独立浮点复算最大差约`3.55e-15`，沿用`1e-12`算术核对容差；精确分数能量逐项相同，原有强弱和特殊结构阈值不放宽。这里证明既定工程系数下的算术，不证明关系效力、古籍定量参数或现实预测。

全部408条记录中，只有JH-01（己卯、甲戌、甲子、己巳）的默认数值变化：卯戌已合后，子卯刑由活动改为解除，不再给未被合住的子重复扣刑损。身印合计工程份额由`105/589`变为`111/595`，等级仍为弱，原典强弱标签继续为未知。此变化不算修正一个已知强弱答案，也不把身印份额当作日主本体力量或概率。

其余407条记录、366条公开记录除声明的方法、策略和来源元数据外逐值逐类型相同；全部367条原典标签、未知、约束和比较结果不变，三项公开集合约束没有新退化，原有违反约束仍保留。全部408条历史默认算术不变，v9策略另可显式精确回放。详见完整差异与逐例审计（本地数据：`validation/bazi-single-end-resolution-files-v1/audit-first.json`）。

原十九例仍全部保留，其中十七例分歧未解，十九例的身印分量、月令与通关旧事实除版本元数据外完全不变。未给月内司令补干、未按原文相对日数重建出生瞬间，也未把解除一个刑事件等同于有效通关。
