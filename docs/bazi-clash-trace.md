# 六冲实际比较依据

现行普通六冲算法比较两种五行的初始藏干预算总量，含月支预算倍数；季相能量、透干激活、盖头、间接生扶、距离权重和寒暖未参与这个输赢比较。此前结果只给保留乘数，不足以解释为何选择0.9或0.5。

新增`clash_comparison`将决策时的原始两方预算、实际藏干贡献、对应柱位、距离及保留乘数保存到同次回执。它没有改权重、冲损、合解冲、四墓土或全局旺衰。方法仍为v6；追溯方法单列`initial_hidden_budget_clash_trace_v1`，不把可追溯误称为原典已经符合。

## 判断分支与缺项

- 普通六冲的`initial_hidden_budget`包含两方原始输入；不能用相互作用后的藏干余量重算这条依据。
- `combination_resolution`表示当前计算实际采用合解冲，没有进行冲力比较；不补造双方得分。
- `storage_movement`表示实际采用四墓土冲动分支，根系数仍从原四墓回执读取，不能改述为普通两方胜负。
- `legacy_power_unavailable`保留旧事件已有系数，但原比较输入未记录；不从现有结果猜回原因。
- 已计算但无六冲时`events=[]`；未供给这次旺衰时共享字段为`null`，两者不能互换。

《滴天髓》地支论的[旺衰与冲动原则](https://zh.wikisource.org/w/index.php?title=%E6%BB%B4%E5%A4%A9%E9%AB%93/03&oldid=844351)具有条件性，并未给出这些数值系数或上述预算公式。每个实际分支保留其原计算来源；`classical_effective_force=not_adjudicated`始终说明尚未裁定原典有效根力。任注反例及已拒绝的季相、透干冲力候选见[冲力研究](bazi-clash-power-audit.md)。

例如丁丑、壬寅、丙申、壬辰：木的原始预算为寅甲16/7加辰乙4/7，即20/7；金为丑辛2/7加申庚8/7，即10/7。当前代理选择月寅保留0.9、日申保留0.5。这解释当前算法，不能推翻原典所说嫩木受冲拔根；完整邻接、生扶、寒暖与救应仍是[未解决缺口](bazi-body-seal-audit.md)。

## 三端读取与解释

综合、九专题及根工具`analyze_destiny`均有公开`clash_reasoning`视图；读取实际已发布的`fields`，视图名不是请求参数。账本位于各自`evidence_chain.strength_context.clash_comparison`；综合的原账本也保留在`day_master.assessment`。

账本与快照复用同一回执。类型检查拒绝虚构藏干、重复物理贡献、总预算不符、位置距离不符、错置比较双方，以及把未比较分支写成已有冲力。结构化声明核验仍须对应同一run与业务哈希；通过合同不等于文本自由解释已获原典认证。详细结果超出预算时读取同一run的分页，不重算补全文。
