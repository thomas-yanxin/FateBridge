# 金镜144局六列的原生书影核读

V23按《太乙金镜式经》四库本卷三立成表，核读阴阳各72局的太乙宫数、文昌、始击、计神和主客两算。144行、576个位置与288个两算全部纳入；这是六列的语义校读，不是全书、逐字字形或有日期全盘验收。

## 版本、栏位与初录

底本为[CADAL06056494四库本扫描](https://commons.wikimedia.org/wiki/File:CADAL06056494_太乙金鏡式經·卷一~卷四.djvu)，原文件144页、5,391,927字节，SHA-256为`2959ff4b7c9c50f7f0b0e26e680aa19ecb8adb1c97d2178800e101e3979d7c30`。卷三所选表在106—124页，阳1和阴1跨两栏，其余每局一栏；页码是DjVu文件的一基页号，栏从右起数。

初录清单（本地数据：`../tests/fixtures/taiyi_jinjing_v23/manifest.json`）在新来源比较实现前冻结扫描、19张原生PNG、144行TSV（本地数据：`../tests/fixtures/taiyi_jinjing_v23/native-columns.tsv`）、初录回执与同书卷二名位参考。资料由Codex代理读图，读者已知代码和旧发现，没有独立人类专家覆核，也不是盲读。预期没有由生产公式生成。

TSV按语义使用名称索引，德/徳、叢/藂、吕/呂、卯/夘及已声明的太陽/大陽归一不改变方位。巽神用“大炅”作索引，书影炅/昊等字形尚未逐字裁定；不能将语义位置一致写成字形已校定。完整附注、断语与四将全表不在这六列范围内。

初次比对旧资料发现四处本轮录入错误：订正清单（本地数据：`../tests/fixtures/taiyi_jinjing_v23/correction-manifest.json`）追加原图页栏及数词，初录文件和首次差异报告均保留。

## 同盘来源交付与校验修正

`count_source_assessment`的规则升级为`jinjing_core_table_alignment_v1@1.1.0`，保留旧转录、旧初录和选读值，追加书影初录与订正清单指纹。`facsimile_page`及`facsimile_columns_from_right`标明本局位置，四位置及两算的`source_layer`明确语义书影层；阳41、阴59原来的所选书影差异记录继续保留。

本轮修复来源比较的输入校验：空字符串及“子丑”这样的连续字符串曾因子串成员判断被当成单一位置，现在返回`not_assessed`。合法单一位置仍按传入事实比较，不用循环公式重新生成来掩盖输入不同。144个合法软件盘的核心、关系及来源比较之外的整个盘结果保持逐值一致；这只是软件保留检查，不是144个独立古例。
