# 第二十五轮：焦点生源资格与2027年公布历表

本轮针对上轮真实模型遗漏的条件补齐共享输出：明确取用的可见本爻，现在同时呈现自身生源资格与作为受方的承受门槛。二者与同次既有计算相连，真、假、未决分别保留；没有由模型重写规则。原典计算、历法数值和既有判断结果未改，相关证据见验收回执（本地数据：`validation/liuyao-depth-v25-verification.json`）。

## 生源与受方不再只显示其中一项

旧`generation_conditions.focus`只有受生门槛，生源资格需另从六爻数组找出。上一轮一例只解释有扶与总体未决，漏讲本爻已核作用资格；另一例虽说本位回头克仍在，却漏讲它阻碍向外生扶。这两项按原标准仍为未通过，不能因增加字段便改记成模型已讲清。

现将`source_condition_match/source_status/source_condition_path`加入同一焦点对象，与原有`target_reception_condition/target_status`并列。确定性`source_explanation/target_explanation`分别转述这两个已有门槛；快照也显示相同文字。它们不新增生向，不把来源匹配当作目标受益，也不增加吉凶总分。

回头克来源为假时，文字明确说“向外生扶受阻”；生源未决时不补成不生。实际变爻、伏神及日月取用不借可见原爻的焦点资格，未覆盖主体保留原对应条件。类型合同、严格叶子投影与三端实际输出共用这些字段。

实施前四组工程情境覆盖生源／受方的不同组合，包括原月破日值、本位回头克、源未决但受方可受生、无根受方。初次标注把五爻子水的承受误记为真，忽略了该日旬空；原输入与结果保留，实施前改用上爻寅木测试所需对比。它们不是新古籍占验或盲测，预期和勘误见固定资料（本地数据：`../tests/fixtures/liuyao_focus_v25/README.md`）。

## 完整旧字段的连续性

本轮运行包只改变生扶结果组装、对应输出模型和六爻快照三个文件。`generation_sources`与`target_admission`的完整AST不变，历法、太阳模型、原典资料与其他作用算法逐字节不变。

按执行前协议，在两个既有开发月日遍历全部64×64本变组合，并循环覆盖六个可见位置，共8,192组。剔除仅六个已声明新增焦点键后，完整旧条件结果逐字节序列化散列相同；原未知值、数组顺序、元忌、控制、生扶、阶段及来源都没有忽略。新增焦点的生源值、状态与引用也全部等于同次数组记录。逐组回执（本地数据：`validation/liuyao-v25/continuity-comparison.json`）保留三态分母，不把软件枚举量当作原典或物理正确率。

最终封存副本的原652项核心、629项共享、上轮47项、新增23项及历表提供者80项检查均通过且无跳过。实际wheel提取后运行的70项是新增23项与上轮47项的复验，不另计独立病例。原共享12个测试模块及629项身份与上一轮完全相同。三个源码单元的类型和四个文件的格式均通过；连同17项资料构建、场景和合同生成，共22个检查命令通过。

795个源文件（实际包789个成员）及4,274个支持文件散列不变，wheel和sdist包成员逐字节一致。为避免重复保存整套大数据文件，恢复归档（本地数据：`validation/liuyao-v25/source-archive.json`）使用已核验的上一轮完整归档加17文件增量，恢复后的5,206个成员集合与散列完全匹配。它依赖所列父归档，不能误当独立tar包。新原始资料的Git字节保护在封存后追加，不改变已执行文件内容。

主工作树另有其他任务添加的pytest marker，依赖声明及`uv.lock`相同；测试、构建均明确归属封存源码，不为整个实时工作树背书。旧三轮365、523、382份验证文件分别核对未变，分组有重叠，不相加为独立证据数。

## 两家天文机构的2027年公布值

XML不带节气名称，按固定黄经顺序对应；再将全部12项中气与PDF表逐项核对。日本中央标准时与香港时间换成同一时刻后相符，霜降、立冬等跨民用日期的差别原样保留。两份出版物可能共享基础星历，不是两套独立物理观测。[香港天文台来源说明](https://www.hko.gov.hk/en/gts/astronomy/Solar_Term.htm)另列其所用天文数据机构。

## 原典后续裁决与真实模型边界

本轮继续逐页读同版PDF73—76页六合章，并与104—105页月破章对照。静合起、动合绊、动爻互合和本位动化合是不同作用范围，月破未来逢合又有时间层；不能用一个“六合为真”开关解除全部月破与合绊。原图、阅读笔记与后续裁决要求见研究记录（本地数据：`validation/liuyao-v25/combination-research.json`）。这些尚未成为新的计算谓词，不宣称整章或全书已通过。

上一轮五个真实对话仍为原20条中18条通过、两条解释覆盖不完整，模型自身完整payload散列核验也未观察到。本轮已封存相同五个提示、相同20条标准和新源码／通用指引的复验候选（本地数据：`validation/liuyao-v25/model-proposal.json`）。新对话需独立授权；没有用上一轮已执行完毕的五次授权继续调用，也没有拿工程检查代替自由回答复验。

原生Moshier的501个旧超差点及其数值继续保留；本轮2027年通过不冲销那些失败。具名解析模型与原生模型仍单独标记。原完整事件历史四项失败仍绑定其原执行源，没有拿后来其他任务的回退测试替换`computed`断言。完整历法、全书原典和自由模型解释的目标继续未完成，候选未发布、未部署。

本轮涉及文档的本地链接检查单列通过；末次全库扫描（本地数据：`validation/liuyao-v25/docs-global.txt`）仍检出其他西占文档的缺失引用。没有代造占位报告，也不把局部检查当作全库通过。
