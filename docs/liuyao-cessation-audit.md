# 土逢巳与化绝条款审计

同版《增删卜易》PDF98页明确区分土的绝位与实际作用：土旺相或得生扶再遇巳，应论生不论绝。原程序虽保留了文字提醒，角色条件层却仍沿用“本位变巳为绝”的原始位置标记；在忌神动化绝条款中，可把这一位置直接当成已匹配的不利条件。

本轮沿用[1925年原版影印](https://upload.wikimedia.org/wikipedia/commons/4/42/NLC416-12jh005345-45344_%E5%A2%9E%E5%88%AA%E5%8D%9C%E6%98%93.pdf)，固定原始页码、散列和九条合成上下文，资料及冻结顺序见说明（本地数据：`../tests/fixtures/liuyao_cessation_v17/README.md`）。没有补齐别本火表，没有把原书叙述的结局作为代码准确率样本。

新增`conditional_analysis.cessation_conditions`逐爻区分绝位`position_match`与本条资格`condition_match`。土爻存在已核独立生扶、且未见所列反制时，本条不按绝处理；有扶克冲突或气根仍未裁定时保留未知。有限支持表中没有找到根，不能证明全局无根，更不能据此确认真绝。其他五行保留现有位置谓词和角色层的强弱前提，尚未获全局效力认证。

## 防止生扶循环自证

正在判断的巳日或本位巳变支不能同时充当已生土的独立证明。其他爻的最终`source_grounded`标记也不能直接照搬：土、金、水、木、火之间可能形成一圈，最终又只依靠原土爻的巳变支。新层沿已通过资格的实际动爻生扶路径追踪外部锚点，排除被判断的爻及其他未裁定土逢巳自生锚点。没有锚点的循环保持未知，有独立日月根的有效多段路径仍可保留。

每个生扶事实和依赖步骤都有同次结果的`support_fact_path`；原始已校位置、23条角色公式及其原始匹配值保留。`conditional_atom_values.day_cessation/changed_adverse`与条款`conditional_matched`采用新资格。已知回头克、变爻月破仍可独立使不利条款匹配，不会被生扶例外擦除。化散未裁定，所以其余已列原因不匹配时，整体`changed_adverse`仍可为未知，不能擅自当作全部无害。

这些上下文的现代公开输入分别使用2004-06-02、2003-12-05、2000-08-22当地正午，不将它们说成原书实际事件。与第十六轮固定源码的逐项对照（本地数据：`validation/liuyao-v17-before-after.json`）验证旧位置、原始角色原子及公式匹配保持不变，并记录改变的条件匹配。快照据同次资格打印“本项论生不论绝”或“气根或反制尚待裁定”，不从位置直接写成真绝。
