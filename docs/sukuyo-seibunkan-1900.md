# 《二十八宿詳解》选页对照

本项对照使用国立国会图书馆的[天之卷760661](https://dl.ndl.go.jp/pid/760661)和[地之卷760662](https://dl.ndl.go.jp/pid/760662)。馆方登记星文館々主著、矢島誠進堂出版、明治33年11月。目录出版时间、序文署年和实际刊记分别记录：所读序末署明治三十三庚子，所选末页是封底或另书广告，尚未亲见本书完整刊记。

目前取得并读取27个选帧，来自两卷合计152个帧；这不是全书校勘，也没有认证与桧尾具体抄本的传承关系。此前20帧首读未定位闰月专条；后取得的7帧补见凡例，原首读与补证分别保存。

天之卷第10帧右页《凡例》二明说“潤月は其月の朔日の宿を用ひ”，支持该书图法中闰月比照本月朔宿使用。句尾仍有“準じと／準じて”的分离工作读法，不因现代语法更顺就统一原字。这段是近代刊本的凡例，不是新取得的T2465正文，亦没有说明小月缺三十日的两半日补配或交叠执行顺序。

上卷34至37页月表含牛宿；凡例应用图法另明说除牛而成二十七宿，并将28与1、29与2、30与3同格列日。这种图上的同位不等于小月缺日补配。下卷21页注者怀疑某图不合经文、可能后插，这是其推测；该图与上卷月表的同一性未定，不能据此删改上卷牛字或认证历史插图过程。

下卷23至24页有二月十七日的本命宿例：生日数加13得30，按27宿周数余3。印字工作读“氏”，现代宿名标识“氐”另列，原字不以算法相合而更改。此例说明该版所述月日计数法，不能当作实际满月过宿、古代钟界或现实预测有效的证明。

下卷65页保留平明所直曜、昼夜各八时和次日晓时次后曜当直的定性含义。两角色对中句汉文酉／西、成／戌及相应日文西成／西戌的读法有分歧；主角色首读和后续裁区纠正也分别保存，未接纳规范原字。现代钟点、太阳高度、桧尾半日及闰小月先后仍未定。

结构化结果位于桧尾档案的 `profile_calculation.hinoo_source.critical_calendar_reference.later_seibunkan_comparison`，与所用SAT条文、校记和句义版本绑定。默认T1299档案不因此采用该书图法；本项没有改变日期、宿名、候选或历法政策。分离角色复用同一提供方、历史和文件系统，不能称严格盲读或独立人工校勘。

原完整82,743条件、165,486组合、180整题及所有失败继续保留。本项选帧数不计历史独立观察，程序测试也不计现实预测样本；真实样本仍0，前瞻仍未注册。
