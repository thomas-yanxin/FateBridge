# 双分量时标、原典候选与五例回执复核

本轮将时间点的输入表示与历法政策分开，新增显式精确TT类型和双分量太阳求根路径，并核对全部原始材料。原40,219条包络失败、41项默认标量冲突、26个原典分歧及5例旧评分继续保留，没有转记为通过。新路径尚未替换默认排盘算法，现实预测仍未验证。

## 时间点不能从舍入值猜回

同一个浮点JD可能是明确的IEEE点值，也可能是由一个已知UTC午夜舍入得到的标签编码。只改默认参数的候选在原闰秒控制中新增14项失败，已经回滚；协议、候选和首败（本地数据：`../tests/fixtures/bazi_tt_utc_point_default_v1/protocol.json`）保留。

新增 `TTInstant.from_float`、`from_parts` 和 `from_utc` 分别表示明确的浮点点值、未经大JD相加的双分量点值和保留原UTC微秒的精确编码。UTC构造必须给出明确的原子偏移，不能省略或套默认值。现代逆算只在最后舍入一次；不能保留历史双分量精度的路径明确拒绝，不把它悄悄压回单数JD。

新类型核对了原6,391条输入中全部3,930条正常日期及243条不可表示标签；另核对全部28个偏移起点及其4组微秒标签。早期输入未增加独立真值信用。原默认标量调用仍遵守原约定，41项冲突逐条保留（本地数据：`validation/bazi-tt-scalar-conflicts-retained-v1.json`），显式类型通过不转计给这个门槛。

## 节令数值表示与包络失败

[Skyfield的时间接口](https://rhodesmill.org/skyfield/api-time.html)提供分开的日期与小数部分。独立采集（本地数据：`validation/bazi-split-tt-reference-first-v1.json.gz`）使用原来的固定半月括区间、Skyfield 1.53官方节令函数及同一完整DE440核，重新保留全部4,872个TT根的两个分量；没有用FateBridge结果或失败位置选择搜索区间。

原标量参考点与细化根的最大位移约40.225微秒。新候选计算把小数日一直保留到核插值、光行时、日期坐标框架及TT求根；默认标量函数保持原路径。全部1,024个通用历元的原太阳黄经和三组核位置、速度逐项不变，双分量位置另与原核的Clenshaw计算核对。

4,872项候选比较（本地数据：`validation/bazi-split-tt-engine-first-v1.json.gz`）在原1秒TT门槛下没有失败；与双分量Skyfield根最大差约16.84微秒，与原标量参考最大差约55.61微秒。这些是同一批已暴露输入的数值研究，不是新增独立观测、物理误差上界或对齐偏移。不同TDB、框架、偏折与光行差模型的差别继续分别研究。

原跨时区包络检验同时涉及根的UTC标签、日历偏移及夏令时不连续处。新TT数值比较不能替代该检验，亦不能证明连续区间的极值完整。原40,219项包络失败与782项来源未决（本地数据：`validation/bazi-dayun-future-clocks-exact-atomic-acceptance-v1.json`）保持原状态，尚未用双分量候选重算并通过该全量门槛。

## 原典26个分歧

全部26个输入的条件复核（本地数据：`validation/bazi-all26-conditions-review-v1.json`）保留字面四柱、原标注、所选原文及原19例的既有审阅，不以程序权重反推作者本意。根气、月相、会合成势、合化成立、有效生扶与单纯藏干存在是不同条件。

本轮针对“完整同类三合／三会、目标透出、已有合格重根”的结构候选作一次固定规则检验。它不查用例ID或四柱答案表，不改权重及原门槛，也不把成势写成已完全成化。全部349条原记录回放（本地数据：`validation/bazi-complete-bureau-capacity-candidate-second-v1.json.gz`）得到3个已知分歧改善、没有已知相符项退化，另改变2个未知标注输入；后两项仍为未知，不加相符数。首候选沿用了旧决策的来源标识，修订版已将新规则明确归于1947年任注《众寡》材料，判级条件不变，首次回执保留。

这是已暴露材料上的候选研究，尚未并入默认强弱政策。默认26个分歧及234条未知记录没有减少。后续需完成候选的版本化、其他原文条件与反例核对，以及公开三端回归；不能仅凭这3项改善宣称原典符合或全书认证。

## 已有五例解释

离线回放（本地数据：`validation/bazi-element-receipt-replay-fourth-v1.json`）验证原始散列链、实际同run回执和原评分函数，原0／5机械结果原样重现。4例省略的 `category` 可由完整冻结词条库唯一解析；5例实际收到的标题、全文、来源、引用均与选定词条相符。错误域、错误类别、歧义键、改过的来源版本、准备阶段run替代实际run、工具错误和未完整取回的分页回执都不能因此通过。

2例原技能路径失败仍保留，4份回答缺少可识别来源版本的事实也保留。另提供五份原回答的来源补录（本地数据：`validation/bazi-element-edited-explanations-v1.md`）：程序只从各自实际同次回执追加作者、版本与链接，明确标为补录，不属于原模型回答，不改原分数。没有新模型运行、补考或新增解释忠实度信用。
