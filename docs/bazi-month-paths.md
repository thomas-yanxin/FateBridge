# 月令、原典取用路径与待判条件

[八字判定](bazi-assessment.md) · [原典路径审计](bazi-classical-routes-audit.md)

旧实现把五类十神共现按固定优先级选成`dominant_structure`，再把首候选的五行加入全局喜用。
这会把尚未判断力量的候选直接提升成取用依据。例如工程旺衰已经因敏感性停止自动扶抑，
首候选仍能重新引入土、金。固定优先级也没有区分杀格用印、印格用杀与伤官用杀印。

现在以同次月令选择作为主类参考，保留`formation_status=not_adjudicated`。
旧首候选移到`legacy_dominant_structure`，原候选列表及优先值完整保留供追溯。
`candidate_selection`分列25条有限原典路径的适用月令、实际星位及尚未裁定的力量条件，
没有由共现或原工程优先级选定路径、相神或全局原典喜忌。

25条是路径规格数，不能当作25个独立通过命例，也没有覆盖全书成败救应。
人工来源观察是开发核对，没有第二位独立专家验收或真实模型逐句归因验收。

续读PDF85后修正过强判据：财印为辅不等于必须透干，官伤并透指二者同时透出，不能把只有伤官透出也计入。财印仅出现仍不证明已经有效辅助。另补伤官以财通官路径；原文所谓化伤为财不在此层解释为删除原局伤官或支局已经合化。原11项来源观察保留，新增附录同时收录该页两个完整命式，均无强弱标签；这些是开发核对，不能相加为独立准确率。

进一步逐句检查发现，PDF84–85对官伤并透作的是警语，不能当作路径不存在的必要前提。
`month_path_conditions_v3`将它移入`source_cautions`，以`source_caution_only`标记：
即使二者同时透出，该路径仍保留力量待判，不因此断成格或现实结果。
v2的654项工程通过记录及这项新语义回归的首次失败均保留，不把旧通过改写为原典全验收。

## 输出怎样区分观察与裁定

`selected_month`保留原月令选择的版本、规则、字与十神，另列`original_main_qi`。
两者不同时，路径用`month_anchor_basis`标记来自`selected`还是`original_main_qi`；
同一条路径不重复计数。并存是兼格待审的证据，不是已经证明两格都成立。

路径只对本次可观察条件返回`matched/not_matched`。星位引用来自同次全部非日干及四支藏干，
可在视图同时返回的`ten_gods`中解析；藏干出现、透干、根存在及有效力量分别理解。
力量条件统一保留`unknown`，不由计数、印比总量或工程强弱标签冒充原典裁定。
`chosen_path_id=null`、`adjudication_status=not_adjudicated`，不把待判路径称为已选相神。

月令路径另与[人元司事来源分层](bazi-month-duty-sources.md)分开：数字条目、原注与任注条件、实际透藏可从同次`month_command.intra_month_duty.source_reference`读取。来源中提到某干不自动改变本气、所选取神或现行藏干，数字表也没有被提升为有效司令选择器。

可观察前提不足的路径为`observable_prerequisite_not_met`；
观察前提齐备才进入`requires_force_adjudication`。前者也不等于现实事件不会发生。
类型合同允许合法局部投影，同时拒绝凭空写入力量通过、成格通过或非空已选路径。

茅状元例是重要未解问题：原印章以身重印轻、偏官生印解释，申中本气为庚印；
现行有限透干选择却取戊杀。新结果同时保留印用杀与杀用印的基准差异，
没有修改原录或宣称月令分歧已解决。其工程强弱与原文的分歧也仍保留。

## 喜用策略的实际变化

`resolution_policy=source_conditions_before_preference_v2`：

- 不再将旧首候选的喜用单独提升为全局方向；旧候选单独提出的忌避也只列条件项。
- 基准扶抑仍沿用共享旺衰模型。参数敏感或极端时，基准继续不提供自动扶抑方向。
- 旧候选、调候参考及冲突完整保留；参考层的反向信息可使基准方向转为条件项。
- 四组五行保持互斥且完整覆盖五行，不把未入喜用当作忌神，也不提供元素行动处方。

这修复的是未裁定共现越级影响取用的路径，没有完成原典相对力量算法。
工程强弱、历法独立误差、全部调候条件与真实模型解释仍按原验收清单分别检查。
原典强弱的已知失败不能因新增路径或工程检查通过而删除。
