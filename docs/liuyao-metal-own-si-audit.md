# 金爻本位化巳的长生与回头克资格

第三十五轮修正了一个实际作用错误：金爻明动化巳时，程序始终按火克金保留回头克阻碍，即使已经核实金爻有独立旺相生扶，向外生扶资格仍直接为假。选定版本的明文同时列出巳日、卦中动巳及金爻实际化巳；此前的计算只落实了部分巳日分支。

依据仍是同一份 NLC 1925《增删卜易》书影（本地数据：`../tests/fixtures/liuyao_scan_v3/sources/nlc-1925-zengshan.pdf`） PDF 第 97—98 页，SHA-256 `caac111bc5c5b1c08fd27b3828e7cf6b5430503800f2427d8f2b28809022abaa`。本轮重新目读已保留的书影，不从其他版本补齐火行表。规则、作用限制及 11 个合法合成上下文在修改前冻结（本地数据：`../tests/fixtures/liuyao_metal_own_si_v35/freeze.json`），修改前的完整计算结果（本地数据：`validation/liuyao-v35/cases-before.json`）保留。它们是开发上下文，不是原书事件或现实验证样本。

现在只对原始可见金爻的实际本位变巳建立单独资格。原始 `火克金`、`back_control=true` 及旧阻碍记录保留；日月的独立生比或有独立根、资格已核的实际动土提供生扶前提。动土证明复用同一领域服务，排除被判断金爻和循环的巳信用，不因来源最终标签为真就认作有独立根。

变巳的旬空、当日冲空填实、月破及值日例外复用既有本位变爻门槛，与第 97 页条件分别返回，明确这是结合既有条款审当前效力的解释，不冒充原文逐字描述了开发结构。前提与门槛均已核时，`own_changed_si.condition_match=true`，同一本位巳火的 `qualified_back_control_condition=false`；未核时两项保留未决，不能继续把原始关系写成已经成立的回头克，也不能补成已获长生。

独立月克、日克、普通午火动克、原爻空破合绊及其他来源资格仍分别处理。普通化午不适用这项例外；静爻不借变盘同位的巳支；变巳不跨位作用其他原爻。长生也没有被改名为五行回头生，`back_generation_condition` 仍按实际五行关系和原门槛返回。角色原始原子与当前限定原子分开，接续相生路径将待审阻碍与明确阻断区分。

例如工程映射为 2006-10-02 12:00、Asia/Shanghai，坤之晋、四爻与上爻明动，上爻酉金实际化巳。独立历表及日序参考给出酉月甲子日；月令同类生扶已核，变巳无所列空破门槛，原金爻向外生扶资格由假改为真。五爻亥水仍在原旬空，不能由金爻资格匹配推出受方已经受益或现实成功。现代日期在实现后用冻结 TT 交节参考及国立天文台日序锚点独立映射（本地数据：`../tests/fixtures/liuyao_metal_own_si_v35/public-payloads.json`），没有调用生产历法选择日期。

首轮定向复验 57 项通过、1 项失败，暴露了第三十四轮自身的一项错误期望：一个酉金实际化巳的开发输入，在已核动土扶持后仍要求保留同一本位回头克。旧输入、旧期望与失败未改，修订后的版本裁决（本地数据：`../tests/fixtures/liuyao_metal_own_si_v35/v34-case-adjudication.json`）另存。该例仍有午月反制，所以新来源资格为未决，并未放宽成真。其后 R1 的 177 项定向检查和 25 项静态、来源及生成检查通过；R2 只补强输出类型与测试，再完整复验。
