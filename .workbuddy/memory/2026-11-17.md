# 2026-11-17

## 任务：用 FateBridge 设计一款有爆款潜力、强付费、一个月可交付的 APP

调研了 Co-Star / Quin / starla / 测测 / 遇见塔塔 / Astar 等，并核对了 FateBridge 源码能力，产出设计方案「合拍」（关系合盘，零 token 架构）。

关键事实（可复用）：
- FateBridge 全部 92 个工具都是确定性计算、计算层无需 LLM API Key；`snapshot_text` 是规则生成文本，非 LLM。塔罗能力不存在（只有占星骰 otherbu）。
- 合盘工具：`two_person_compatibility`（八字合婚，实测输出 overall_score 0–100 + 五维 weight/score + strengths/challenges + traditional_compatibility，status=partial，分数是规则索引非成功概率）、`astro_relative_chart`（evidence_views=compare/composite/influence/timespace/marks，需双方经纬度）、`sukuyo_compatibility`（宿曜27宿）。
- 省 token 姿势：`fields` + `strict_fields=true` + `include_snapshot_text=false`；evidence_views 是发现文档不是请求参数。`as_of` 冻结时间、`trace_id`/`parent_run_id` 关联。结果临时文件约 1h 过期，APP 侧须自行持久化；仓库无账户/历史库。
- 硬边界：不做生死寿命、灾祸断言、临床诊断、医疗择时；卜卦/择日有 topic 白名单。

市场结论：
- Co-Star 490万 MAU、零买量，收入 80%+ 来自"看他人星盘/情侣契合度"一次性好奇，订阅仅 13.7%；被 Midjourney 收购后用户刷一星，骂"AI 伪灵性"。泛泛/重复文案是 Starla、遇见塔塔、Co-Star 共同差评点。
- 全球占星 App 市场 2025 约 47 亿美元，2026 约 57 亿，CAGR ~25%；美区 30% 成年人年用一次。
- 中国大陆：算命/占卜宣扬封建迷信属违法（《网络信息内容生态治理规定》第六条等），应用商店下架过；但"泛心理/自我探索/传统文化"外壳可行（测测/遇见塔塔/Quin 均如此）。2026 年 3·15 测测被曝诱导消费近 30 万，监管风险点=绝对化承诺+诱导高额消费+退款难+达人资质。

设计要点：定位"关系合盘与相处指南"，聚焦暧昧/相亲/恋爱转折期"TA 适不适合我"的焦虑；免费个人盘引流→测TA单次¥12–18→关系档案订阅¥28/月→流年提醒回访→双人共同解锁+分享卡片裂变。目标人群先国内 18–30 都市女性，再出海。MVP 4 周：W1 接 FateBridge REST 封装 3 工具+字段投影；W2 结果可视化；W3 档案/支付/分享；W4 文案+合规。token 策略：计算+渲染零 token，仅付费"追问"用薄 LLM 且按视图字段投影。

后续若继续：可把方案落成 PRD 或落地页/原型；出海需注意 Co-Star 用户对"AI 生成"的排斥，卖点应强调"真实历法计算、可复现"。

## 任务：FateBridge 能否做成 Skill

结论：能，但要区分「能力」和「方法论」。计算能力已是 MCP/REST/CLI（92 工具，zero token），不该重做成 Skill；适合做成 Skill 的是「如何正确咨询」的流程纪律（硬边界拦截、主题路由、资料归属、引擎优先、字段投影省 token、三层解读）。Skill 里绝不手算。

已创建项目级 skill：`.workbuddy/skills/fatebridge-consult/`（SKILL.md + references/{safety,tool-map,low-token,interpretation}.md + scripts/fb_consult.py），fastmatter 用 init_skill.py 初始化、quick_validate 校验通过、package_skill 打包到 `dist/fatebridge-consult.zip`。fb_consult.py 自动定位仓库 .venv（src 布局下系统解释器不可用），支持 list/describe/call，call 支持 --fields/--no-snapshot/--strict-fields 与 KEY=VALUE 透传；已实测 list、describe、two_person_compatibility 调用（投影生效、无 snapshot_text）、usage_error 报错回执正常。

关键点：evidence_views 视图名不是请求参数，只复制其 fields；result_delivery 约 1h 过期需下游持久化；错误只在 stdout JSON，exit code≠0 判失败，仅 retryable=true 重试。
